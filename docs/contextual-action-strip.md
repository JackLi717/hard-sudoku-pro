# Contextual Action Strip

手机游戏页在棋盘和数字键之间使用一条无边框、无背景的快速操作行，平时不占位。它只承载“批量排除”和带闪电图标的自动完成开关，不再显示“只剩简单步骤”状态文案或带边框卡片。两个操作同时可用时并排靠右显示；只有一个操作可用时仍保持右对齐。

安卓平板横屏的自动完成入口是一个带闪电图标的小开关，视觉尺寸为 36×20 并跟随当前主题强调色；它吸附在右侧工具面板的右下边缘外侧，与面板保留 6px 间距并和右边框对齐。开关保留不少于 44px 的隐形触控范围，不在面板内部显示快速操作行。开关使用绝对定位，不参与面板尺寸计算，确保整个工具面板始终在垂直方向居中。手机快速操作行复用同款开关。两种布局中的开关都只在自动完成可用或正在运行时显示；可用时默认关闭，打开后执行一次自动完成，并在逐格动画期间保持开启和不可操作，完成后随游戏页离开。沿用原有资格判断、其他忙碌状态和暂停隐藏规则，并保留“自动完成”的无障碍名称及操作说明。

冲突按以下顺序处理：

1. 暂停和其他遮挡棋盘的模态界面接管交互，快速操作行隐藏。
2. Hint 使用自己的语义视觉层，快速操作行隐藏。
3. 提交操作等其他忙碌状态暂时隐藏快速操作行；自动完成动画期间保留开关并保持开启且不可操作。
4. Auto Complete 条件满足时显示关闭状态的开关，等待玩家确认。
5. 批量排除与自动完成可以同时显示，不互相挤占位置。

批量排除使用“多选框＋减号”的组合图标并保留短文字，避免仅靠抽象图标表达复杂操作；不再提供选中格数或 `Done`。其完整规则见[候选格自然多选交互](candidate-multi-select-interaction-proposal.md)。临时候选选区不写入棋局、Undo 快照或复盘动作；批量候选删除仍走现有 `edit_candidates` 命令及 Undo/复盘路径。

Auto Complete 在开启设置后，于困难、专家和极限难度剩余 30 个或更少空格时开始求证；每个空格对应一步填数。只有余下全部步骤都能由末格补全或唯一候选数完成，且棋局没有错误时才提供操作。打开快速操作行右侧开关才开始逐格填入；动画期间开关保持开启，完成或资格消失后自动移除。原先位于棋盘上方的 `»` 入口不再显示。设置和界面使用“自动完成”语义，已保存的偏好字段与复盘动作标识保持不变。
