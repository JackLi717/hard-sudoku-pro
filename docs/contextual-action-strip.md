# 棋盘边缘收尾入口

游戏页的主要工具栏固定为五项：撤销、擦除、候选、笔记、提示。收尾不占第六个位置，也不留下工具栏空位；其他高级工具保持原有入口与布局。

设置只提供一个“收尾辅助”开关。开启时提供可选操作，关闭时隐藏收尾入口与提示；不再提供手动／自动模式，不会自动执行。沿用当前偏好字段 `autoFinishMode` 的 `manual`（开启）和 `off`（关闭）值，默认开启；无效旧值按当前默认设置处理，不保留自动执行路径，不增加开发版本号或迁移流程。

## 可用与操作

- 困难、专家和极限难度，剩余不超过 40 个空格且当前填数全部正确时，求证余下整盘是否仅用末格补全和唯一候选数即可填完。玩家笔记不参与资格求证。
- 满足条件后，在棋盘下缘右侧、格子之外显示“收尾”按钮，点击才执行。它是一次性操作按钮，不是开关。
- 每局在当前 App 会话内首次可用且游戏页已显示、棋盘与入口尺寸已测量时，在棋盘正中央显示“余下 N 格可自动填完”的文字，同时播报无障碍提示。文字淡入后停留约 2 秒，再用 350ms 原地淡出，随后右下方收尾按钮轻亮一次。完整播放结束才记录本局已提醒；过程中暂停、后台、打开菜单、提示、推演或离开页面，恢复后从头补播。完整提醒后继续填数或暂停恢复不重复播放，新棋局重新提示。减少动态效果时在棋盘中央显示静态文字 2 秒，不播放淡入淡出和按钮高亮。
- 开启辅助时预留 31pt 棋盘边缘窄条：统一计入棋盘外框向下伸出的 3pt，按钮外观保持 72 × 24pt，外框到按钮以及按钮到数字键选中背景各留 2pt；点按区域高 31pt，并向左侧空白扩展，不向棋盘或数字键扩展。竖屏移除该窄条与数字键之间额外的布局间距，并将数字键从 72pt 区域的垂直居中改为靠上排列，上内边距缩到 2pt、下内边距增加到 10pt，保留原有按键高度；进入页面时纳入布局预算。资格出现、消失、保存、暂停和动画运行不使棋盘、数字键或工具栏移动。提示使用不接收触摸的绝对定位层，不改变布局或锁定棋盘。
- 暂停、后台、提示、推演与其他忙碌操作期间不提供收尾点击。收尾动画运行时保留按钮，显示“收尾中…”并禁用重复执行。
- 收尾逐格动画统一为每格 200ms：选中 40ms、填入 60ms、划除候选 60ms、淡出 40ms，40 格约 8 秒。保留原有资格判断、结算与复盘事件；不计作智能提示，不影响积分。不改变题库、难度、原生竖屏规则或其他操作。
- 复盘使用有效操作路径作为备用读取方式时，仍保留实际保存的批量收尾事件，并验证它连接收尾前棋盘与最终保存状态；不因撤销后的完整事件路径不连续而丢弃整局步骤，也不推测缺失的收尾事件。

候选多选规则见[候选格自然多选交互](candidate-multi-select-interaction-proposal.md)。收尾运行时仍锁定棋盘并取得交互优先权。
