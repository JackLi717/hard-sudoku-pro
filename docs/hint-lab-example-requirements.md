# Hint Lab 例题质量与覆盖要求

适用范围：首个公开版本之前的 39 项技巧实验。更新当前开发基线，不增加内容或协议版本，不保存逐轮题库和审计归档。

## 合格例子的含义

每个实验至少三个独立合格例子，并相对本次输入基线新增至少两个独立例子。旧例不满足新标准时替换，不能以旧例数量抵扣新增要求。每种已支持的主要推理模式至少两个独立例子；方向、布局与结论差异分别统计。数字置换、旋转、镜像不计为独立新增来源。

正式实验必须从有效、唯一解的原题开始，使用实际原生检测器的有效步骤回放，精确重建盘面、候选和给定格身份。候选没有删掉参考答案不等于删除过程合法。人工候选结构只能用于独立的算法、讲解回归测试；未证明原题唯一与状态可达的结构不得出现在正式实验目录或计入配额。

目标步骤必须成立、有实际填数或删除，并保留能验证的证明。应用目标步骤后出现单数等简单后续是正常现象，不因此淘汰。

## 低级技巧门槛

以 `native/hsp-hint-core/tests/lab_fixture_validation.hpp` 中明确的偏序为执行定义：低于目标等级的全部支持技巧，以及明确列出的同级基础规则。技巧目录顺序和 `humanCost` 不能替代偏序定义。

验收起点必须通过一次完整的“低级规则均无可用步骤”检查。这比“只用低级技巧无法解完整题”更严格：起点没有任何第一步低级动作，因此低级规则序列无法开始。若发现低级动作，生成过程必须先推进到固定点，再重新检测目标；目标消失则淘汰该候选。

- Full House 没有更低规则，按行、列、宫覆盖。
- Naked Single 排除 Full House；Hidden Single 再排除 Naked Single。
- Locked Triple 排除基础数对；四数组排除三数组。
- Multi-Coloring 排除 Simple Coloring；XYZ-Wing 排除 XY-Wing。
- Locked/普通子集、Turbot/专用鱼形、专用链/通用链有定义重叠，不制定循环互斥规则。

硬门槛针对明确支持的规则集合，不声称涵盖所有数学解法。高级链的深度、节点访问和枚举边界属于检测器能力边界；在边界之外不能证明不存在其他解释。取消、枚举截断、超时或验证未完成不得记为通过。同级技巧可以有替代解释；本轮不宣称已排除任意长度的同级链或所有成本更低的同级证明。

## 模式覆盖

模式分类必须来自实际证明结构，不能仅取全部 `focusRegions` 的区域种类。例如鱼形方向取基础区域；锁定候选区分来源和影响区域；隐藏子集以完整落点所在区域分类。

| 技巧组 | 主要覆盖维度 |
| --- | --- |
| Full House、Naked/Hidden Single | 行列宫证据、目标是否真正需要该规则 |
| Pointing、Claiming、Locked Pair/Triple | 行宫/列宫关系、来源方向、子集数量和实际删除 |
| Naked/Hidden Pair/Triple/Quad | 行列宫、不可约的小集合、完整候选/落点、额外候选 |
| X-Wing、Swordfish、Jellyfish | 行基/列基、基础落点分布、不可退化的小鱼形、单/多删除 |
| Skyscraper、Kite、Turbot、Empty Rectangle | 强对与宫连接的实际布局、端点可见关系 |
| W/XY/XYZ-Wing | 双值或三值枢轴、真实强连接、目标共同可见关系 |
| Simple/Multi/Complex Coloring | 同色冲突、见两色删除、跨分量关系、实际传播路径 |
| Remote Pair | 真实双值连接、路径长度和分叉，不能以坐标排序冒充链 |
| Unique/Hidden/Avoidable Rectangle、BUG+1 | 当前支持的唯一性模式、原题唯一、已填与给定身份、全局计数 |
| Finned/Sashimi X-Wing | 行列方向、单/多鳍、缺角、单/多目标、鳍与删除目标同宫 |
| X/XY-Chain、AIC、Grouped AIC | 端点/矛盾、填数/删除、真实强弱边、链长度、分组数量/位置 |
| Forcing Chain/Net | 穷尽分支、共同填数/删除、单分支矛盾、真实依赖、链与网的区别 |

不要求无意义地穷举所有组合。不同链长或坐标本身不是新的推理规则；同一个例子可同时覆盖方向、结果和长度，但不能因此算成两个独立模式例子。

鱼形保留确切的基础区域落点序列（例如 Jellyfish 的 2-2-3-3 与
2-3-4-4），以展示较稀疏和较密集的四区域约束。教学分类把 Jellyfish
8–10 个落点标为稀疏、11–16 个标为较密；Swordfish 的 6 个落点标为
稀疏、7–9 个标为较密。这些是显示和抽样范围，不是新的技巧子类型。
若出现每基础区域恰好两个落点，另标记 `minimum-density`；不要求穷举
全部落点数量组合，也不把十落点例子声称为八落点极限例子。

Unique Rectangle 当前只承诺 Type 1；Hidden Rectangle 当前检测器的 roof 强对只支持行方向。未实现的文献变体应明确列为能力边界，不伪装为已覆盖。新增支持模式必须同时补检测、证明、界面和例子。

## 生成、展示与验证

先搜索当前题库和合法回放，再按真实缺口定向生成原题。生成文件只由生成器导出，临时来源和检查点可以丢弃。输出包含稳定 ID、原题、回放步骤、候选状态、模式/布局/结论标签及验证范围。

独立检查器重放每个例子、重新检测目标与低级规则、计数原题解并核对覆盖标签；不信任 JSON 中自报的验证布尔值。提交当前例题数据、必要生成来源和简洁验证报告，不提交原始日志或历史数据副本。

实验按技巧聚合，例子显示可读模式名、方向、结论和技巧内编号。切换例子必须清空上例的临时假设、候选变化和已应用状态。所有棋盘沿用当前 `useAppTheme()`/`boardTheme`，不新增实验专属主题。

自动验收覆盖全部正式例子的四语讲解、完整原子结果、Apply/Undo 和切换状态。精确坐标/分页的结构回归使用隔离的生成测试案例，不算正式例子。原生检查、组件验证和真机验收分别记录；未实际执行的真机检查不写成通过。
