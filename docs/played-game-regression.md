# 真实对局跨平台回归机

回归现已包含[排除与填数分步识别](reasoning-stages-prototype.md)，报告提供 `reasoningStages`、`reasoningSummary`，并独立检查分步转换和来源依赖；指定新报告为基线时，也检查来源或依赖是否丢失。

归因语义只引用[玩家技巧归因协议](player-technique-attribution-policy.md)。本工具不修改游戏数据库、原始影子日志或成长档案，不生成真人思考路径标签。

## 一键使用

在项目根目录、Node 24 环境运行：

```sh
npm run behavior:regression:devices
```

它采集所有连接且可通过 `run-as` 读取的 Android 游戏，以及本机 iOS 模拟器目录内的游戏存档（无需启动已关机模拟器），再编译当前 C++ 并回归。Android 默认使用 macOS SDK 的 adb，可用 `ADB` 指定。macOS 需 Xcode 命令行工具及 C++20 编译器。设备上的游戏应保持静止，Android 复制前后摘要不一致会拒绝采集，而不会停止应用或丢弃 WAL。

其他主机或单平台可以分开执行：

```sh
npm run behavior:regression:capture -- --android
npm run behavior:regression:capture -- --ios
npm run behavior:regression:capture -- --database /absolute/path/user.sqlite
npm run behavior:regression -- --corpus /absolute/path/played-games.json.gz
npm run behavior:regression -- --corpus /absolute/path/played-games.json.gz --baseline /absolute/path/report.json
```

`--database` 可重复指定，同行目录的 `behavior-shadow.sqlite` 自动纳入。iOS 和导入 SQLite 以只读连接和读事务读取；Android 副本包含 WAL 后再读取。用户库与影子库是两个读快照，不声称有跨库原子事务。缺失来源、无法读取的设备明确报告，不静默计为通过。

默认输出 `.local/behavior-regression/capture-*/played-games.json.gz` 和 `run-*/report.json`，各次运行使用独立目录、拒绝覆盖。完整数据库内容只保存在本机且被 Git 忽略；代码库只保存最小缺陷样本。共享完整样本库前请确认其中含游戏历史与本机路径，不应当作产品资源打包。

## 检查范围

- 枚举全部会话，不只选最后一局；保留未完成、弃局、错误操作和已撤销分支。完全相同的会话快照去重。
- 独立数独求解器检查唯一解与完成盘面，不使用保存答案证明技巧标签。
- 依据保存的 accepted move 前后快照，将填数、删除、提示、辅助补全送入当前真实行为适配层；明确列出 UI/计时投影及撤销重建边界。
- 使用当前 C++ 重放新请求和原始影子请求；复验新投影与旧日志中的完整机会过程。旧日志保持原样，修复不会悄悄改写旧局回顾。
- 独立行列宫扫描器从提示曝光候选与真实已应用提示出发，检查后续实际动作的提示依赖；它不调用生产单数实现，也不模拟未来落数。
- 对本轮候选恢复 4 个动作、提示上下文 2 个冻结反例和成本关联建立固定期望。Jest/工程验收也运行精简样本，无需连接设备。
- 可显式指定上一份已审核报告作为基线：已匹配变未匹配、枚举完整性倒退、已有提示依赖丢失、完整过程验证减少或会话/请求消失会失败。候选列表及默认名称变化另列 `changes`，需结合修复目的审核，不自动更新基线。

## 状态解释

- `failed`：执行错误或明确断言失败，退出码 1；空样本库不能通过。
- `checks_passed_with_incomplete_evidence`：已执行断言通过，但历史曝光缺失、无法复原所有 UI/异步时序、枚举不全或未解释动作仍单独保留。退出码 0 仅表示工程断言通过，不是所有历史动作均已识别。
- `passed`：本次要求的证据与断言均完整；历史数据库回放通常有时序局限，不应期待强行得到这一状态。

真实数据库不记录所有选格、后台、计时回调或提示展示时刻。不得假装精确重放这些缺失事件；异步过期、快速输入等严格边界由已有真实控制器测试和对抗模拟补充。本工具不会替代这些测试，也不会把“结果唯一”解释成“玩家必然用了某个技巧”。
