## 发现与修复

10:42 完成的二级对局共 78 次分析请求（58 次落数、20 次候选删除），78 次原样 C++ 回放结果一致，无缺失动作或盘面指纹不一致。影子导出为 79 条：78 个片段与一条无片段的错误输入诊断。

此局记录仍使用旧式 segment/request ID，安装包 JS 时间为 09:24，不能把这局视为上一轮修复版的模拟器回归。不过以下两个问题在当时最新主分支也可重现：

1. 四次删除候选后直接填入同一数字，未显式加回候选，正确落数被旧独立候选状态拒绝。
2. 擦除 R5C5 的错误数字 7 时，错误地把最近的 R8C7 填 4 的片段标成失效。

修复适配器，使直接落数可撤回同格同数字的旧删除证据，重建落数前的独立候选并发出独立 placement 请求。旧删除保留为不可归因诊断，而非被改写为成功。

控制器以游戏 move ID 关联请求片段，擦除查找目标格最后一次值变化，撤销查找实际历史栈顶动作。不再保存或回退到“最近已结束片段”。即使当前开放片段同时被中断，也仍单独处理确实被擦除/撤销的历史动作。
