# 阶段 6D：双端设备无障碍终验清单

日期：2026-09-02

## 用途

本清单是阶段 6 的最终设备验收依据。模拟器用于提前发现布局和语义问题，但不能替代 iOS、Android
真机上的 VoiceOver、TalkBack、字体渲染、触觉反馈和系统“减少动态效果”验收。

每个组合必须记录设备、系统版本、App 提交、结果和证据路径。发现问题后先标记 `BLOCKED`，修复并
重新执行原组合，不得以其他组合的通过结果代替。

## 验收前置条件

- 使用候选发布提交构建，不连接开发菜单，不启用 Hint Lab。
- 全新安装一次，再覆盖安装一次，确认新用户和旧数据升级都能启动。
- 准备一局可完成题和一局可稳定触发至少两页提示的题。
- 每次切换语言、主题、字体或辅助功能后重新进入首页和当前游戏。
- 验收结束后恢复系统字体、动画、屏幕阅读器及 App 语言/主题设置。

## 必跑主流程

1. 启动 App，浏览首页统计摘要并选择难度。
2. 选择格子，输入数字，切换候选模式，写入和擦除候选，执行撤销。
3. 打开提示，逐页阅读推理，确认遮罩、高亮、候选删除线和结论；应用提示并撤销。
4. 暂停游戏，确认棋盘内容不可读、不可聚焦；继续游戏。
5. 打开设置，切换语言、主题和至少两个游戏选项，确认控件名称、提示和状态完整。
6. 浏览统计、玩法说明、技巧目录和一个高级技巧详情，再返回游戏。
7. 完成或失败一局，读取结果指标、奖励和后续操作。
8. 杀死并重启 App，确认设置和未完成游戏正确恢复。

## 每组检查点

- 所有交互目标均有名称、角色、状态；开关、单选项和模式按钮会朗读选中/启用状态。
- 棋盘格按“行、列、值或候选、选中状态”朗读；数字键会朗读剩余数量和禁用状态。
- 暂停时 81 个棋盘格均不进入焦点；恢复后重新可聚焦。
- 提示页标题和正文会在翻页后朗读，进度可理解，结果不会在推理完成前泄露。
- 最大字体下正文可滚动、按钮不重叠、文字不被固定高度裁切；棋盘数字和候选布局不变形。
- 错误、选择、提示、完成和禁用状态均有颜色之外的文字、符号或无障碍状态表达。
- 减少动态效果开启时提示抽屉、分页和棋盘强调不执行依赖位移/淡入的动画。
- 深色模式下正文、候选、遮罩、高亮、删除线和焦点框具有可读对比度。

## 当前执行状态

- Android API 35 模拟器：150% 字体、德语、简体中文、TalkBack 游戏操作和暂停焦点隔离已通过。
- Android API 35 模拟器完整回归（2026-09-02）：首次复现点击棋盘后进入错误覆盖层，根因是游戏
  交互触发震动时 Android 清单未声明 `android.permission.VIBRATE`，系统同步抛出
  `SecurityException`。清单补齐权限后，声音、震动和保持唤醒等可选反馈也增加故障隔离，反馈失败
  不再中断选格或其他游戏操作。
- 修复后的 Debug 与 Release APK 均完成首页继续游戏、连续选格、错误输入与撤销、候选数切换与
  撤销、正确填数、擦除与撤销、暂停与恢复、设置开关、返回首页及杀进程冷启动恢复测试。Release
  版额外执行 80 次连续棋盘点击，进程保持存活，系统日志无崩溃、ANR、权限异常或 React 错误；
  帧统计无高输入延迟、慢 UI 线程或漏 VSync，P95 为 23 ms。
- 本轮工程门禁通过：`npm run check`（18 个 Jest suite、260 个 test，C++ 39 技巧）以及 Android
  `check assembleRelease`（四种 ABI）均成功。
- iPhone 15 Pro / iOS 17.5 模拟器：最大动态字体、全新安装、启动与首页滚动已通过；验收时发现并
  修复 Nitro SQLite 并发启动崩溃。
- 当前环境未连接 iOS 或 Android 真机，因此 A1–A8 真机矩阵尚未签署，阶段 6 仍保持未完成。
