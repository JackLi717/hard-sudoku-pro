# 技巧挑战模式产品定义

记录日期：2026-10-02。状态和授权边界见 [设计总览](challenge-mode-design.md)。

本文件定义挑战解决的用户问题、用户行为和进阶规则。已确认方向与具体设计建议分开标注；判题算法以 [选题与判题机制](challenge-mode-validation-policy.md) 为准。

挑战与 [免费技巧讲解和专项练习](technique-learning-practice-design.md) 构成三个互补功能。课程可自由查看，练习可自选技巧；两者不作为挑战的强制入场条件，完成记录和广告资格互不替代。新增学习练习功能不改变本文件的挑战结构、禁用提示或进阶规则。

三部分使用独立题目及原题来源。讲解或练习中的原题、其等价变换和其他回放阶段不能用作挑战题；其他功能的候选、解析和作答状态不进入挑战会话。按技巧跳转只传递技巧与导航信息，不传递题目答案或通过事实。

## 产品目标

让希望提升逻辑能力的玩家，在无需解完整盘数独的情况下，主动发现技巧、提交有效结论，并在综合局面中连接多次推理。长期吸引力来自新的观察方式、逐步扩大技巧范围和可见的挑战表现改善。

首批验证玩家能否理解操作、获得公平反馈、愿意连续挑战以及在陌生局面中再次找到技巧。暂不把通过某道题解释成掌握技巧，不承诺留存、购买转化或科学能力评分。

## 内容单位和进阶

建议正式使用以下名称，界面命名后续细化：

| 单位 | 定义 |
| --- | --- |
| 挑战集 | 一段完整体验，包含五个专项关和一个综合关 |
| 专项关 | 一个独立固定局面，完成一次指定范围的技巧应用 |
| 综合关 | 一个连续变化的局面，应用多种已接触技巧达成考核目标 |
| 尝试 | 从该关起点开始的一次操作过程，包含提交和反馈 |
| 步骤 | 一次经判题接受的原子逻辑应用 |

五个专项关分别考察不同技巧；每集五种技巧从当前阶段技巧池中选择。专项关按顺序完成，五关通过后进入综合关，综合关通过才取得下一集的进阶资格。Premium 绕过广告要求，但遵循相同进阶规则。

这里将综合关作为新增第六关，是对用户综合考核方向的具体建议。广告范围须与这一结构一同确认，不能默认在第六关额外收费。

首批建议只发布一集完整内容，包含综合关，共六关。若需要同时验证广告解锁，再准备第二集，共十二关。只显示实际发布内容；下一集未发布时显示当前内容已完成，发布后读取既有进阶资格。

## 初期技巧和扩展

初期建议使用六种已支持技巧：Hidden Single、Locked Candidates Pointing、Locked Candidates Claiming、Naked Pair、Hidden Pair、X-Wing。稳定代码引用现有技巧目录，页面名称沿用项目本地化。

前几集明确专项关目标技巧，选择结构清楚的局面。后续丰富区域、方向、候选分布和排除目标，并逐步增加三数组、Wing 和单数字图形等已有技巧。混合判断阶段可以隐藏技巧名称，但只使用已经出现过的技巧。

30 集是第一阶段扩展路线，不要求全部局限于初期六种技巧。后续按整集补充，内容更新随 App 发布，不承诺每周在线发新题。数字置换、旋转、镜像可用于复习，不算独立内容增长。

## 一关中的用户行为

1. 查看任务：明确该关要求填数还是排除、是否需要提交完整结果，以及何时通过。
2. 观察：默认显示合法候选，自行选择数字、格子和相关区域，不展示关键结构或答案。
3. 组织提交：分别选择推理的关键依据和要执行的结论；名称选择不是首期必需操作。
4. 确认：提交前自由修改草稿，提交后判题才改变真实盘面。
5. 获取反馈：有效操作被原子应用；无效提交不改变盘面；系统故障不记作玩家错误。
6. 继续或结束：专项目标完成则通过；综合关继续观察变化，直到达到综合目标。

关键依据选择是本套文档为避免只检查最终答案而提出的设计建议，具体手势、控件和视图由后续界面设计决定。无需玩家书写完整证明或补做所有心算过程。

首期建议排除题提交同一个结构的全部直接排除，填数题提交一个直接确定值。任务明确写出这个要求，不能临时在判题时更换标准。

## 综合考核

初期综合关建议需要至少两种不同技巧和二至三个关键步骤；使用同一连续盘面，后续至少一个考核步骤必须依赖此前真实应用的结果。后续可以增加步骤和干扰，不单纯依靠候选更密或更长耗时制造复杂感。

综合关不预告具体技巧顺序。考核目标以规则表达，不绑定某一条示范路径；内容机制验证允许的替代路径。达到目标即可结束，不要求整盘完成。目标步骤数是最低或目标范围，不强制玩家精确做出示范路径的步数。

同一个步骤不能同时算作两种技巧；重复提交、撤销后重做同一机会不能增加考核进度。单数等收尾可以参与推理，但不能代替内容要求的两种核心技巧。

通过表示完成本集考核任务。它不是竞技认证、真实心理过程的证明或长期掌握结论。

## 辅助和反馈

智能提示在挑战命令层禁用，不能只隐藏按钮。自动候选始终免费，默认显示；显隐和恢复不得抹去起点合法排除或已经接受的排除。

首期不开放基于答案的自动标错、单数自动识别与一键填数、答案驱动的候选高亮或自动执行推理。普通选格、同数字观察、手工标记可以保留，具体观察工具在界面阶段评审。

错误提交只给整体反馈，不逐个标记选对的候选、不显示正确结构。正确步骤可以确认已应用，不解释下一步，不开放综合关中途的答案讲解。完成整关后可查看该关解析；结束当前尝试也可查看解析。

查看解析不直接通关。本套文档建议允许重试后有效通过并继续进阶，同时保留该关曾看解析的事实，显示为解析后通过；新尝试不能擦掉已看解析事实，也不宣称独立发现。

首期建议不限重试、不设生命值、强制倒计时或零错误进阶门槛。错误提交保留已接受步骤；撤销真实步骤同时撤回该次尝试的对应目标进度。已经完成的历史通过事实不会因新尝试撤销而删除。

## 访问和广告

用户已确认：第一集免费，后续一次广告开放一集的五个专项关，Premium 直接开放。本套文档建议同一次解锁同时包含新增综合关，失败重试和继续不重复看广告。

进阶资格和访问资格分别判断。前一集未通过时不能播放下一集解锁广告；资格就绪后，免费玩家主动选择观看广告并进入，Premium 或已领取资格者直接进入。

建议广告奖励领取后形成持久的本地集访问资格，而非一次性尝试次数；不增加普通辅助钱包余额。播放前说明解锁内容，广告有效奖励事件才产生资格。取消、无奖励关闭、无填充和加载失败不解锁，也不丢失进度。

第一集、已领取集以及有效缓存 Premium 访问可离线继续。新集广告不可用时保留重试和返回；市场长期禁止广告时如何开放新集仍待产品裁决，不能悄悄绕过现有广告市场规则，也不能以假奖励开放。

建议 Premium 第一次开始某集时记录该集访问资格，撤权后已经授予的集可继续，尚未开始的集回到免费规则。此项与本地资格永久复用一起属于待确认的权益细则。Premium 对未完成的集不豁免综合考核。

## 本地表现记录

独立保存每关通过、提交次数、错误提交、是否曾看解析、接受的真实步骤、用时和每集通过事实。用时扣除暂停和广告，不等同于思考某技巧的时间。

挑战不推进普通题库首次完成、连胜、积分、三格辅助奖励或技巧成长计数。通过动作是挑战事实，可能的技巧解释是算法事实，两者分开。

首批通过本地试玩和自愿测试反馈观察进入、继续、退出、错误原因和陌生局面表现；本设计不授权上传行为、新增埋点 SDK 或恢复隐藏成长界面。

## 体验验收目标

玩家能区分依据和结论、理解整组排除与填数要求、知道为何当前不能进入下一集。有效替代路径不被判错，系统故障不消耗尝试，免费与 Premium 使用同一判题规则。

手机和平板竖屏、项目四语、大字体、读屏和减少动态效果均须验证。不得只以自动算法通过替代实际体验验收，也不得仅以广告展示量评价玩法成功。
