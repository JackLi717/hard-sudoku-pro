# 单局复盘验收记录

日期：2026-09-04。本轮为当前工作区改动；未提交、未推送，不涉及 schema、内容版本或技巧检测规则变更。

## 行为

- 历史列表与详情共同使用 `replayRecoverability` / `buildSessionReplay`。顺序允许撤销留下的序号间隔；操作间的草稿、候选模式和暂停状态不再被误判为盘面断裂。开局盘面、会话身份、严格递增的动作序号、相邻操作的数值盘面及最终保存盘面仍校验。
- 这仍是保留的有效操作路径，不是完整点击录像。每个操作提供原始操作前/后快照；未记录的候选模式、草稿和撤销点击不补造为动作。
- 数值盘面断裂或历史动作反序列化失败时，保留可验证的最终盘面。整个会话不可读时列表禁用该条记录；详情停止加载并说明不可用。不把未知用时和提示次数显示成零。
- 单步显示坐标及填数、清除、添加候选、删除候选。变化格有边框和底色；操作后显示划线删除的候选，保留至切步或切到操作前，方便观察。填数导致的自动候选清理不标作玩家删除。
- 普通填数及明确删候选自动显示解释列表；持久化提示与可能解释共用列表，并标为“当时使用”；相同的直接解释不重复显示。不授予技巧归因、独立使用或成长证据，不调用游戏写入、提示扣费或曝光路径。
- 停留在有效操作 300 毫秒后自动查直接解释，再自动补充多阶段解释；播放、拖动切步、后台及进入演练时停止分析。展示所有本次保留且验证通过的代表性路径，不做前三条 UI 截断。继承现有搜索预算：深度 5、展开 256、前沿 4096、保留容量 128、时间 30 秒；直接搜索深度为 1。界面说明深度、时间、容量、枚举不完整或验证失败等限制，并提供取消、失败和无解释状态。预算不是穷尽承诺。
- Android 工作线程和 iOS 串行后台队列通过新的 `enumerateSteps` 接口调用现有 C++ 枚举器，返回绑定完整盘面、候选及给定格的 HintStep 证明。搜索支持取消；离开、切步及后台时取消并丢弃迟到结果。不启动离线可执行文件。
- 搜索从操作前数值盘面的合法候选开始，不把未经验证的玩家笔记排除预设为正确前提。已有笔记删除所需的中间证明可由多阶段搜索寻找；预算内找不到不表示动作一定错误。同一复盘页面内缓存最近 8 个动作的解释；缓存绑定会话对象、动作对象和分析来源，离开页面后释放。
- 每阶段从独立理论快照开始，复用 `buildHintPresentation(..., 'replay')` 与原有棋盘视觉规则。未观察的中间效果有说明。结论使用现有结果文案，不出现应用或撤销指令；实战提示保留原行为。
- 演练最后一页显示“完成演练，返回第 N 步”。顶部返回及 Android 系统返回键均先退出演练，保留真实操作位置和操作前/后选择。
- 增加可拖动且支持辅助功能增减的进度条；播放可选 0.5×、1×、2×（每步 3 秒、1.5 秒、0.75 秒）。到达结尾停止，从结尾播放重新开始。控制栏固定在底部。
- 顶部只保留返回和复盘标题，步骤、动作、进度条、播放及前后切换集中在棋盘下方的固定面板中；解释列表在面板内独立滚动。棋盘大小不随结果数量变化，不缩小解释字号。速度选择、搜索限制和候选说明收进“复盘说明”。历史列表补充具体时间、用时和提示次数。新增文案覆盖四种语言。

## 验证

- Jest：覆盖有效路径、撤销序号间隔、历史降级、损坏 SQLite 动作与状态、普通动作解释、第五条结果、前后盘面、高亮、演练结束、迟到异步结果、取消、播放速度、拖动、后台暂停、系统返回和提示来源区分。
- 共享提示展示测试：39 种技巧在只读模式不使用应用/撤销指令，原游戏文案及视觉标记保持一致。
- Native 适配测试：正确解包原生 HintStep，重验生成路径，取消传递到原生。
- `npm test -- --runInBand --no-watchman`：45 个套件、886 个测试通过（上一轮完整回归）；本轮追加自动列表、后台补充、缓存与重试测试；按既有配置跳过 1 个套件/11 个测试。`npm run typecheck`、`npm run lint` 通过。
- `npm run hint:core:check`：100 局、6,166 个逻辑步骤、1,000 个随机合法状态及 39 种技巧的原有验证通过；新增枚举桥接完整性及取消检查通过。
- 使用本轮 `enumerateStepsJson` 编译临时驱动，运行 `reasoning-paths-native.test.ts` 的两个真实多阶段样本通过（约 3.2 秒、1.8 秒）；临时驱动位于 `/private/tmp/hsp-replay-review/enumerate`。
- Android `app:assembleDebug --offline`：通过，包含四种 ABI 的 C++ 和 Kotlin/Codegen 编译。使用 `adb install -r` 更新到已有的 `emulator-5554`，保留对局数据。
