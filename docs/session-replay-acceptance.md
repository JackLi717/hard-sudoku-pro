# 单局复盘首版验收记录

日期：2026-09-04。实现基线：`f9354ae` 上的未提交工作区改动。

## 已交付

- 完成页提供“本局复盘”；主屏幕直接提供“历史对局”，列出已完成、失败和放弃的对局。
- 复盘使用独立导航流程：历史选择页、单局复盘页和理论演练页不会共享同一个滚动页面。单局页有固定顶部返回栏及固定播放控制条；平板宽度采用棋盘与动作详情双栏。
- 重放从 `game_moves` 的有效动作前后快照建立只读时间线，支持开头、上一步、播放/暂停、下一步和结尾。播放在离开复盘或进入演练时停止。
- 快照链的顺序、序号和前后状态会校验。不连续、没有动作或无法反序列化的历史不会被猜测为完整复盘。
- 文案明确旧存储只能证明有效动作和候选快照：选格、自动候选清理及被标为 inactive 的动作不能可靠还原为历史点击或撤销事件。
- 对有已保存 `apply_hint` 的动作，“解释这一步”复用 `buildHintPresentation`、原有分页文案和 `SudokuBoard` 标记进行只读理论演练；不进入协调器、持久化、提示扣费或成长归因路径。
- 多阶段搜索的默认保留容量从 3 提高到 128。它仍会在报告中公开 `path_limit`，不把容量截断伪称为穷尽。
