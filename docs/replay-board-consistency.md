# 复盘棋盘显示对照与验收

范围：普通复盘还原历史盘面，沿用实际游戏的视觉规则；进入分析演示后才使用推理标记。本次仅落实以下清单，不增加新的复盘交互、历史记录字段或推理能力。

## 与游戏保持一致

| 项目 | 约定 | 验收 |
| --- | --- | --- |
| 选中数字、同数背景 | 与游戏共用普通高亮；关闭备注输入不取消已填数字的同数背景 | 已通过 |
| 选中格边框 | 使用相同边框，位置来自历史焦点，未记录则不猜测；不以“推理结果”底色替代选中状态 | 已通过 |
| 行、列、宫背景 | 普通复盘保留关联区域背景，不被操作标记覆盖 | 已通过 |
| 高亮偏好 | 使用应用当前的区域高亮、同数高亮设置，不恢复历史外观设置 | 已通过 |
| 本步操作格 | 填数保持玩家数字颜色，不额外加确定结果底色或结果符号 | 已通过 |
| 备注 | 与游戏一致：备注开关控制输入方式；已保存的当前草稿候选仍可见，不因关闭备注而隐藏；不自动生成候选 | 已通过 |
| 主题、数字、错误 | 共用当前主题、明暗模式、题目数字与玩家数字颜色，按历史错误状态显示 | 已通过 |

## 保留复盘特殊性

| 项目 | 约定 | 验收 |
| --- | --- | --- |
| 只读 | 不允许填数、删候选或自动补数 | 已通过 |
| 历史焦点 | 焦点由历史控制，不增加点击棋盘重新选格功能 | 已通过 |
| 操作过程 | 保留现有先关注、后变化的时序；删除候选保留局部删除线，不覆盖同数或关联区域背景 | 已通过 |
| 暂停 | 暂停仍可看棋盘，不采用游戏暂停遮罩 | 已通过 |
| 分析演示 | 可以使用程序候选、推理线、关注范围和讲解配色；退出恢复历史盘面 | 已通过 |
| 候选关注 | 不补建没有记录的多数字关注状态，不根据候选增删推断用户开启了候选关注功能 | 已通过 |

保持现有主动分析、开局隐藏分析详情、第 0 步无分析入口、播放和取消规则。候选来源仍取历史快照中的手动/快速草稿，不修改历史数据。
