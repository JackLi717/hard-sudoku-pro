# 过关挑战出题指南

当前三个大关十八小关为真实回放来源，具体 ID 记录于 tools/challenge-mode/manifest.json。主题用于引导观察，所有结果按唯一解统一判定；不要制作「只有某条点击路线才算对」的关卡。

## 第一大关结构

1. Hidden Single：观察数字在行、列或宫中的唯一位置。
2. Pointing：观察宫内落点共线，向宫外的线排除。
3. Claiming：观察线上落点同宫，向宫内线外排除。
4. Naked Pair：观察两格仅有相同两个候选。
5. Hidden Pair：观察两个数字仅占两格。
6. 综合：用前面技巧观察并找到可以填入的确定数字。

前五关来源应包含对应有效结构，但玩家使用其他正确方法也接受。综合关不要求隐性唯一数终点或两类排除技巧，不枚举所有路径。直接正确填数可通过；正确排除可保留并继续。

## 生成流程

从现有题库和原生回放语料挑选来源，录入稳定来源 ID，运行 challenges:build。生成器导出起点、候选与答案并运行原生来源复验及独立唯一解检查。challenges:check 复验当前内容和分配去重。需要重复生成时可使用 --corpus 指定临时回放语料、--checker 复用临时编译器输出。

每个空格候选必须保留答案，来源不能与讲解或练习等价。不可直接手改生成 JSON、数字或候选制造结构。输出替换当前开发基线，不新增内容版本、历史备份或逐实验审计目录。

## 文案

Goal 应独立写清观察主题与动作：填数，或排除至少一个候选再检查。排除专项允许直接填数作为等价完成；综合关目标为找到一个可确定数字并填入，不要求实际点击中间排除。不要声称程序证明了玩家使用某技巧。

具体模式解释放进默认折叠的 How to play。不要重复堆叠操作标签、再要求选择依据或完整排除；也不要标出答案格或预设技巧顺序。

## 后续内容

当前实现三大关：第二大关依次为 Naked Triple、Hidden Triple、X-Wing、Skyscraper、Two-String Kite；第三大关依次为 Swordfish、XY-Wing、XYZ-Wing、W-Wing、Empty Rectangle。每大关最后附综合关。第二、第三大关各以一次广告奖励解锁整组六关；第三大关结束为敬请期待。每一集沿用统一结果判定，不逐题添加特殊规则。数字置换、旋转、镜像只用于复习，不算独立新增内容。
