# Platon Sudoku：宽松免费体验与 Lifetime Premium 商业方案

更新日期：2026-10-04

状态：参数已由产品负责人确认，已接入当前源码；尚未上传、发布或完成商店真机验收。自动验证记录见[奖励验收](reward-model-acceptance.md)。历史测试包不据此推定已包含新规则。

## 1. 权威边界与长期目标

本文是奖励与商业策略的唯一产品依据，其他产品、运营和技术文档引用本文，不另设奖励表。

- 长期扩大真实使用用户群。基础游戏好玩、免费且少打扰；教学、逻辑提示与复盘是附加价值。
- 大多数玩家可以长期免费使用，少量自愿购买者和自愿广告收入支撑低成本维护。小比例购买即可维持产品和半年至一年百万用户均为待实际数据验证的假设。
- 用户增加不构成减少福利的理由，不预设达到规模后提高广告频率或收紧免费体验。
- 获客优先商店自然发现与真实体验推荐，不要求持续经营多个平台或依赖博主合作。
- 核心游戏、提示、奖励与进度本地处理；不建设账号、推荐归因、云钱包、自建后台、远程配置或新分析 SDK。
- 本轮实现奖励、相关商业入口与四语文案，Android 首先验证闭测构建；不改题库、难度、提示算法、成绩、复盘或其他页面设计。设置 → 奖励页按已确认的七日日期条设计实现，其他页面布局保持原样。

## 2. 已确认规则

| 项目 | 免费玩家 | Lifetime Premium |
| --- | --- | --- |
| 基础游戏与手动笔记 | 长期免费，无自动广告 | 同样可用 |
| 快速候选（自动笔记） | 首次生成与确认重新生成均免费无限；显示、隐藏、恢复和人工编辑免费 | 同样免费，不作为独占权益 |
| 安装赠送 | 首次安装初始化 5 次提示，另加首日登录 3 次，首日合计 8 次；更新不重复送安装礼包 | 不额外补钱包 |
| 每日连续奖励 | 按手机本地日期，每日首次打开自动领取；第 1–7 天为 `3、3、5、5、5、10、10`；七天循环，漏一天从第 1 天重来 | 不领取次数奖励 |
| 提示使用 | 每条首次展示的有效提示消费 1 次；已有余额保存并可离线使用 | 永久无限，不扣免费钱包 |
| 余额上限 | 99；每日奖励只发剩余空间，超出部分不保留、不补发；满仓当天仍算连续登录 | 不需要补给 |
| 完成补给 | 保留：三道不同新题首次完成填满三格，提示 +1；重玩不推进；满仓不补发 | 不补钱包 |
| 自愿广告 | 每个有效激励奖励事件提示 +5；保留设置、耗尽和完成页入口，不设每日广告上限；完成页同一局只领一次 | 不请求或展示广告 |
| 自动广告 | 开局、继续、游戏中、完成后均不自动插入 | 无 |
| 分享奖励 | 暂缓邀请奖励、七天无限、归因与防刷后台；普通下载链接分享不附加奖励 | 无额外权益 |
| 购买 | 自愿一次性购买永久无限提示与无广告，无订阅 | 永久权益 |

奖励是增加余额，不是补到某个数值，也不是每次启动发放。七天合计 41 次。中断只重置连续天数，不扣已领取余额。

快速候选继续保持草稿、人工编辑、覆盖确认和恢复边界，不自动覆盖笔记。无次数徽标、耗尽或广告补充流程；操作统计与成绩规则保持原样。底层保留旧快速候选钱包记录以免动到现有存档，但不再发放、消费或在商业界面展示。

## 3. 本地日期、幂等和展示边界

- 日期取手机当地年月日，不要求联网或账号。首次启动、回到前台和前台跨午夜均尝试领取。
- 连续日期按日历比较，跨月、跨年与夏令时不按 24 小时推算；相邻一天接续，超过一天重新开始。
- 已领取日期与最近日期同余额、流水原子保存。重复启动、前台恢复和重试不重复发奖；日期回退到最近已领日期或以前不再次发放。跨时区按当时本地日期适用同一规则，不承诺防改时钟或防破解。
- 每日记录保存日期、周期第几天、应发与实发数量。设置 → 奖励页只显示余额数字、今日实发与当前周期的七个日期，标题为“连续登录 7 天奖励”；日期条展示计划数量，已领取日期保留实际到账事实。零到账也显示“今日到账 +0 次”；满仓、部分到账与溢出不补发的详细说明收进奖励规则。漏签后显示新周期，既有余额保留。
- 返回“设置”单独一行，“奖励”标题放在下方。主页面不显示可用提示标签、上限说明、日期范围、明日预测、完成奖励介绍、广告区域标题或介绍；完成新题只保留标题、三格与进度，广告只留“观看广告 · +5”按钮。快速候选免费无限、安装赠送、连续登录、完成补给、广告与容量规则均在折叠的奖励规则中查看，细主题色边框、12pt 圆角的 Premium 按钮放在奖励规则上方。
- 日期条读取现有本地记录，不新增领取按钮或自动奖励弹窗；读取中不编造领取结果，手机日期回退时显示简短状态。广告仅在点击按钮时由播放流程检查可用性，处理期间在按钮内显示状态并防止重复点击；不可用、关闭或失败后直接结束并恢复按钮，不显示额外状态、结果文字或重新检查入口。成功后直接更新余额，余额超过 94 不提供广告入口。
- 免费页支持中、英、日、德四语与浅深色主题；放大字体时日期条换为两行。Premium 页显示无限提示及真实权益来源，区分永久、闭测临时与审核临时，不显示每日补给或广告。
- Premium 期间不补钱包、不补签到；恢复免费时只领当日，按最近实际免费领取日决定接续或重启，不追补过去。

## 4. 提示和广告

- 有效结构化提示首次展示时消费 1 次；同一提示的推理、应用和重复读取不再次收费。修改棋盘后新提示仍消费一次。
- 冲突、错误、已完成棋局、计算失败或无有效步骤不消费。首次展示后关闭算使用，应用后撤销不退额度；不自动连续解题。
- 每次广告前明确说明“观看广告，获得 5 次智能提示”。余额超过 94 时不提供广告；暂停游戏并结算待保存操作后再检查空间，避免完成奖励挤占承诺空间。广告期间不发日补给，广告结束后再尝试领取。
- 只凭 SDK 有效奖励事件入账；展示、关闭、点击素材或安装广告主产品不能代替奖励条件。有效事件和钱包流水同事务保存、重复回调不重发。
- 奖励与后续消费分别保存。领取后取消提示、计算失败或随后断网不撤销所得。
- 加载失败、无填充、提前关闭、拒绝同意或离线不入账，不阻断基础游戏或免费快速候选。
- 广告、商店购买、恢复和必要隐私处理可能联网，不宣传“完全离线且无广告”。卸载或清除本地数据不保证余额恢复，不因此增加后台。
- 保持标准激励、UMP、地区限制、平台验证与 SDK 隔离；详见[商业 SDK 边界](commercial-sdk-boundary.md)。广告平台与商店实测仍须独立验收。

## 5. 长期承诺与隐私文档

- 已购买永久权益、已承诺永久码和已领取提示继续兑现。不因用户增加降低福利，不突然扣减或给已领余额增加有效期。
- 当前不设奖励政策期限或自动截止；无需在隐私政策里写奖励降额或经营调整权。具体奖励写在奖励说明，隐私文档只披露本地余额、奖励日期、连续日数与数据处理事实。
- 未来若确需调整赠送规则，提前简明说明数量、生效日和已领权益保护；约 30 天通知为体验建议，并非法定期限。若公开期限活动，兑现承诺期并在替代安排明确前沿用规则，不自动关闭福利。
- 购买、恢复和交易刷新只更新真实权益，不伪造购买或补钱包。退款／撤销恢复已保存免费余额，不追扣历史使用，不追补 Premium 期间奖励。

## 6. 测试者策略

- 普通闭测使用**临时 Premium**：不限智能提示、无广告；与真实商店交易、审核访问分开，不写入永久购买表，不显示已购买永久权益。
- Android `npm run android:bundle:closed-beta` 显式设置 `HSP_CLOSED_BETA_PREMIUM=1`。普通公开构建默认关闭，离开闭测后按照免费规则或真实已购权益运行；已有钱包不清空。
- 原一次性最低余额 20 的闭测补贴停止发放，已获得提示保留；不把旧补贴反复补发。
- 已对外承诺永久码的测试者继续兑现原承诺；本轮不扩大新批次永久码承诺，也不自动伪造商店兑换。真实码仍按商店可用能力安排。
- 免费规则在公开配置、本地测试及专项许可账号中单独验收，临时 Premium 不替代免费路径验证。真实购买、恢复、离线缓存与退款另外验证。
- 测试回报与评分、正面评论或推荐分离；负面反馈同样有价值。不新增分析采集，使用平台现有数据和自愿问卷。
