# Hard Sudoku Pro：单局积分规则

## 1. 目的与边界

单局积分用于在完成数独后提供明确的成就反馈，并让同一难度等级内题目的实际差异反映到结果中。它是每次完成记录的一部分，不是金币、经验值、可消费余额或累计钱包；首版也不建立排行榜。

积分只在盘面合法完成并成功写入完成记录时结算。失败、主动结束和未完成对局没有积分。重复完成同一道题仍会得到该次对局的积分，但不会因此重复获得“首次完成”补给。

## 2. 总公式

```text
r = clamp(
  ln(difficulty_score / reference_min[level])
  / ln(reference_max[level] / reference_min[level]),
  0,
  1
)

base_score = round_to_10(midpoint[level] × (0.75 + 0.50 × r))
no_mistake_bonus = error_count == 0 ? round_to_10(base_score × 5%) : 0
no_hint_bonus = hint_use_count == 0 ? round_to_10(base_score × 5%) : 0

total_score = base_score + no_mistake_bonus + no_hint_bonus
```

其中：

- `difficulty_score` 是题库已有的固定人类解题负担分，只在同一等级内比较。
- `round_to_10` 表示四舍五入到最接近的 10 分。
- `clamp` 把结果限制在 `0–1`；超出当前参考范围的题目不会突破该等级的基础分上下限。
- 对数映射会压缩极端高难题的原始分差，避免少量异常高值支配整个积分范围。

## 3. 固定等级参数

| 等级 | 中点 | 固定原始分参考范围 | 基础分范围 | 完美完成最高分 |
| --- | ---: | ---: | ---: | ---: |
| Level 1 | 1,000 | 446–732 | 750–1,250 | 1,370 |
| Level 2 | 2,000 | 2,394–11,175 | 1,500–2,500 | 2,760 |
| Level 3 | 4,000 | 3,453–10,717 | 3,000–5,000 | 5,500 |
| Level 4 | 8,000 | 4,467–22,648 | 6,000–10,000 | 11,000 |
| Level 5 | 16,000 | 5,664–54,684 | 12,000–20,000 | 22,000 |

这些参考值是积分政策常量，不在运行时按当前题库重新统计。因此题库增删不会改变已经结算的积分，也不会让同一道题在不同日期因题库分布变化而得到不同基础分。公开版本冻结后，如需改变参数，必须作为新的积分政策明确评审，而不能静默重算历史记录。

## 4. 行为因素

首版只保留两个幅度克制、容易解释的完成质量奖励：

- 零错误：基础分 `+5%`。
- 未使用智能提示：基础分 `+5%`。

两项可以叠加；考虑到每项分别取整到 10 分，结果约为基础分的 `110%`。以下因素不改变积分：

- 完成时间；速度不应压过严谨推理，也不鼓励为了积分仓促输入。
- 快速候选；它已有独立的可用次数机制。
- 系统允许的简单尾盘自动完成；它不改变题目的基础难度，也不视为智能提示。
- 是否首次完成；首次完成只影响补给，不改变同样表现下的单局积分。

## 5. 结算、保存与展示

积分与完成记录、首次完成奖励和额度流水在同一个 SQLite 事务中结算，并使用同一游戏事件保证幂等：重复提交同一完成事件必须返回原积分，不能再次生成或叠加。

每条已完成的 `game_attempts` 保存最终总分；结算结果同时保留基础分、零错误奖励和无提示奖励，供完成页解释。失败和主动结束记录的分数为 `NULL`。

玩家界面：

- 完成页在用时、错误和提示之前突出显示本局总分，并列出本次实际获得的奖励项。
- Replay 历史列表在已完成对局摘要中显示该局总分。
- 游戏进行页不实时累计分数，避免玩家逐格刷分或被即时数字打断推理。
- 首版不显示累计总分、积分余额、排行榜或可兑换用途。

## 6. 验收要求

- 同等级中，原始难度分更高的题目基础分不得更低。
- 任意题目的基础分都必须落在该等级的固定范围内。
- 零错误和无提示奖励分别独立计算并四舍五入到 10 分。
- 用时、快速候选次数、首次/重复完成不得改变相同题目和相同行为质量下的积分。
- 完成事件重试、App 重启和 Replay 历史读取必须得到相同的已保存积分。
- 失败、主动结束和未完成对局不得产生积分。
