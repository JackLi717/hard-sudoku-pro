Hint Lab 提供了可复用的证明讲解基础。无验收状态的讲解播放器已提取，正式教学产品仍需新增课程目录、教学组织和学习记录；Hint Lab 继续作为内部质量工具，共用播放器而保留独立验收外层。

本方案将需要调整的部分整理为产品流程、模块任务和分阶段验收清单。全部讲解免费、三种用途题目独立是已确认规则；播放器和课程资源契约以当前实现和下文说明为准，阅读完成方式和后续阶段划分仍是实施建议。正式上线入口尚未接入。

## 共享播放器实施

用户已明确本次只提取共享播放器并接回 Hint Lab。实现包括只读快照适配、盘面与讲解布局、图例、步骤按钮及目标选择回调；例题目录、来源、验收清单、备注和验收存储继续由 Hint Lab 管理。未增加课程目录、学习数据库、正式首页入口、练习或挑战功能。

[HintWalkthroughPlayer.tsx](../src/ui/components/HintWalkthroughPlayer.tsx) 已成为共享实现。Hint Lab 用原题 givens、当前值、当前候选和证明构建快照，不再为页面播放创建临时 GameSession；原有 createHintLabSession 辅助函数继续服务既有领域测试。

| 已实现契约 | 归属与行为 |
| --- | --- |
| HintWalkthroughSnapshot | 调用方提供已验证的不可变 id、values、givens、candidateMasks、step；不包含答案、会话或验收记录 |
| presentation | 调用方用同一快照及所选目标构建页面，播放器展示对应正文和视觉，不另行检测技巧 |
| pageIndex 与 onPageChange | 调用方持有唯一页码；播放器请求上一步、下一步或回到第一页；换例时由调用方同步重置 |
| targets 与 onSelectTarget | 仅转发允许目标的点击；调用方更新目标、重建证明及决定页码，播放器不修改盘面 |
| labels 与 proofSupplement | 调用方提供步骤和按钮文案，以及可选说明；保留当前 Lab 的文字，后续课程自行提供本地化内容 |
| renderHeader 与 renderFooter | 调用方提供课程或验收外层，播放器按现有布局放置，不读取或保存外层状态 |
| 布局与棋盘状态 | 播放器管理测量和只读棋盘展示适配，保留现有竖屏及遗留横屏布局，不改变原生方向配置 |

播放器不接受 GameSession，不调用对局命令，不导入 Lab 目录或验收存储。无有效证明页属于调用契约错误，不能自动退回占位页。播放器沿用现有 buildHintPresentation；正式课程适配由下文独立课程资源模块提供，不改变 Lab、普通提示或复盘的证明语义。

## 产品关系和阅读流程

Hint Lab 是讲解播放器加内部验收外层，正式教学是同一个播放器加课程外层和学习记录。两者共享盘面与证明演示能力，分别管理验收状态和阅读状态。课程目录不展示实验目录，教学完成也不改变 Lab 的验收结论。

正式阅读流程为技巧目录、技巧介绍、分步盘面讲解、要点回顾，最后由玩家选择返回目录或进入专项练习。课程全程免费，不用广告、Premium 或答题成绩解锁阅读。

| 页面或阶段 | 玩家需要完成的事情 | 页面需要提供的内容 |
| --- | --- | --- |
| 技巧目录 | 找到想学的技巧，继续上次阅读 | 技巧名称、用途、前置知识、阅读状态和继续入口；只展示已发布课程 |
| 技巧介绍 | 了解何时使用、从哪里观察 | 学习目标、观察对象和必要前置概念 |
| 分步盘面讲解 | 看清条件如何推出结论 | 固定盘面、完整候选、分步正文、高亮、上一步、下一步和重播 |
| 要点回顾 | 记住识别方法和容易看错的条件 | 判断要点、常见误区、返回目录和专项练习入口 |

阅读不设置正确答案门槛。建议只有玩家到达回顾并主动完成阅读时才记为看完；提前退出保存当前位置，重播不清除既有看完记录。看完表示阅读完成，不生成掌握分数，也不替代练习与挑战成绩。具体完成事件在学习状态契约中冻结。

## 共享播放器

共享组件为 src/ui/components/HintWalkthroughPlayer.tsx，已实现契约见共享播放器实施。组件接受只读起点、HintPresentation、当前页码、可选证明目标及导航回调，负责棋盘、正文、图例、页码切换和重播。

播放器不依赖 HintLabFixture、HintLabStore、学习数据库、广告、购买、普通钱包或挑战完成。它不打开数据库、不发奖励、不调用普通游戏完成，也不把临时标记写入真实棋局。

内部结构为 Hint Lab 外层加共享播放器，正式结构为课程外层加同一个播放器。前者管理实验筛选和验收，后者管理课程、阅读位置和练习导航。普通游戏提示继续使用原有表现构建器，不要求同时改造整页。

继续复用 buildHintPresentation 和教学构建器，其 mode 保持 game 与 replay。课程通过独立 buildLessonPresentation 适配器使用 replay 的阅读语义，不提供应用真实游戏动作的文案；无需新增一个未经定义的 lesson 字符串。

缺少证明、候选或必要数据时，正式课程构建应失败，不能以通用占位页发布。保留逐步揭示、临时假设、冲突和结论语义，组件提取不改变技巧标准。

## 正式课程内容

现行 EncodedLesson 包含 lesson_id、technique_code、prerequisite_techniques、四语 texts 和精选 example。example 包含稳定 ID、来源身份、原题和当前盘面指纹、候选基础及完整证明。读取后转换为 LessonSummary 或 LessonContent，课程页面只消费本语言的介绍与不可变快照，具体字段见课程契约。

已有证明页承担观察、条件、推理和结论。新增课程章节包围这些页面，不手工重写另一份逐坐标证明脚本；需要棋盘演示的易错案例同样由工具生成和验证。

正式产品只发布准备好的技巧子集，每种技巧先选清楚的主例。内部 Lab 可以质检三种用途素材；素材正式发布前须分配唯一用途并通过跨池检查。选为讲解的原题、等价来源和其他回放阶段不能再成为练习或挑战。

课程资源由生成器按课程清单导出，运行时通过正式仓储读取。不能直接 import 全部 debug JSON，正式课程加载器不要求全部 40 项都存在，也不把完整答案和验收字段送给课程界面。

## 学习记录和正式外层

LessonController 建议管理载入、章节、证明页码、重播、退出恢复和看完事实，记录放在 user.sqlite 的独立学习数据中。不把验收 passed 或 proof_page 解释成用户学习进度。

看完只表示阅读完成。换例清空旧例的假设与目标；切换功能只传导航标识，不传盘面、解析或完成事实。结束后的练习入口加载另一道独立题，不能直接把演示改成作答。

正式外层增加技巧目录、用途说明、返回恢复、免费展示、四语控件与读屏名称。手机和平板采用竖屏，正文滚动时关键盘面仍可观察；保留已有 landscape 代码和测试，不启用横屏。

## 落地顺序

| 阶段 | 具体交付物 | 依赖和完成门槛 |
| --- | --- | --- |
| 一 定义契约 | 播放器输入与回调、课程结构、阅读状态及完成事件、内容拒绝条件 | 明确数据与状态归属，不依赖具体正式题目即可描述阅读及恢复 |
| 二 提取播放器 | Hint Lab 使用共享播放器，原验收外层继续保留 | 契约已定；原选例、页码、目标切换和证明表现不回退 |
| 三 接入正式内容 | 课程清单、生成导出、只读课程仓储和来源检查 | 播放器可用；少量课程可载入，错误资源与跨用途冲突不能发布 |
| 四 完成课程外层 | 目录、介绍、证明、回顾、独立学习存储和恢复 | 课程结构稳定；阅读免费，退出可恢复，验收记录与普通成绩不受影响 |
| 五 内部完整验证 | 少量代表素材完成进入、阅读、退出、恢复、看完流程 | 四语和竖屏可用，正式资源边界已验证；练习未交付时不显示失效入口 |
| 六 准备公开交付 | 正式课程内容、每技巧三至五道独立免费练习、可用的练习导航 | 内容和体验验收通过；首批技巧与数量、入口位置和发行范围另行明确 |

播放器原型可用内部素材，不提前指定为第一集或正式课程。内容生产按总览的契约和机制门槛推进，不先批量开发全部课程。

练习与挑战仍需要提交、证据、目标、持久化和广告机制，不能通过给讲解播放器加一个提交按钮获得。

只读讲解原型不需要等待完整挑战状态图和广告机制完成；公开交付仍需满足已确认的免费练习配置。教学播放器验证通过，也不代表练习或挑战判题机制已经通过。

内容工具可以复用现有回放和证明检查能力，但正式资源导出与 Lab 全目录导出应有明确入口。删除 debug 依赖前须追踪实际引用，不能删除共享技巧文案、证明构建器或正常游戏需要的内容。

播放器状态归属也需在契约中明确：外层控制页码和目标，播放器展示并发出操作回调，避免播放器与控制器分别维护两份阅读位置。构建数据、验收记录、学习记录和普通对局分别保管，不能用同一个状态字段兼任。
