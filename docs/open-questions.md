| D-002 | 设备范围 | 首期正式面向 iPhone 和 Android 手机，只支持竖屏 |
| D-003 | 市场对齐 | Oakever 为主基准，Sudoku.com 为大众操作基准，Andoku 3 与 Good Sudoku 为提示专项基准 |
| D-004 | 源码与资产 | 商业闭源；第三方许可证单独保留；不复制参考产品代码、图标、文案或品牌资产 |
| D-005 | 平台一致性 | 核心数独行为一致，返回、弹窗、购买、隐私和无障碍遵循平台惯例 |
| D-006 | 阶段0工具链 | Node 24.20.0、Xcode 26.6、CocoaPods 1.17.0；iOS 与 Android Debug 构建均已验证 |
| D-007 | SQLite 运行时 | 使用 MIT 的 Nitro SQLite 9.7.0；内容库由自有 TurboModule 校验 SHA-256 后原子复制，用户库只通过数据层异步事务访问 |
| D-008 | 阶段4视觉基线 | 使用原创暖中性色/绿色视觉、系统字体和无外部资产的工具标记；阶段6再完成主题、正式图标和全量无障碍审计 |
| D-009 | npm 审计处置 | 不以破坏性强制降级修复当前仅位于构建工具链或未使用代码路径的告警；发行候选前复核上游修复和实际可达性 |
| D-010 | 阶段5提示体验 | `HintStep v1` 保持原子领域契约；C++ 输出结构化解释参数，客户端从39项类型安全源模板生成观察、推理、应用三阶段页面；四语翻译在阶段6完成 |
| D-011 | 游戏交互持久化边界 | 单元格选择属于瞬时展示状态，同步更新且不占用全局 `busy`、不单独增加持久化 revision；数字、候选、提示、暂停和后台操作继续以事务保存，下一次持久化会包含当前选择 |
| D-012 | 未来技巧扩展边界 | 当前版本保持 `hsp-1.2` 的 39 项技巧；ALS 家族、Sue de Coq、高级鱼类和更多唯一性变体仅作为未来升级参考，须由新内容、专家教学或真实用户需求重新触发立项 |
| D-013 | 技巧成长产品方向 | 将 39 项技巧的本地成长档案、成长曲线和“待探索、正在成长、已掌握、待巩固”生命周期提升为当前版本下一项重要产品能力；正常游戏仍是主体，课程、考试、云同步和群体比较不进入首轮范围 |
| D-014 | 首版开发期版本策略 | 当前处于首次公开发行前开发期，只维护一个当前 schema、协议、题库和算法基线；保留稳定 ID、序列化及 migration 入口，但不为未发行的每次内部变化增加版本或兼容分支。首个发行候选冻结公开基线，发行后再执行版本递增与迁移兼容；进入第二版前必须更新 `AGENTS.md` 的发行状态 |
| D-015 | 技巧覆盖与补题顺序 | 不在技巧成长开发前随机扩充题库；先对现有 10,000 题建立评级路径和 HSP 运行时路径覆盖、反向索引及任意/全部技巧组合检索，再区分题目不足与 `nextStep()` 选择遮蔽。只对确认缺口定向生成、运行时复现、去重和人工验收，并一次性合入首个公开内容基线 |
