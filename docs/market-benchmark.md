# Hard Sudoku Pro：市场产品对齐基准

## 1. 目的

本文档固定首期产品的市场对齐依据。成熟数独产品已经形成通用行为时，Hard Sudoku Pro 默认采用该行为，不因开发便利创造新的操作方式。参考对象只用于确认功能、信息层级和交互习惯；项目必须使用自己的代码、品牌、图标、文案和视觉资产。

产品行为出现冲突时，按“主基准优先、专项基准只解决专项问题、已确认产品规则高于参考产品”的顺序处理。任何没有依据的差异先记录到 `docs/open-questions.md`，确认后才能实现。

## 3. 已确认的对齐矩阵

| 功能 | 市场通用行为 | Hard Sudoku Pro 决策 |
| --- | --- | --- |
| 游戏入口 | 首页突出继续或选择难度开始 | 只保留继续、新游戏、统计、设置和 Premium |
| 棋盘选择 | 高亮当前格、同行、同列、同宫及相同数字 | 保留，并增加非颜色状态区分 |
| 数字输入 | 选格优先为默认，数字优先为可选设置 | 保留两种方式，不增加新的输入模式 |
| 工具栏 | 撤销、擦除、备注/铅笔、辅助提示 | 固定为“撤销、擦除、快速铅笔、铅笔、智能提示” |
| 铅笔 | 候选数固定在格内九宫位置，再次点击删除 | 手工草稿免费编辑，候选数不校验答案 |
| 快速铅笔 | 一次补全当前合法候选数，之后允许继续编辑 | 与手工草稿独立；盘面变化后重新生成需确认和额度 |
| 撤销 | 撤销最近一次有效棋盘操作 | 完整保存并在退出后恢复；首期不提供重做 |
| 错误 | 可选择即时检查，错误数字保留并突出显示 | 默认自动检查；错误数字保留并标红 |
| 自动保存 | 离开后继续未完成题目 | 全局只允许一局未完成游戏，每次有效操作后保存 |
| 智能提示 | 从观察方向逐步揭示技巧与结果 | 每次只处理一个最简单原子逻辑步骤，最后由用户应用 |
| 统计 | 按难度统计完成、时间和错误 | 只显示本地真实统计，不提供全球百分位 |
| 广告 | 在自然流程边界展示，奖励广告由用户触发 | 自动插屏仅在开始/继续后；棋盘中间不自动展示广告 |

详细规则以 `docs/game-feature-plan.md` 为准，本表只用于追踪市场依据，不能替代验收规则。

## 4. 对齐工作方式

开发一个用户可见行为前，必须依次检查：

1. 产品文档是否已经定义。
2. 主基准产品是否已有成熟行为。
3. 专项基准是否提供更明确的同类行为。
4. iOS 和 Android 是否存在必须遵循的平台差异。
5. 如果仍不明确，停止该项并写入问题台账。

允许偏离市场基准的原因仅包括：已经确认的产品定位、离线限制、无障碍、隐私或平台审核要求。差异必须记录原因和验收方式。
