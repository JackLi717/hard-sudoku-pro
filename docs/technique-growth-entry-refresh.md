# 成长入口与本局足迹：视觉推广

2026-09-04。基于已提交的 `ba5b9df`，沿用用户认可的技巧总览与详情设计。本轮不提交或推送，先体验效果。

## 展示调整

- 首页：紧凑的技巧图形、标题、最近一条真实记录的技巧名和来源短标签。入口仍在开始/继续、历史对局之后，不使用分数、进度环或奖杯。
- 完成页：突出本局一条有依据的经历和「查看全部足迹」。展示优先级为已有应用记录、已有学习记录、可能解释，同类取活动时间最近的一条；这是展示选取，不改变归因准入和计数。下一局、选择难度、完整复盘仍保留原位置和行为。
- 本局足迹：一条真实记录的操作前棋盘与回看入口；全部记录以单列可展开列表展示。学习接触、应用记录、值得回看筛选保留，列表分批加载，未知与相关收尾也可访问。
- 提示显示「当时查看提示」或「提示辅助」，可能解释直接标注。归因理由、替代解释、实际活动时间和源对局时间按需展开。无记录、整理中、证据缺失、失败分别呈现；无预览时不造棋盘，完整复盘仍可访问。

足迹进入技巧详情或原复盘时保持挂载，保留筛选、分页、展开项和原滚动位置。重新整理数据不会强制滚动；明确点击「预览这条记录」才回到顶部。预览仅调用已有只读回放源，稳定引用改变才重读，并忽略过期异步响应。进行中对局仍不开放技巧复盘。

## 保持的边界

应用层、投影器、成长统计、事件序列化、数据库、提示/复盘分析、归因准入、奖励和轻反馈实现均未修改。首页/完成页仍通过原 `GrowthSummary` 接口接入，设置开关沿用原路由判断。已认可的总览/详情布局不变，未新增动画、课程、依赖或持久化版本。

新增展示主要文字保持16–32逻辑单位，按钮至少48，展开行至少64。记录名自动换行，大字时棋盘与操作纵向排列；装饰图形不进入读屏焦点，真实棋盘提供步骤说明，按钮提供选中/展开语义。未宣称完成实体设备的 VoiceOver/TalkBack 全流程。

## 验收方法与产物

目录：`.local/behavior-regression/growth-entry-refresh-20260904/`。

原 Android 与 iPad Mini 保存了首页、足迹页改版前画面。期间原模拟器仍被用户使用，因此额外创建独立 iPad Mini 验收实例，并启动只读 Pixel 4a Android 实例，避免打断原设备或修改其数据。

独立实例使用同一份从 iPad 用户数据库只读导出的10局原始投影、状态、move和event，通过现有反序列化与回放适配器呈现。Saved 是原记录；Hint/Possible 是筛选出的真实记录；Empty/Pending/Failed 是明确构造的展示状态。完成页使用原完成对局快照，不执行完成命令、不发奖励。截图顶端的 QA 栏属于临时验收入口，正式应用没有此栏。

`*-before-*-saved.png` 与 `*-after-*-saved.png` 在相同设备、数据与语言下比较；旧组件来自 `ba5b9df`。`*-after-footprint-hint/possible/empty/pending/failed.png` 为明确标注的边界状态样例。设备截图用于视觉检查，返回位置与异步更新同时由组件交互测试覆盖。

临时入口、旧组件副本与导出数据在验收后移出产品源码，仅保存于忽略的本地产物目录。正式体验入口：

- 首页 → 我的技巧。
- 历史对局 → 任一对局的本局技巧足迹。
- 正常完成一局 → 本局值得回看 → 查看全部足迹（遵循完成页摘要设置）。
