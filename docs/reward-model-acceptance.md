# 免费辅助钱包与 Premium 无限权益验收

更新日期：2026-10-02

## 当前规则

- 正式免费初始额度为智能提示 `5` 次、快速候选 `3` 次；两项持有上限各 `99` 次。Android 封闭测试包用 `npm run android:bundle:closed-beta` 构建，临时一次性将智能提示补至至少 `20` 次；普通 Release 构建的补贴参数默认为 `0`，不再启用无限提示。
- 每次有效智能提示消费 `1` 次；快速候选首次生成或确认覆盖后重新生成消费 `1` 次。无效请求不消费。
- 每道新题首次合法完成使智能提示奖励进度增加一格。进度到三格时自动兑换智能提示 `+1`，然后归零。重玩同一道题、失败和放弃不增加进度；首次完成不再给快速候选次数。
- 奖励页和辅助不足入口的标准激励广告为所选资源 `+1`。每个合法完成的对局另有一次可选广告，固定给智能提示 `+1`、快速候选 `+1`；重玩同题的新对局可另看一次，重新打开同一结果页不可重复领取。
- 两项奖励在播放前明确显示，只有 SDK 有效奖励事件后才入账。任一资源已满、广告不可用或 Premium 生效时不提供通关广告。
- Lifetime Premium 无限使用两项辅助，无广告、无次数奖励。购买前的免费钱包和三格进度保留并冻结；权益撤销后恢复使用，不追补 Premium 期间的完成奖励。

完整产品规则见 [Premium 辅助设计](premium-reward-design.md)。

## 必须验证的行为

1. 免费用户连续首次完成三道不同新题时，进度依次为 `1/3`、`2/3`、`0/3`，只在第三次增加智能提示 `1` 次，快速候选不因通关增加。同一道题重玩不能推进进度。进度和额度在重启、数据库重开和完成事件重试后保持一致。
2. 三格兑换、首次完成标记、钱包、流水、成绩和完成结果在同一个 SQLite 事务里结算。达到 `99` 时只显示实际入账；失败事务不得留下部分进度或奖励。
3. 完成页广告只在合法完成后提供，并在播放前说明两项各 `+1`。同一已完成对局只能领取一次；有效奖励回调后两项和领取标记在一个事务里保存。重复回调、重新打开结果页和重复点击不能再加次数。
4. 普通广告仍只给用户选择的一项 `+1`，不受完成页双项奖励影响。提前关闭、无填充、断网、拒绝或播放失败不入账，也不阻断手动游戏。
5. Premium 不展示三格进度、库存和广告；两项辅助不扣钱包。购买和恢复购买不补额度；权益撤销后恢复购买前的免费进度。
6. Android 封闭测试用户仅一次补到至少 `20` 次智能提示；已有更高余额不减少，重启不重复补给。公开发布构建不设置封闭测试额度参数，并以正式 `5` 次初始额度验证。
7. 四语界面、屏幕阅读器标签和结果页均准确区分通关进度、自动到账以及自愿广告奖励；手机和平板竖屏布局均可阅读。
