# 自有盘面录入与 PDF 打印规划

状态：规划已保存，择机开发，尚未进入开发排期。

记录日期：2026-10-02。

本文保存自有数独录入、PDF 导出与打印的产品规划。两项功能均面向免费用户和 Premium 用户：免费用户在最终保存或输出前主动观看激励广告，Premium 用户直接执行。本文不改变当前首发范围，不授权立即修改代码、数据结构或商业化配置。

## 产品目标与建议优先级

自有盘面录入让玩家把书籍、报纸或其他来源的经典 9×9 数独带进 App，使用现有棋盘、候选数、逻辑提示和复盘能力。PDF 与打印让玩家把题目或当前进度带到纸上继续解题。

建议优先完善自有盘面录入，再加入单题 PDF 与系统打印。录入功能更直接体现现有逻辑提示和复盘的价值，打印适合作为配套能力。该优先级是产品建议，尚未形成排期；对使用频率和购买转化的影响仍需实际验证。

## 已确认的使用权限与广告交互

以下规则来自本次产品讨论，未来实现应以此为基础：

- 免费用户可以使用两项功能，正式保存、导出或打印前需要观看激励广告。
- Premium 用户直接保存、导出或打印，不播放广告。
- 录入过程中不播放广告。点击保存后，先检查盘面；检查通过才进入广告流程。未取得广告奖励，不正式保存题目。
- 预览和调整输出内容时不播放广告。用户完成预览、点击最终导出或打印按钮后，才进入广告流程。未取得广告奖励，不输出文档。
- 用按钮上的 `AD` 标记轻量提示广告要求，不增加二次确认弹窗。
- 用户点击明确标记广告的操作按钮，即主动选择观看本次广告；不自动连续播放广告。

### 按钮与说明文案

| 使用身份 | 保存按钮 | PDF 按钮 | 打印按钮 |
| --- | --- | --- | --- |
| 免费用户 | 保存 · AD | 导出 PDF · AD | 打印 · AD |
| Premium 用户 | 保存 | 导出 PDF | 打印 |

建议在按钮附近增加一行简短说明，补充 `AD` 的含义：录入页使用“完成观看广告后保存这道题”，输出预览页使用“完成观看广告后输出本次文档”。这些是待视觉设计时细化的文案建议，不另设确认弹窗。读屏名称建议使用“观看广告并保存”“观看广告并导出 PDF”“观看广告并打印”。

AdMob 要求展示前清楚说明用户需要完成的动作与获得的奖励，并由用户主动选择。官方允许清楚、无歧义的图标说明，没有要求必须使用确认弹窗；单独的 `AD` 标记不应被当作自动满足全部要求的保证。依据见 [AdMob 激励广告政策](https://support.google.com/admob/answer/7313578?hl=en-GB)。正式实现时应结合最终按钮、周边说明与本地化重新核对。

## 自有盘面录入方案

### 使用场景与建议范围

建议支持从头录入一道题，以及录入原题后补充玩家已经填写的进度。原题给定数字与玩家填写数字必须分开：原题条件在游戏中锁定，玩家填写数字仍可编辑和检查。把已填数字都当作给定数字，会把玩家的错误变成题目条件。

第一批建议只支持经典 9×9 数独，通过手动录入和常见 81 位题目字符串粘贴完成输入。拍照识别、图片识别和数独变体留作后续候选，不随本规划自动进入开发范围。

建议的保存流程：

1. 录入原题，可选地补录已有进度。
2. 点击保存按钮；免费用户按钮带 `AD` 标记。
3. 检查原题格式、冲突、可解性与唯一性，并单独检查玩家已填进度。
4. 检查不通过时留在编辑页指出问题，不播放广告。
5. 检查通过后，Premium 直接保存；免费用户播放本次激励广告。
6. 取得广告奖励后自动完成保存，不再要求用户重复点击。

题目检查建议采用以下处理：

| 结果 | 建议处理 |
| --- | --- |
| 原题冲突或无解 | 引导检查录入，保留内容，不播放广告 |
| 原题存在多个解 | 提示可能漏录数字，第一批暂不进入普通游戏 |
| 原题有唯一解，但玩家已填数字错误 | 指出已有进度的问题，允许修改或清除，不把错误进度当成原题条件 |
| 原题有唯一解，但超出现有逻辑提示能力 | 允许手动玩，明确提示可能无法覆盖完整解题过程 |

外部题不经过发行题库的筛选，不能承诺任意题目都能用现有技巧逐步讲解；也不能为了兑现该承诺而加入猜测或回溯提示。

### 草稿与保存后的使用

建议把“未看完不保存”定义为不加入正式的“我的题目”，但保留本地录入草稿。退出、广告取消或播放失败时，用户可以回来继续，不丢失输入。

建议提供轻量的“我的题目”列表，支持继续、重玩、重命名和删除。一次保存广告解锁一题入库，之后继续游戏、自动保存进度、改名称和重玩不重复要求保存广告；新增另一道题时再观看广告。

保存广告只解锁题目保存。智能提示与快速候选继续遵循现有免费钱包和 Premium 无限辅助规则，不因观看保存广告额外发放额度。

自有题建议独立记录用时、错误、提示使用和录入后的操作复盘，初期不混入题库的难度成绩、最佳纪录、连胜和首次完成奖励。纸上此前的解题过程不属于 App 已记录的复盘。难度展示、成绩与统计的最终边界应在立项时明确。

## PDF 与打印方案

### 内容与排版

第一批建议支持当前单题的两种输出：

- 原题：只包含原题给定数字，适合在纸上从头解题。
- 当前进度：包含给定数字和玩家已填数字，用字重等方式区分来源，适合在纸上继续。

使用专门的纸面排版，避免直接导出游戏截图。建议黑白输出、宫线清楚、格子足够大并留有候选书写空间，支持 A4 和 Letter，默认一页一道题。候选数可作为可选项；答案默认不包含，如后续提供则单独放页避免剧透。

批量练习册、多题一页、完整推理步骤导出，以及纸面识别和进度同步不属于第一批建议范围。

### 输出流程与广告次数

建议让 PDF 和打印共用同一份文档与预览：

1. 选择原题或当前进度，调整纸张与内容。
2. 查看预览；预览和修改选项不要求广告。
3. 点击最终导出或打印按钮；免费用户按钮带 `AD` 标记。
4. Premium 直接执行；免费用户取得本次广告奖励后执行。
5. 导出 PDF，或打开系统打印界面由用户选择打印机和打印选项。

建议一次广告解锁本次确认的文档，导出 PDF 和打印同一份文档共用这次解锁，避免用户先导出再打印时重复观看。另一题或另一份盘面内容算新的输出；同一文档的重试保留解锁。具体复用范围和保存期限尚未确认，立项时需明确，不能直接把每次点击按钮都算成新的广告机会。

已经导出的 PDF 可由用户自行保存并反复打印，不控制外部文件的后续使用，也不按实际打印张数收取广告。纸上完成不会自动产生 App 的完成记录。

## 广告中断与操作失败的建议处理

| 情况 | 建议行为 |
| --- | --- |
| 用户提前关闭，尚未取得奖励 | 不正式保存、不输出；保留草稿或预览 |
| 广告无填充、网络断开或播放失败 | 说明广告暂不可用，保留内容并允许稍后重试，不自动放行 |
| 当前地区或隐私状态不允许请求广告 | 不请求广告，保留内容并说明当前无法通过广告解锁；Premium 仍按权益直接使用 |
| 已取得奖励，但保存或 PDF 生成失败 | 保留本次解锁，重试不再要求广告 |
| 打印机不可用或用户取消系统打印 | 保留同一文档的解锁，可重试或改为导出 PDF |
| 已取得奖励后 App 中断 | 恢复对应操作或保留可重试状态，避免重新观看和重复保存 |

奖励是否达成以广告 SDK 的奖励事件为准，不能只根据广告窗口关闭判断，也不要求用户点击广告或安装其他应用。奖励确认和操作执行应分开处理，用户返回 App 后继续对应操作。依据见 [Google 激励广告接入说明](https://developers.google.com/admob/android/rewarded?hl=en)。

## 技术可行路径

以下为初步方向，尚未完成实现验证：

- 录入需要本地盘面格式校验、解数量检查、答案生成，以及区分原题和玩家进度的数据边界。验证算法可用于检查题目，不能成为面向玩家的猜测提示。
- 自有题、草稿与游戏进度通过专门数据层保存到用户存储，不修改只读的发行 `content.sqlite`，不把 HoDoKu2 打包进 App。
- 棋盘、候选、提示和复盘有复用基础，但外部题适配、持久化与结算边界需要验证；不默认给外部题套用题库固定评级。
- PDF 使用专门排版生成；iOS 通过系统打印接口，Android 通过系统打印框架输出。打印机可用性由系统与设备环境决定，保留独立 PDF 导出路径。参考 [Apple 打印接口](https://developer.apple.com/documentation/uikit/uiprintinteractioncontroller) 与 [Android 自定义文档打印](https://developer.android.com/training/printing/custom-docs)。
- 保存和输出广告沿用现有激励广告与 Premium 权益边界，独立于辅助钱包，不引入新的钱包额度或广告网络。
- 录入、校验、预览和已解锁题目的正常游戏可在本地完成；免费用户的新保存或新输出受广告可用性限制，应提前说明。

开发时遵循届时实际的发行阶段和数据兼容要求。本规划不指定新版本号、迁移序列、依赖库或服务端方案。

## 立项时需要明确的细节

已确认的是免费与 Premium 的权限、广告发生时机，以及按钮 `AD` 提示且不加二次确认弹窗。下列内容属于本次讨论保留的建议，需要在实现前确定具体边界：

- 首批是否同时支持原题与已有进度录入、81 位字符串粘贴。
- 草稿保留和“我的题目”的入口、编辑规则，以及与当前游戏的切换方式。
- 自有题的难度、成绩、统计、连胜、完成奖励和复盘边界。
- 保存广告解锁一题后的复用规则，输出广告解锁同一文档的范围和保存期限。
- 纸张、候选数、答案页等首批输出选项，以及四语按钮与说明文案。

建议通过少量目标玩家验证完整流程，观察录入是否顺畅、是否会重复使用自有题，以及导出的文档是否实际被打印和使用，不预先增加分析 SDK。

实施验收应覆盖：有效及无效盘面、原题与已填进度隔离、唯一解与提示覆盖边界、广告取消和成功、奖励后的失败重试与中断恢复、Premium 无广告、钱包隔离，以及双平台 PDF 和实际打印的清晰度与边距。本文保存规划，不启动这些开发或测试任务。
