# C++ 智能提示引擎验收报告

## 范围

`hsp-hint-core` 已实现 `kTechniqueCatalog` 固定目录中的 39 个 Level 1–5
技巧检测入口。运行时只接收当前盘面、持久化候选数，以及唯一矩形家族所需的可选
给定格标记；不接收答案，不调用 HoDoKu2，不使用回溯、猜测或试错。

检测器共享组合枚举、宫格交集、基础鱼、强弱链、双色组件、分组候选节点和有界
蕴含图。高级 forcing 只传播候选数约束，搜索深度和访问节点数均有固定上限；无法
推出结果时返回 `noSupportedStep`。高级搜索轮询请求中的原子取消标记，取消时返回
独立的 `cancelled` 状态，不返回部分证明。

## 自动验收

运行：

```bash
npm run hint:core:check
npm run hint:core:sanitize
```

固定验收包含：

- `-std=c++20 -Wall -Wextra -Wpedantic -Werror` 编译。
- 请求错误、完成盘面、无支持步骤、确定性和技巧目录契约测试。
- 对 `content-v1` 全部 100 道验证题逐步回放至完成。
- 从 100 道题的答案按固定随机种子构造 1,000 个不同正确填写顺序的合法中间
  盘面，验证结果确定性和答案安全，避免只依赖一条预存轨迹。
- 每一步重复调用并逐字段比较，验证确定性。
- 每个填数与版本化答案一致；每个排除均不删除答案候选。
- 39 个检测器分别在合法回放状态中执行正例；Avoidable Rectangle 使用带
  `givenCells` 的专用结构化正例。
- 每个独立检测器正例再次调用以验证确定性，并检查证据区域、原子动作和答案安全。
- 消费该正例动作后再次运行相同检测器，作为近似反例验证原步骤不会被重复报告；
  Avoidable Rectangle 另有移除关键候选后的专用反例。
- 按返回技巧等级统计 `nextStep` P95；Level 1–4 门槛为 100 ms，Level 5
  门槛为 300 ms。
- AddressSanitizer 与 UndefinedBehaviorSanitizer 重跑单元测试和完整回放。

## 当前边界

Avoidable Rectangle 在缺少 `givenCells` 时会保守跳过，因为仅凭当前数字无法区分
不可移动的题目给定数与玩家填写数。唯一矩形相关检测默认发行题具有唯一解；该
前提仍由构建期题库验收保证。

100 题是固定的早期回归集，不替代正式发行前更大规模的随机合法中间盘面与双平台
真机测试。TurboModule、后台取消、iOS/Android 构建和 UI 提示模板属于计划 E 的
平台集成工作，不在纯 C++ 静态库本次验收范围内。
