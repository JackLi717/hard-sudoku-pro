# 双输入方式候选多选：自然点按与按钮共用状态

2026-09-28 确定并实现。范围仅为游戏页候选批量排除：选格优先和数字优先同时支持自然进入、结束与选择反馈；保留现有按钮。共用设置中的“多选”偏好，且只在“笔记”开启时生效。批量操作只删除候选，不添加候选或填正式数字。

## 状态与点按

| 阶段 | 选格优先 | 数字优先 |
| --- | --- | --- |
| 普通选择 | 点候选格，单选该格 | 点数字，单选该数字 |
| 进入批量 | 再点当前单选候选格 | 再点当前单选数字 |
| 增加选择 | 点其他候选格 | 点其他数字 |
| 调整选择 | 再点已选格，移除该格 | 再点已选数字，移除该数字 |
| 最后一个选择 | 再点它，结束批量并保留普通单选 | 再点它，结束批量并保留普通单选 |
| 执行 | 点数字，从选中格删除该候选 | 点候选格，从该格删除选中数字 |
| 连续执行 | 继续点数字，沿用选区 | 继续点格子，沿用数字组合 |
| 执行后重新选择 | 再点候选格，结束批量并单选该格 | 再点数字，结束批量并单选该数字 |

“再次点按”依赖当前选中状态，没有双击时间窗口。删除后重新选择优先于移除旧成员，因此点旧成员也开始普通单选。选区从多项减为一项时仍保持批量语义；只有再点最后一项才退出。

禁用数字、选中数字在目标格中均不存在等没有实际候选可删的操作，不触发“执行后重新选择”。选格优先从候选中移除已填格和不再含可见候选的格子；没有有效选格时结束批量。

两种输入方式中，点已填格或没有可见候选的空格都会结束批量并普通选中该格，本次点击不执行数字输入。数字优先同时保留最后选中的数字。点棋盘外空白结束批量并清空选择。

## 按钮与手势

按钮与自然点按共用 `candidateBatchActive`；不建立独立按钮状态。

- 平板横屏保留固定高度的 Normal / Batch remove 分段入口。Batch remove 带入当前有效选择；Normal 结束批量并保留最后选中的有效格子或数字。点击已亮起的分段不改变状态。
- 其他布局保留原有 Batch remove 切换按钮，开启和关闭分别执行同样的进入、退出规则。
- 自然进入、退出立即同步按钮状态。空选区也能通过按钮进入批量，等待选择。
- 选择顺序保存在临时 UI 状态中，用于 Normal 恢复最后选择；提交候选删除命令时仍排序、去重。
- 保留批量状态中的拖选：只增加有效候选格，经过已填格时忽略；删除后首次拖选从新选区开始，并继续使用批量语义。

## 视觉与边界

普通单选使用蓝色实线框；批量选项使用紫色四角框和浅紫底。只选一个项目的批量状态也必须使用批量框。选格优先标记棋盘选区，数字优先标记数字键；数字优先的目标格不呈现批量选框。平板数字键始终保持圆形，使用蓝色实线圆环表示单选、紫色虚线圆环和浅紫底表示批量选择；棋盘选区与手机数字键保留上述框形。深浅主题均提供对应颜色。

开启多选且处于笔记输入时，格子点击用于候选选择／编辑，不触发一键填数，以免自然点选被直接填数截获。关闭笔记或多选后保留原有一键填数行为。

关闭笔记、多选设置或切换输入方式会退出批量并清理临时批量选择。着色、提示、暂停等更高优先级交互期间暂停批量操作，恢复后保留有效选择及“已执行”边界。同一棋局离开页面再返回也保留该边界，新棋局独立初始化。候选来源、撤销、复盘、提示和数据协议不变。
