# 双输入方式候选多选：临时按钮原型

2026-09-24 确定先用临时按钮实现。设置中只有一个“多选”偏好，选格优先和数字优先共用。多选只编辑候选数，不批量填入正式数字。

开启设置并打开“笔记”后，数字键盘上方出现“批量排除”按钮。默认仍是普通单选。点亮按钮后：

| 输入方式 | 累加选择                                     | 执行排除                         |
| -------- | -------------------------------------------- | -------------------------------- |
| 选格优先 | 点选或拖选多个带候选数的空格；再次点选可移除 | 点数字，从所选格中排除该候选数   |
| 数字优先 | 点选多个数字；再次点选可移除                 | 点一个空格，从该格排除所选候选数 |

选区只剩一个格子或数字时，按钮仍保持批量候选编辑语义。再次点按钮退出，普通点按恢复单选。关闭“笔记”或多选设置、切换输入方式会退出批量排除。着色、提示、暂停等更高优先级交互期间暂停批量编辑；返回后保留有效选区。按钮沿用一个设置和同一个批量候选命令，便于下一轮对手势入口进行实际操作比较。
