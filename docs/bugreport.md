# 手工测试BUG/缺陷记录

1. 游戏时间显示为人类习惯的时间， 超过60分钟，应该显示是分表，超过1天显示 天:时：分:秒，符合各个文化/语言/系统的的设定。
2. 游戏暂停界面，放弃游戏的按钮不好看，需要重新设计为按钮，字体的红色太扎眼。
3. 游戏的赤之感比较强，例如选择录入数字，点击单元格，从暂停回复游戏都有明显的迟滞感，需要优化界面响应速度。
4. 从暂停恢复后，发现不能点数字了。可以点“铅笔”可以修改笔记。需要我重复测试检查可重复性。简单重复没有发现bug浮现，需要继续观察。
5. 点铅笔编辑笔记是，发现如果数字不存在，就点不动，没有给反馈，主流游戏会突出显示同行/同列/同宫中已经存在的数字，提示操作失误，大概一段时间自动回复正常，提供反馈。需要增加这个功能。
