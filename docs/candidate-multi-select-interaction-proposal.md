# 候选格自然多选交互提案

> 状态：已实现并通过自动化验收；本文档是当前行为与验收依据。
>
> 范围：讨论游戏棋盘中的候选格选择、批量删除及两种输入模式共用的数字键反馈；不修改候选生成、Undo、复盘或提示算法。

## 1. 背景

改造前的 Multi-select 是一个显式的临时模式：玩家通过工具按钮或长按进入，选择多个空格后用数字键批量删除候选，再通过 `Done` 等方式退出。旧实现已经支持点选、拖选、数字键候选数量提示以及删除后保留选区，但进入、退出和状态说明仍会打断玩家观察棋盘的过程。

本提案希望将多选改成格子优先输入中的自然延伸：

- 单格操作继续遵守现有填数与笔记规则；
- 选择第二个及更多候选格后，自动成为批量候选删除；
- 数字键执行删除后保留选区，允许连续删除多个数字；
- 通过格子和数字键自身反馈状态，不新增游戏内开关、状态栏或教学区域；
- 保留现有的拖动经过多个格子即可快速选择的能力。

## 2. 产品目标

1. 减少进入多选、结束多选和重新选择同一组选区的操作次数。
2. 保留玩家已经形成的单格填数、笔记输入和拖动选择习惯。
3. 让同一组选区能够连续删除多个候选数。
4. 让点错的候选格可以通过再次点按该格单独取消。
5. 保持游戏页面简洁，不因多选增加常驻说明、计数栏或教学式界面。
6. 保留数字优先“先选数字、再点格子”的操作顺序，并统一候选增删反馈。

## 3. 非目标

- 不在数字优先输入模式中提供本多选交互。
- 不允许向多个格同时填入正式数字。
- 不通过多选批量增加候选数；多格状态下数字键只删除候选。
- 不增加独立的候选增加／删除模式或新的设置开关。
- 不把临时选区写入棋局数据、Undo 快照或复盘动作。
- 不在本阶段改动候选生成、提示、难度或数独逻辑。

## 4. 术语

- **已填格**：题目固定数字或玩家已经填入正式数字的格子。
- **候选格**：尚未填入正式数字，并且当前激活候选来源在界面中显示至少一个候选数的格子。仅存在于求解器内部、但玩家当前看不到的候选不计入本定义。
- **候选选区**：玩家在多选开启后，通过点按或拖动选中的候选格集合。
- **单格状态**：候选选区中只有一个格子。数字键继续使用原有单格输入规则。
- **多格状态**：候选选区中有两个或更多格子。数字键暂时统一解释为批量删除候选。
- **开启多选**：玩家在设置的“输入方式”页面打开“候选格多选”，使候选格可以通过普通点按累加选择。这与当前选区是否为空是两个不同状态。

## 5. 适用范围与模式边界

### 5.1 格子优先

本功能只在格子优先输入模式中可用。开关放在设置的“输入方式”二级页，游戏工具栏不提供入口。新用户默认关闭；玩家主动开启后，该偏好需要跨继续同一棋局、开始新局和重启 App 保存。候选格的普通点按开始使用本文定义的累加选择规则。

多选开启不代表数字键永远删除。数字键的行为由候选选区的格数决定：

| 候选选区 | 笔记按钮 | 数字键行为 |
| --- | --- | --- |
| 0 格 | 任意 | 显示盘面剩余数量，但全部禁用 |
| 1 格 | 关闭 | 按现有规则填入正式数字 |
| 1 格 | 开启 | 按现有规则编辑该格候选数 |
| 2 格及以上 | 关闭或开启 | 从选中格批量删除对应候选数 |

当选区从多格减少为一格时，数字键立即恢复单格语义，并重新由笔记按钮状态决定行为。多格状态不得自动修改笔记按钮；它只是在选区存在期间暂时取得数字键解释权。

### 5.2 数字优先

数字优先输入模式不提供候选格多选，但与格子优先共享数字键增减符号：

- 游戏页始终不显示多选入口；设置中的偏好仍被记住，但在数字优先模式中不生效；
- 笔记关闭时，数字键继续显示盘面剩余数量；
- 手动笔记开启时，数字键显示 `±1`，点格后短暂显示本次实际执行的 `+1` 或 `−1`；
- 快速候选开启时，数字键显示 `−1`，只允许删除目标格已有候选，不把缺少的候选加回；
- 点按格子继续执行“先选数字、再点目标格”的输入顺序；
- 不将连续点格解释为候选多选；
- 从格子优先切换到数字优先时，必须清空候选选区。

切换到数字优先只清空当前候选选区，不覆盖已经保存的多选开启偏好。返回格子优先后，自动恢复切换前的多选开启状态。

## 6. 点按交互

多选开启时，棋盘点按遵循以下规则：

| 点按对象 | 结果 |
| --- | --- |
| 未选中的候选格 | 将该格加入候选选区 |
| 已选中的候选格 | 只将该格移出候选选区，其他选中格保持不变 |
| 已填格 | 清空候选选区，并将该已填格作为普通单选焦点 |
| 没有可见候选的未填格 | 清空候选选区，并将该格作为普通单选焦点；该格不能加入候选选区 |
| 棋盘外无关空白区域 | 清空当前候选选区，不关闭多选开关 |
| 在设置中关闭“候选格多选”后返回棋局 | 清空候选选区并恢复普通格子优先输入 |

由此形成以下连续行为：

1. 点第一个候选格，进入单格状态。
2. 点第二个候选格，进入多格状态。
3. 继续点其他候选格，持续加入选区。
4. 再次点某个已选候选格，只取消该格。
5. 点已填格，结束本轮候选选择并转为普通单格观察。
6. 点棋盘外空白，结束本轮候选选择，但多选功能仍保持开启。

候选格资格随当前可见候选动态更新。在候选编辑、Undo、快速候选、Hint 应用或其他操作改变候选后，从选区中移除已经填入数字或不再显示任何候选的格子；其余仍符合资格的格子继续保留。由此造成选区从多格减少为一格时，立即恢复单格语义。

数字键不是结束选区的触发器。无论连续删除多少个候选数，选区都保持不变，直到玩家通过上述棋盘操作改变它，或在设置中关闭功能。

## 7. 拖动选择

现有的拖动快速选择必须保留，并适配新的语义：

1. 从候选格开始拖动，沿途经过的候选格自动加入候选选区。
2. 拖动只增加选择，不批量取消选择；单格取消使用再次点按。
3. 拖动经过已填格时忽略该格，不清空选区，也不把该格变成普通单选。
4. 从已经选中的候选格开始拖动，只要移动超过拖动判定阈值，本次手势仍按“沿途增加选择”处理。
5. 在已选格上按下但没有形成拖动时，才按普通点按处理并取消该格。
6. 拖动过程中应即时显示沿途新增选区，使玩家能预测松手后的结果。

“点按已填格会清空选区”和“拖动经过已填格会忽略该格”必须通过手势是否达到拖动阈值来区分，不能因为拖动路径经过固定数字而意外结束选择。

## 8. 数字键盘反馈与操作

游戏页面不新增多选开关、状态栏、选中格数说明或 `Done` 操作。反馈集中在现有棋盘和数字键盘上。

### 8.1 无选格、已填格与单格状态

数字键将“盘面还缺多少”和“当前能执行什么操作”作为两层独立信息：

| 当前上下文 | 数字键行为 | 键下方信息 |
| --- | --- | --- |
| 未选择格子（格子优先） | 全部禁用 | 盘面剩余数量 |
| 已填数字或题目固定数字 | 全部禁用，只用于观察高亮 | 盘面剩余数量 |
| 未填格，笔记关闭 | 按现有规则填入正式数字 | 盘面剩余数量 |
| 单个候选格，手动笔记开启 | 已存在的候选可删除，未存在的候选可添加 | 分别显示 `−1` 与 `+1` |
| 单个候选格，快速候选开启 | 已存在的候选可删除，未存在的候选禁用 | 可删除项显示 `−1`，其余无附加信息 |

- 禁用数字键不隐藏剩余数量；其视觉与未填格、笔记关闭时的剩余数量采用同一布局，只通过禁用态区分可操作性。
- 单格候选的 `+1 / −1` 直接表达本次按键将怎样改变候选，数字键本身仍沿用现有候选编辑命令。
- 单格填入正式数字后，继续沿用现有的选格、自动清理候选和焦点规则。
- 数字优先不套用上述格子优先禁用规则，其候选工具反馈按 8.5 节处理。

### 8.2 多格状态

- 数字键立即呈现明确的删除语义，不依赖额外文字区域解释。
- 无论笔记按钮是否点亮，点数字都只从候选选区中删除该候选。
- 每次数字键操作后保留完整选区，允许继续删除其他数字。
- 选区中不存在的候选数字应禁用或明确显示为不可用，点击不得清空选区。
- 每次数字键删除分别沿用现有候选编辑命令和 Undo/复盘记录方式。

数字键删除反馈采用与单格候选编辑一致的增减表达：

- 显示 `−N`，其中 `N` 是当前选区中包含该候选数的格子数量；
- 可删除数量为零时置灰、禁用且不显示数量；
- 不增加单独的删除色、状态栏或解释文案；
- 从一格变成两格、或从两格回到一格时，只更新数字键状态，不引发布局位移。

### 8.3 其他界面反馈

- 候选格的选中视觉必须足以区分一个和多个被选格，但不增加文字说明。
- 多选开关只在设置的“输入方式”页面显示，游戏页不重复显示开启状态。
- 可以保留轻量触觉或按压反馈，但不显示弹窗、常驻提示条或一次性教学遮罩。
- VoiceOver 等辅助技术仍需获得当前格是否选中、数字键删除目标和不可用状态；无障碍文本不要求在视觉界面中显示。

### 8.4 数字观察焦点

数字观察焦点与候选选区是两个独立状态。玩家点已填数字 5 后，按现有高亮设置显示的正式数字 5 与候选数 5，应在随后点按、拖动、增加或取消候选格时继续保持高亮。

- 候选格点选和拖选只改变候选选区，不清除当前数字观察焦点。
- 多格状态下按另一个数字删除候选时，观察焦点切换到刚按下的数字，并在删除后保持。
- 点另一个已填数字时，观察焦点切换到该数字。
- 点无候选空格或棋盘外无关空白时，清除数字观察焦点。
- Color、Hint、自动完成运行态和推演工作区接管棋盘时，普通数字高亮暂时隐藏；退出后恢复仍有效的观察焦点。
- 继续复用“高亮相同数字”和“高亮同数笔记”设置，不增加“多选时保持高亮”开关。玩家关闭现有高亮设置时，本规则不强制显示对应高亮。

### 8.5 数字优先的候选工具反馈

数字优先时，数字键先选择工具，实际目标格尚未确定，因此不能在按数字前把每个键固定解释为增加或删除。采用以下统一而不误导的表达：

- 笔记关闭：显示盘面剩余数量，不显示增减符号；
- 手动笔记开启：所有数字键显示 `±1`，表示目标格缺少该候选时增加、已有该候选时删除；
- 玩家点目标格后，当前选中的数字键在 480 毫秒内显示本次实际结果 `+1` 或 `−1`，随后恢复 `±1`；
- 快速候选开启：所有数字键显示 `−1`；点含有目标候选的空格时删除，点不含该候选的空格时只更新观察焦点，不产生候选编辑命令；
- 点已填数字或题目固定格不显示虚假的增删反馈，仍由现有棋盘规则阻止编辑；
- 数字键保持选中状态，允许玩家继续把同一个候选工具应用于其他格子；
- 不新增增加／删除模式开关，不改变再次点击已选数字即可退出数字工具的规则。

## 9. 工具按钮与界面简洁性

多选不再依赖以下现有元素：

- 长按空格进入多选；
- “已选 N 格”的 Contextual Action Strip；
- `Done` 按钮；
- 为说明进入和退出方式而显示的多选教学卡及其设置页预览入口。

普通的游戏工具按钮不应仅因被点击就隐式清空候选选区。Undo、擦除、笔记、快速候选、颜色、Hint、暂停和返回均保留多选开启状态；当前候选选区在工具接管棋盘期间应暂停而不是被无条件丢弃。工具结束后，按当前可见候选重新过滤选区并恢复仍符合资格的格子。

### 9.1 临时模式优先级

采用“高优先级工具接管交互，多选状态暂停并在结束后恢复”的统一规则：

1. **Color**：Color 开启时，棋盘点按和拖动优先执行着色；候选选区保存在后台但不响应数字键删除。关闭 Color 后，过滤并恢复候选选区。
2. **Hint**：Hint 打开时，提示视觉和操作取得优先权；候选选区暂停。关闭或应用 Hint 后，根据最新盘面和可见候选过滤并恢复。
3. **Auto Complete**：可用提示可以继续按现有位置显示，因为新的候选多选不再占用 Contextual Action Strip。自动完成运行时锁定棋盘并取得交互优先权。自动完成之后棋局已经结束，不再存在候选格或候选选区，因此不为完成态另行定义多选生命周期行为。
4. **推演工作区**：推演有独立的选格和数字键语义，进入后应暂停普通候选选区，不能混用两组选区。退出或应用推演结论后，过滤并恢复普通候选选区。
5. **Pause 和临时遮挡层**：暂停期间隐藏或冻结候选选区交互，恢复游戏后重新显示，不改变选区内容。

优先级为：阻断棋盘的模态界面／自动完成运行态，其次是 Hint 和推演工作区，其次是 Color，之后才是候选多选和普通格子输入。高优先级状态只接管交互，不自动关闭已保存的多选偏好。

## 10. 数据、Undo 与复盘

- 候选选区属于纯界面临时状态，不保存到棋局数据库。
- 点选、取消和清空选区不创建 Undo 记录，也不生成复盘动作。
- 多格状态下每点一次数字，产生一次现有的候选删除操作；连续删除两个数字应形成两个可分别撤销的操作。
- 批量删除仍需忽略未包含目标候选的选中格，不得向任何格增加候选。
- 快速候选的“只删不加”由游戏引擎保证；即使快速连续输入或绕过界面调用输入命令，也不得把已经删除或原本不存在的候选重新加入。
- 多选开启偏好跨棋局和 App 重启保存；候选选区本身仍是临时界面状态。
- 暂停、临时工具和同一 App 运行期间返回再继续同一棋局时，恢复候选选区并过滤失效格。
- 开始新局或 App 完全重启时不恢复上一次候选选区，只恢复多选开启偏好。

## 11. 验收场景

### 11.1 单格行为不变

1. 使用格子优先，开启多选。
2. 点一个候选格。
3. 笔记关闭时点数字，结果与当前普通单格填数完全一致。
4. 撤销并打开笔记，再点数字，结果与当前普通单格候选编辑完全一致。

### 11.2 自动进入多格删除

1. 连续点两个候选格。
2. 数字键立即切换为删除反馈，不显示额外状态栏。
3. 点一个在部分选中格中存在的数字，只从包含它的格中删除。
4. 选区保持不变。
5. 再点另一个数字，继续从同一组选区删除。

### 11.3 逐格取消并返回单格

1. 选择三个候选格。
2. 再点其中一个，只取消该格。
3. 再取消一个，使选区只剩一格。
4. 数字键恢复单格样式，行为重新取决于笔记按钮。

### 11.4 已填格切换

1. 建立多格候选选区。
2. 点一个题目固定数字或玩家已填数字。
3. 候选选区全部清空。
4. 该已填格成为普通单选焦点，并继续使用现有的同数字、同行列宫高亮。

### 11.5 拖动选择

1. 从候选格开始拖动并经过多个候选格、空白候选格和已填格。
2. 所有符合条件的候选格加入选区。
3. 已填格被忽略，不触发清空或普通单选。
4. 松手后可以连续点多个数字删除候选，选区不消失。

### 11.6 数字优先隔离

1. 切换到数字优先输入。
2. 候选选区被清空；游戏页本身没有多选入口。
3. 预选数字并连续点格，行为与当前数字优先完全一致。
4. 返回格子优先后，多选恢复为切换前的开启状态，但旧候选选区不恢复。

### 11.7 简洁性

- 多选全过程没有新增常驻状态栏、选中数量文案或 `Done` 按钮。
- 从单格进入多格时页面布局不发生位移。
- 玩家可以仅凭格子选中效果和数字键状态判断当前行为；功能开关只在设置页呈现。

### 11.8 数字高亮连续性

1. 点一个已填数字 5，确认正式数字和候选数 5 按现有设置高亮。
2. 连续点按或拖动多个候选格，高亮 5 保持不变。
3. 在多格状态按数字 4，删除对应候选后观察焦点切换到 4 并保持。
4. 点棋盘外空白，高亮焦点和候选选区同时清除。
5. 关闭现有数字或候选高亮设置时，不因多选强制显示高亮。
6. 一键填入最后一格或唯一候选数后，该格保持为当前格，数字观察焦点切换到实际填入的数字；原先聚焦的数字不再残留高亮。
