# 阶段 6：产品完整化开发与验收计划

日期：2026-09-01

## 目标与边界

阶段 6 将阶段 4、5 已经可完整游玩的英文浅色版本补齐为可发行的产品体验。本阶段不改变
游戏规则、五级难度、题库、39 种技巧、提示排序或阶段 7 的广告、额度与 Premium 设计。

## 当前基线

- 完成/失败结果页已经接通时间、错误、提示、奖励、重试和下一题。
- `user.sqlite` 已提供通用设置读写，统计仓储已提供尝试、完成、失败、放弃、时长和工具使用
  聚合数据。
- 首页只展示简要统计；尚无独立统计页、设置页、玩法帮助页和数独技巧目录。
- 用户可见文案仍为组件内英文，主题仍为固定浅色调色板。
- 棋盘、提示及主要按钮已有部分无障碍语义；系统“减少动态效果”已用于提示棋盘动画，但尚未
  完成 VoiceOver/TalkBack 主流程审计、动态字体布局和全应用动画降级。

## 实施顺序

### 6A：产品基础设施

- 建立应用级页面路由，支持首页、统计、设置、帮助、技巧目录和技巧详情的返回行为。
- 建立英语、日语、德语、简体中文资源与类型安全翻译键；设备语言匹配、英语回退和用户选择
  优先级可测试。
- 建立浅色、深色、跟随系统主题及应用级主题上下文，状态栏与系统主题同步。
- 建立持久化产品偏好模型及迁移兼容层，旧数据库缺少新键时使用稳定默认值。

验收：语言和主题切换立即生效、重启保持；未知或缺失语言回退英语；旧用户数据可无损打开。

### 6B：设置与既有页面迁移

- 设置页接通语言、主题、音效、震动、常亮、输入模式、数字/区域高亮、自动检查、自动移除
  候选、提示动画等已定义选项。
- 将应用壳、首页、游戏页、结果页、确认弹窗、错误消息和 Hint Lab 之外的无障碍标签迁移到
  翻译资源和动态主题。
- 游戏级设置在新局和恢复局中保持明确语义，不静默改变已开始游戏的错误限制或候选行为。

验收：设置均有持久化测试；四种语言下既有主流程无硬编码用户文案；浅色、深色和系统模式
截图基线通过。

### 6C：统计、帮助和技巧页面

- 统计页展示总尝试、完成、失败、放弃、总时长、提示和快速铅笔使用，以及已有的分级完成数。
- 玩法帮助覆盖选择、填数、候选、擦除、撤销、暂停、错误、提示与完成规则。
- 技巧目录覆盖 39 种正式技巧，按 Level 分组；详情页包含本地化名称、目标、识别方法和结果
  类型，并复用稳定技巧代码。
- 完成页补齐本地化、可访问标题顺序、奖励说明和长文案布局。

验收：所有页面可以仅靠屏幕阅读器导航；39 种技巧在四种语言下均有名称与正文且无缺失键。

### 6D：无障碍与设备验收

- 完成 VoiceOver、TalkBack 的开始、填数、候选、提示、暂停、恢复、完成和设置主流程。
- 支持动态字体，德语长文案及中日文字体不截断；棋盘数字保持固定可读布局。
- 全应用响应系统“减少动态效果”，并确保颜色不是错误、选择、提示和完成状态的唯一表达。
- 在 iOS、Android 真机上分别检查浅色、深色、四种语言和屏幕阅读器关键组合。

验收：路线图定义的四语无缺失键或截断门槛通过；两端屏幕阅读器可以独立完成主要流程。

## 自动化门槛

- 翻译资源键集合完全一致，插值参数经过测试，用户界面不存在未允许的硬编码英文。
- 主题和设置具有默认值、切换、持久化、恢复与旧数据兼容测试。
- 页面路由、统计映射、39 种技巧内容和主要无障碍标签具有 Jest 覆盖。
- 每批提交继续通过 `npm run check`；涉及原生依赖或配置时同时通过 Android 与 iOS 构建。

## 开发记录

### 2026-09-01：6A 首个垂直切片

- 新增版本化产品偏好模型，语言和主题共用一个设置快照写入既有 `user.sqlite`；连续更新按顺序
  提交，旧数据库无该设置时使用稳定默认值。
- 新增英语、日语、德语和简体中文类型安全资源，支持插值、设备语言匹配、英语回退和手动语言
  优先级。繁体中文设备不会被错误映射为简体中文。
- 新增浅色、深色、跟随系统主题上下文及状态栏模式；保留旧页面的浅色调色板兼容出口，允许
  后续逐页迁移而不影响棋盘与提示稳定性。
- 首页和应用壳已迁移到动态语言与主题，首页可进入设置页并即时切换语言和主题；选择持久化后
  重启恢复。
- 新增资源键一致性、Locale 回退、偏好顺序写入/恢复、主题解析和设置页无障碍单选测试；当前
  全量为 13 个 Jest suite、232 个 test。
- Android API 35 模拟器 Debug 构建安装通过；已实际从首页进入设置、即时切换德语与深色模式，
  强制停止并重新启动 App 后语言、主题和对应状态栏样式均正确恢复。

这一切片不表示 6A 或阶段 6 已完成。游戏页、结果页、领域错误消息、提示正文以及统计、帮助、
技巧页面仍需迁移或实现，深色模式也必须在所有正式页面迁移后才可验收。

### 2026-09-01：6B 既有主流程迁移

- 游戏页、数独棋盘、暂停层、提示抽屉、结果页、确认弹窗和应用内消息已接入四语资源与
  动态浅色/深色主题；棋盘在深色下保留宫线层级、候选数和提示状态的可读对比度。
- 领域层不再把英文错误句子暴露给 UI，改为稳定消息代码与参数，由当前 Locale 在展示时翻译。
- 产品偏好增加“提示动画”开关；关闭后提示抽屉入场、分页及应用动画立即降级，并且仍尊重
  iOS/Android 系统“减少动态效果”设置；该偏好已纳入 `user.sqlite` 恢复测试。
- `npm run lint`、`npm run typecheck`、13 个 Jest suite 共 232 个 test 及 C++ 39 技巧全量门禁通过。
- Android API 35 模拟器 Debug 包已重新安装；实际验证简体中文即时切换、提示动画关闭状态、
  深色设置页和深色游戏棋盘。

这一批仍不表示 6B 或阶段 6 已完成。音效、震动、常亮、输入与棋盘行为设置尚未实现；提示技巧

后续 6B–6D。

### 2026-09-01：6B 游戏设置补齐

- 产品偏好升级到 schema v2，在保留旧用户语言、主题和提示动画选择的基础上，增加音效、震动、
  游戏中常亮、计时器、剩余数字、格子优先/数字优先输入、相关区域高亮、相同数字高亮、自动检查、
  三次错误限制和自动移除候选设置。
- 音效和常亮通过轻量原生模块接入 Android/iOS；震动复用 React Native 平台能力。交互反馈只作用于
  游戏操作，且可以分别关闭。
- 显示及输入偏好即时作用于当前游戏；规则偏好只成为新开游戏的设置快照，恢复中的游戏和当前游戏
  不会被静默改写。开启三次错误限制会同时开启自动检查，防止产生无法计数的矛盾组合。
- 增加旧偏好迁移、偏好到游戏规则映射、新局规则隔离、数字优先输入、计时/余数显隐和棋盘高亮开关
  回归测试，并在 Android API 35 模拟器完成 Debug 构建安装。
- Android 系统返回键已接入设置页和 Hint Lab 的应用内返回行为，不会从子页面意外离开应用。

这一批完成 6B 中的游戏设置范围；提示技巧名称与证明正文四语化仍需继续。统计、玩法帮助、39 技巧
内容页属于 6C，完整的双端无障碍、动态字体与真机组合验收属于 6D。

## 阶段完成定义

只有在 6A–6D 全部通过、四语和两端屏幕阅读器主流程完成实际设备验收后，阶段 6 才标记为
完成。模拟器或单一语言自动化通过不能单独替代该门槛。
