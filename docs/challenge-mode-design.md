# 过关挑战设计总览

三个大关已经实现十八小关、共享棋盘、独立进度和首页入口；第二大关「组合与交叉」、第三大关「联动与突破」接入完成上一大关后的广告解锁。当前用户已确认采用统一结果判定；此决策替代旧版以技巧证据、实际排除路径和隐性唯一数依赖为通关条件的设计。

## 已确认边界

- 第一大关六个小关的主题依次为 Hidden Single、Pointing、Claiming、Naked Pair、Hidden Pair、综合挑战；每个已解锁大关的六关自由选择。
- 所有关卡按唯一解判断填数和候选删除，正确替代方法和省略中间步骤均接受。
- Hidden Single 专项与每个大关的综合关正确填一格通过；其余技巧专项正确排除至少一个候选或正确填一格通过。各大关六关全部通过才完成本集。
- 不要求选择依据、完整排除、技巧声明、固定点击次数、实际两类技巧计数或穷举状态路径。
- 对局复用游戏棋盘与输入，候选自动删除沿用普通游戏设置；数字覆盖、擦除、撤销和批量检查保持一致。
- 棋盘返回当前说明并保留草稿，说明 Home 才退出；移除棋盘信息入口。
- 主题与 Goal 引导玩法，帮助默认折叠。通过只说明结果正确，不作为技巧认证。
- 挑战广告只授予整大关访问资格，不接入普通游戏奖励、技巧成长或辅助钱包。
