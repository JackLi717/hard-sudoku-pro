# 技巧学习练习与挑战设计总览

记录日期：2026-10-02。

状态：设计文档。产品方向来自本次讨论；执行细则和技术机制为待评审方案。当前只授权文档设计，不制作具体关卡，不修改运行时代码、数据库、广告配置或首发范围。

系统由免费技巧讲解、自选专项练习和挑战闯关三个互补功能组成。讲解帮助理解，练习帮助应用，挑战让玩家在精选真实局面中主动寻找技巧，再通过综合闯关验证连续推理能力。本套文档把产品形态、技术实现、内容判定机制和关卡设计分开，目标是让后续设计人员按照固定约束制作内容，而不必逐题重新定义操作、算法或通关规则。

## 决策状态

| 内容 | 状态 |
| --- | --- |
| 固定局面的技巧挑战，禁用提示，自动候选免费 | 用户已确认 |
| 三个互补功能为技巧讲解、专项练习和挑战闯关 | 用户已确认 |
| 三部分题目及原题来源独立，等价变换和不同回放阶段不能跨功能复用；会话、表现与访问分别维护 | 用户已确认的长期原则 |
| 全部技巧讲解免费，每种已发布技巧三至五道免费练习 | 用户已确认 |
| 免费玩家每次有效广告解锁五道更多练习 | 用户已确认 |
| 每个挑战五个专项小关，每个小关一种技巧 | 用户已确认 |
| 第一个挑战免费，之后一次广告解锁一个挑战的五个专项小关，Premium 直接开放 | 用户已确认 |
| 五个专项小关之后增加综合闯关，通过后进入下一集 | 用户确认的方向 |
| 产品、技术、机制、具体关卡设计分别交付，先建立规范再选题 | 用户已确认 |
| 每集增加一个综合关，总计六关，原广告解锁同时覆盖综合关 | 本套文档建议的具体结构 |
| 首期六种技巧、整组结果提交、关键依据选择、允许有效替代路径、重试和进度细则 | 待评审设计 |
| 30 集是扩展规划，先发布一集完整内容 | 本套文档建议，不是产量或发行承诺 |
| 100～150 集长期容量 | 先前讨论的估计，未完成选题验证 |

综合关是新增内容，按建议的六关结构，30 集是 180 关；100～150 集是 600～900 关。先前五关结构中的 150 关、500～750 关不再用于这套六关方案。集数是规划容量，不要求一次性生产，也不是无限内容承诺。

题目独立原则的产品定义见 [讲解与练习设计](technique-learning-practice-design.md)，生成及发布拒绝条件见 [选题与判题机制](challenge-mode-validation-policy.md)。三部分可使用相同技巧并共享算法，知识学习可以帮助闯关；题目答案和可变状态不得跨功能带入。

## 工作顺序和完成门槛

| 阶段 | 交付物 | 完成门槛 |
| --- | --- | --- |
| 产品定义 | 用户流程、规则和待决策项 | 明确通关、进阶、访问资格与广告边界 |
| 技术契约 | 数据模型、模块接口和能力缺口 | 不依赖具体界面即可描述一次完整提交及恢复 |
| 机制验证 | 生成、校验、判题和综合目标原型 | 正例、反例、替代路径、截断与恢复均能正确处理 |
| 关卡设计 | 按规范选出的整集内容 | 所有盘面及路径经过自动检查和体验检查 |
| 界面与纵向交付 | 已批准内容的完整用户体验 | 手机、平板竖屏、四语和无障碍可用 |

机制原型可以使用临时合法测试素材，但不提前把它们当作第一集正式关卡。只有第三阶段通过后，设计人员才按既定约束制作正式内容。

## 当前边界

保持现有普通游戏、钱包、题目难度、复盘和统计行为。未来学习和练习按新定义交付，不因文档更新自动恢复现有数独学堂或隐藏入口；不恢复技巧成长和掌握评分，不增加账号、服务器、排行榜、联网题库或新的技巧检测器。

挑战内容随 App 发布，发行内容只读，用户进度单独保存。开发期直接更新当前基线，不增加实验版本、历史数据库或审计归档。若实际开发发生在首个公开版本发行之后，先按 AGENTS.md 更新发行阶段和兼容基线。

现有 [产品与数据架构](product-and-data-architecture.md)、[首期游戏定义](game-feature-plan.md)、[商业化边界](commercial-sdk-boundary.md) 和 [免费钱包与 Premium 设计](premium-reward-design.md) 继续决定当前运行时行为。本套文档描述未来学习、练习和挑战功能，不将其自动纳入当前首发。

## 进入实现前需要裁决的事项

1. 采用五个专项关加一个综合关，并让原一次广告覆盖整集六关。
2. 首期关键依据提交、整组排除、有限状态图与多路径判题方案，经原型验证后冻结。
3. 广告长期不可用或市场禁止广告时，新集的免费访问规则。
4. 已解锁集的长期复用、Premium 撤权后的已开始集资格，以及开发实际所属发行阶段。
5. 判题状态图和证据适配器在目标设备上的大小、耗时及取消预算。
6. 扩展练习包的持久访问、Premium 练习权益、撤权及广告不可用规则；每包五题和基础免费数量已确认，不重新讨论。

以上问题不阻塞本次文档交付，但涉及的规则未解决前不进入正式运行时实现。具体建议分别记录在所属文档中。
