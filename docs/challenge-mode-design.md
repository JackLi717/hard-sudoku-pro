# 过关挑战设计总览

第一集「发现与衔接」已经实现六关、共享棋盘、独立进度和首页入口。当前用户已确认采用统一结果判定；此决策替代旧版以技巧证据、实际排除路径和隐性唯一数依赖为通关条件的设计。

## 已确认边界

- 六个小关的编号主题依次为 Hidden Single、Pointing、Claiming、Naked Pair、Hidden Pair、综合挑战；六关自由选择。
- 所有关卡按唯一解判断填数和候选删除，正确替代方法和省略中间步骤均接受。
- 第一关与综合关正确填一格通过；第二至五关正确排除至少一个候选或正确填一格通过。六关全部通过才完成本集。
- 不要求选择依据、完整排除、技巧声明、固定点击次数、实际两类技巧计数或穷举状态路径。
- 对局复用游戏棋盘与输入，候选自动删除沿用普通游戏设置；数字覆盖、擦除、撤销和批量检查保持一致。
- 棋盘返回当前说明并保留草稿，说明 Home 才退出；移除棋盘信息入口。
- 主题与 Goal 引导玩法，帮助默认折叠。通过只说明结果正确，不作为技巧认证。
- 不接入普通游戏奖励、技巧成长、广告或新埋点。
