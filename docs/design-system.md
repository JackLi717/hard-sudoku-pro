# Platon Sudoku 1.0 Design System

首版只展示浅色外观。Home、Replay、Statistics 的任务不同，但使用同一套视觉语法；不要把三个页面做成相同布局。

## 基础规则

- **颜色**：以 `src/ui/themes/warm-paper.ts` 的 `lightPalette` 为唯一颜色来源。暖米白 `background` 承载页面，`ink` 承载主要文字，`muted` 承载次级文字，深绿 `accent` 用于主要操作与核心数字，`line` 用于极淡分隔。金色 `accentWarm` 仅用于少量奖励或特殊强调。
- **标题**：Replay 与 Statistics 使用 `RootPageHeader`，18 / 800 居中，左右预留相同宽度；一级页面标题下方用留白，不画横线。Home 使用品牌标题与右上角设置入口，不强行套用居中导航标题。全屏详情可按需要显示标题下分隔线。
- **导航**：底部 Home / Replay / Statistics 由 `HardSudokuApp` 唯一渲染，统一描边图标、文字和选中态。一级页面不另造导航。
- **宽度与触控**：列表内容左右留白 20、最大宽度 720；导航标题高 58，底部导航高 64；可点击图标或返回入口至少 44。共同尺寸定义在 `src/ui/root-page-design.ts`。
- **层级**：先展示用户最需要的动作或数据，再展示细节。主数字或主动作直接成为视觉重心；说明性文字仅在不能从名称理解时出现。以字重、字号和留白区分层级，细线只分隔相邻记录。
- **容器**：Home 的主要 CTA 可以有填充面；Replay 记录与 Statistics 数据使用平面列表。不要为每条记录或每个数字单独加圆角 Card。

## 三个一级页面

| 页面 | 主要任务 | 结构 |
| --- | --- | --- |
| Home | 继续或开始游戏 | 品牌、Continue、New Game；设置是右上角单图标 |
| Replay | 找到已结束对局 | 居中标题、日期分组、整行可点的单行记录；记录间浅分隔 |
| Statistics | 看总体表现 | 居中标题、完成数 / 完成率 / 总游戏时长、活动列表、难度列表 |

添加一级页面内容时，先复用 palette、`RootPageHeader` 和 `ROOT_PAGE` 中已经成立的规则。页面专属的字号、行高与留白留在页面内，只有跨页面重复且语义一致时才提升为共享规则。
