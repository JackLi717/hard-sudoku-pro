# Platon Sudoku 1.0 Design System

Home、Replay、Statistics 的任务不同，但使用同一套视觉语法；不要把三个页面做成相同布局。首页采用已选定的「暖纸棋册」方案，跟随现有主题设置支持浅色与深色。

## 基础规则

- **颜色**：使用 `src/ui/themes/warm-paper.ts` 中当前外观的 palette。浅色以暖米白 `background` 承载页面，`ink` 承载主要文字，`muted` 承载次级文字，深绿 `accent` 用于主要操作与核心数字；深色使用相应主题色。`line` 用于分隔，金色 `accentWarm` 仅用于少量奖励或特殊强调。
- **标题**：Replay 与 Statistics 使用 `RootPageHeader`，18 / 800 居中，左右预留相同宽度；一级页面标题下方用留白，不画横线。Home 使用品牌标题与右上角设置入口，不强行套用居中导航标题。全屏详情可按需要显示标题下分隔线。
- **导航**：底部 Home / Replay / Statistics 由 `HardSudokuApp` 唯一渲染，统一描边图标、文字和选中态。一级页面不另造导航。
- **图标**：除启动器、商店及其他品牌图标外，应用内功能图标优先使用 Google Material Symbols 官方图形，并默认采用 `Outlined` 风格。已有合适官方图标时不得自行近似绘制；通过统一图标组件设置主题颜色、尺寸和对齐，不修改官方路径的轮廓、比例或方向。自定义图标仅用于官方库无法准确表达的语义，并须在对应设计文档中记录原因。
- **宽度与触控**：列表内容左右留白 20、最大宽度 720；导航标题高 58，底部导航高 64；可点击图标或返回入口至少 44。共同尺寸定义在 `src/ui/root-page-design.ts`。
- **层级**：先展示用户最需要的动作或数据，再展示细节。主数字或主动作直接成为视觉重心；说明性文字仅在不能从名称理解时出现。以字重、字号和留白区分层级，细线只分隔相邻记录。
- **容器**：Home 的主要 CTA 可以有填充面；Replay 记录与 Statistics 数据使用平面列表。不要为每条记录或每个数字单独加圆角 Card。

## 三个一级页面

| 页面 | 主要任务 | 结构 |
| --- | --- | --- |
| Home | 继续或开始游戏 | 左上角品牌字标、倾斜九宫格装饰、衬线标题与短句、Continue、New Game；设置是右上角单图标 |
| Replay | 找到已结束对局 | 居中标题、日期分组、整行可点的单行记录；记录间浅分隔 |
| Statistics | 看总体表现 | 居中标题、完成数 / 完成率 / 总游戏时长、活动列表、难度列表 |

添加一级页面内容时，先复用 palette、`RootPageHeader` 和 `ROOT_PAGE` 中已经成立的规则。页面专属的字号、行高与留白留在页面内，只有跨页面重复且语义一致时才提升为共享规则。

## 首页：暖纸棋册

- 本次范围仅为首页视觉与首页文案；保留现有难度选择、继续游戏、设置长按开发入口、底部导航以及已有横屏布局，不改其他页面或全局主题配色，也不启用横屏。
- 平板宽度（内容区至少 600）下，页头铺满可用宽度，品牌字标与设置入口分居两侧，沿用安全区内 28 点的左右留白和至少 44 × 44 的点击区域。品牌主体与按钮继续保持居中限宽；手机页头保留原有宽度。
- 九宫格采用「缎面钛金」材质：银绿色拉丝金属、细倒角、刻字和低强度投影，数字 3 使用墨绿金属面。展示尺寸 160 × 160，整体逆时针倾斜 7°，保留静态数字 1 / 3 / 5 / 7 / 9 与留空格。它是品牌装饰，不是真实棋盘，不可操作且不进入无障碍朗读。
- 标题在 iOS 使用 Georgia、Android 使用系统 serif；中文短句为「留一点时间，给思考。」，其他语言使用对应译文。小屏缩小标题基础字号，大字体可自然换行并滚动。
- 有未完成棋局时，主要按钮居中显示「继续游戏」和真实难度 / 用时，不显示箭头；最小高度 64，上下内边距 8，大字体时自然增高。「新游戏」为带加号和 1 点主题强调色边框的次要操作。没有可继续棋局时，仅展示填充色的新游戏主按钮。
- 竖屏按钮区下移至底部品牌署名与导航上方。九宫格、标题和短句组成紧凑品牌组；剩余空间按约 1:2 分布在品牌组上方、品牌组与按钮之间，分别保留至少 24 / 40 的间距。小屏或大字体时内容自然增高并允许滚动，不绝对定位按钮；已有横屏布局保留原来的居中结构。
- 页面与按钮使用现有浅色 / 深色 palette，避免与安全区和底部导航发生配色断层。九宫格使用独立的浅色 / 深色金属材质色，在 `HomeBrandEmblem` 中通过现有 SVG 依赖绘制渐变、拉丝与倒角，不新增图片、字体或第三方依赖。
