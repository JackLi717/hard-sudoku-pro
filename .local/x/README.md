## 内容计划

| 内容 | 目的 | 形式与素材 | 当前状态 |
| --- | --- | --- | --- |
| 英文招募 | 给访客一个可直接加入的入口 | 一条主帖和两条自身回复；首图选真实分步提示截图 | 主帖已发布；两条回复仍为草稿 |
| 日语招募 | 补充约 3–5 名日语体验者 | 日语短帖和加入链接，强调提示文字与操作反馈 | 主帖已发布，纯文本 |
| 德语招募 | 补充约 3–5 名德语体验者 | 德语短帖和加入链接，强调逻辑提示、复盘与德语反馈 | 主帖已发布，纯文本 |
| 简体中文招募 | 收集中文表达与操作反馈 | 同一流程，针对中文用户改编文案与素材 | 待改编 |
| 提示演示 | 展示为什么下一步成立 | 真实短录屏或截图，一条内容只讲一个步骤 | 后续选素材 |
| 复盘演示 | 验证完成后回看操作的价值 | 真实操作回放；涉及推理时写“可能解释” | 后续选素材 |

第一轮以招募为主：先建立英文入口，再按实际需求发布其他语言版本，不在同一条帖子堆四种语言。回复使用对方的语言；普通开发进展以英语为主。是否需要独立语言账号，留到各语言有持续用户与内容需求时再判断。

完整招募计划包括主帖和两条说明回复；本次按用户要求先发布英文主帖。各语言稿都要保留开发者身份、免费无偿测试、加入步骤和反馈方式；两周指尽可能持续保持 Play opt-in，不要求连续两周每天玩。
