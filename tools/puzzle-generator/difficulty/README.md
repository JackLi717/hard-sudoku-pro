# 难度评价

HoDoKu2 生成候选，HSP C++ 引擎完成最终分级验收。也可从相关种子题调整给定数或做保持数独规则的局部答案交换，再验证唯一解和逻辑求解。

- 使用 L1 到目标等级必须能完整解出；低于目标等级的检测器用尽后必须停住。
- 每一步先用最低可用等级。定向训练时，在 L5 前沿中选择目标技巧；同级其他技巧可能有替代解，不能称为唯一方法。
- 同级排序使用 HSP 标准路径的固定原始人类负担分；最难步骤占主导，链类步骤
  另外计入证明节点、最大依赖深度、分支数和长链非线性成本。分数不参与升降级，
  也不依赖当前题库中的题目数量。
- 当前未上线基线直接替换旧分数，统一使用 `rating_version = "1"`，不维护并行
  评分解释器。
- 不完整解、多解题和含不支持技巧的路径不能入库。
- 按 AGENTS.md 直接更新当前开发基线；不为实验递增版本或建立历史审计归档。
