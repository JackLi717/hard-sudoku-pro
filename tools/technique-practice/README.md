# 技巧专项练习试点

首批只开放隐性唯一数与裸对。每项选一段真实盘面示范和三道来源独立的练习，入口仍在设置中的课程开发预览。用户可免费重试和查看当前题的证明，不影响普通游戏与挑战。

`manifest.json` 只选择现有 Hint Lab 例题 ID，不手工编辑盘面、候选或答案。运行 `npm run practice:build` 会从合法回放生成只读练习资源，并更新共用的 `content-allocations.json`。构建时重新运行 C++ 原生检查器验证唯一解、回放和目标证明，同时检查来源族与其他内容池的隔离。

隐性唯一数入口直接显示三道选题，不再先播放示范。每道题使用正式对局界面和游戏引擎处理填数、笔记、候选数、擦除与撤销；练习盘面只保存在当前页面，不计时、不扣积分、不写入普通游戏记录。候选数默认不显示。点击“检查答案”时，确认玩家最后填入的数字符合原题唯一解，且填入前是当前行、列或宫中的隐性唯一数；讲解根据实际填入的位置和数字生成。

裸对暂沿用原来的示范和选择交互：先选择两个模式格，再选择区域及一个可排除候选；每题只含一个排除目标。当前不保存练习完成记录，待选题与盘面交互验收后再接学习进度存储。
