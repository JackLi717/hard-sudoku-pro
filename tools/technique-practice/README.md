# 技巧专项练习试点

首批只开放隐性唯一数与裸对。每项选一段真实盘面示范和三道来源独立的练习，入口仍在设置中的课程开发预览。用户可免费重试和查看当前题的证明，不影响普通游戏与挑战。

`manifest.json` 保存每项技巧的目标题数和已锁定的例题 ID。增加题目时只提高 `targets` 中的 `exercise` 数量，再运行 `npm run practice:build`；脚本从 Hint Lab 的已验证真实盘面中选择来源独立的例题，为新题生成稳定 ID，并把选择写回当前清单。不要手工编辑盘面、候选或答案。构建器重新运行 C++ 原生检查器验证唯一解、回放和目标证明，同时检查来源族与其他内容池的隔离，最后生成只读练习资源。`python3 -m unittest discover -s tools/technique-practice -p test_*.py` 验证新增题目不会改变既有 ID。

App 从 `PracticeRepository` 查询题目，题目数据将起始盘面、答案和讲解证据分开；练习会话把起始盘面接入正式游戏引擎和棋盘。当前开发预览使用打包的 JSON，页面不依赖具体存储格式，也不写死题数。每次判题的正确／错误结果按稳定题目 ID 保存在 `user.sqlite` 的 `practice_progress` 表；同一 ID 的起始盘面或答案改变时，尝试计数重新开始。题目内容可随 App 更新，用户数据不随内容替换。课程正式发行时可在仓储接口后改用 `content.sqlite` 的独立练习表。

隐性唯一数入口直接显示三道选题，不再先播放示范。每道题使用正式对局界面和游戏引擎处理填数、笔记、候选数、擦除与撤销；练习盘面只保存在当前页面，不计时、不扣积分、不写入普通游戏记录。候选数默认不显示。点击“检查答案”时，确认玩家最后填入的数字符合原题唯一解，且填入前是当前行、列或宫中的隐性唯一数；讲解根据实际填入的位置和数字生成。

裸对暂沿用原来的示范和选择交互：先选择两个模式格，再选择区域及一个可排除候选；每题只含一个排除目标。裸对练习的正式棋盘交互留待下一步验收。
