Fish fins · Core Concepts

Fins are extra base candidates outside the selected cover lines. The teal 2 is a fin: it might be true, so ordinary fish eliminations cannot be used throughout the covers.

Definition

Fins are extra base candidates outside the selected cover lines. The teal 2 is a fin: it might be true, so ordinary fish eliminations cannot be used throughout the covers.

How to find it

First understand the basic fish, then find extras outside the covers. An elimination target must be on a cover, outside the bases, and see every fin.

Common mistake

There may be several fins; the target must see them all. Sharing a corner box helps in this diagram, but proximity alone is insufficient.

X-Wing · Row

Teaching board · local candidate diagram

Observe candidates

Look only at candidate 2, at r2c2, r2c8, r6c2, r6c8, r2c3; the line names can wait.

Verify the condition

Start from the blue row 2, row 6 and find every 2; each line must eventually contain one 2. These selected starting lines are the bases.

Draw the conclusion

The teal 2 at r2c3 is outside the covers: a fin; r1c2 is on a cover outside the bases and sees every fin, excluding 2. If every fin is false, the ordinary fish excludes 2 at r1c2. If any fin is true, r1c2 sees it and cannot contain 2 either. Both cases exclude only cover targets outside the bases that see every fin.
