裸结构 · 核心概念

同一区域中，N 个格子合起来恰好只有 N 种候选数字。这些数字只能占据这 N 格。

概念

同一区域中，N 个格子合起来恰好只有 N 种候选数字。这些数字只能占据这 N 格。

如何寻找

先选同一行、列或宫里的格子，再数它们全部候选的并集；两格两数是最简单的裸对。

容易误判

只看高亮候选不够；选中格子的全部候选若超过格子数，就不是这个裸结构。
