Kahulugan

Nagkikita ang dalawang cell kapag nagbahagi sila ng row, column o 3×3 box.

Paano ito mahahanap

Mula sa isang cell, lagyan ng tsek ang isa laban sa row, column at box nito.

Karaniwang pagkakamali

sa malapit o dayagonal ay hindi nagpapahiwatig ng visibility. Ang mga cell sa iba't ibang mga kahon ay maaari pa ring magbahagi ng isang row o column.

Lahat ng mga kapantay

Teaching board · diagram ng lokal na kandidato

Obserbahan ang mga kandidato

Magsimula sa reference cell r5c5; mga posisyon lang ang mahalaga, kaya walang mga digit na kailangan.

I-verify ang kundisyon

Ang 20 na may markang mga cell ay nagbabahagi ng row 5, column 5, kahon 5 sa reference; ibukod ang mismong reference at isang beses lang magbilang ng mga overlap.

Iguhit ang konklusyon

Ito ang mga kapantay ng reference cell, mayroon o walang mga digit; Ang paglalagay ng digit sa reference ay nag-aalis ng digit na iyon sa bawat peer.
