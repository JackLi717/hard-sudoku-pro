Kahulugan

Ang mga kandidato ng isang digit sa isang shared intersection ay maaaring kumilos bilang isang logical node. Ang tunay na grupo ay nangangahulugang kahit isang miyembro ay totoo.

Paano ito mahahanap

Ayusin ang isang digit at maghanap ng mga posisyong nagbabahagi ng parehong linya at kahon.

Karaniwang pagkakamali

Ang parehong-digit na mga kandidato na nakakalat sa mga kahon ay hindi isang intersection group.
