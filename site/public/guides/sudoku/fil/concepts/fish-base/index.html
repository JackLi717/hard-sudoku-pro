Mga linyang base ng fish pattern · Mga pangunahing konsepto

Base lines ay ang mga row o column na pinili upang siyasatin ang bawat kandidato ng isang digit. Ang mga asul na hilera ay ang panimulang punto: ang bawat isa ay dapat maglaman ng 2; sa bersyon ng column, magsimula sa mga asul na column.

Kahulugan

Base lines ay ang mga row o column na pinili upang siyasatin ang bawat kandidato ng isang digit. Ang mga asul na hilera ay ang panimulang punto: ang bawat isa ay dapat maglaman ng 2; sa bersyon ng column, magsimula sa mga asul na column.

Paano ito mahahanap

Tumutok sa 2 at hanapin ang bawat 2 sa bawat isa sa dalawa o tatlong asul na linya.

Karaniwang pagkakamali

Blue ang marka ng panimulang linya, hindi isang kumpletong isda. Susunod na suriin kung aling mga crossing lines ang naglalaman ng kanilang mga kandidato.

Obserbahan ang mga kandidato

Tumingin lamang sa kandidatong 2, sa r2c2, r2c8, r6c2, r6c8; maaaring maghintay ang mga pangalan ng linya.

I-verify ang kundisyon

Magsimula sa asul na row 2, row 6 at hanapin ang bawat 2; bawat linya ay dapat maglaman ng isang 2. Ang mga napiling panimulang linya ay ang mga base.

Iguhit ang konklusyon

Ang asul na row 2, row 6 ay ang mga panimulang linya; bawat 2 sa bawat isa ay ipinapakita.
