Kahulugan

Sa iisang rehiyon, ang lahat ng kandidato sa N kahon ay binubuo ng eksaktong N magkakaibang digit. Nakalaan ang mga digit na iyon para sa mga kahong iyon.

Paano ito mahahanap

Pumili ng mga kahon sa iisang hilera, kolum o bloke. Bilangin ang magkakaibang numero sa lahat ng kandidato ng mga kahong iyon; isang beses lamang bibilangin ang bawat numero.

Karaniwang pagkakamali

​​Bilangin ang bawat kandidato sa mga napiling cell. Higit pang mga natatanging digit kaysa sa mga cell na sinisira ang hubad na set na ito.
