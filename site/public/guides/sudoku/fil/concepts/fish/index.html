Kahulugan

Fish technique ay sinusuri ang mga posisyon ng isang digit. Sa pinakasimpleng X-Wing, maaaring ilagay ng dalawang row ang digit na iyon sa parehong dalawang column, kaya hindi ito mailalagay ng ibang row sa mga column na iyon. Ang apat na kandidato sa intersection ng row-column ay ang apat na sulok ng rectangle.

Paano ito mahahanap

Tumutok sa isang digit: pumili ng dalawang row na may eksaktong dalawang posisyon bawat isa, parehong nasa parehong dalawang column; pagkatapos ay makipagpalitan ng mga row at column.

Karaniwang pagkakamali

Suriin ang bawat kandidato sa mga napiling hanay, hindi lamang apat na kaakit-akit na sulok. Pinangalanan ng mga base at cover lines ang mga row at column na ito; ang mga sumusunod na konsepto ay nagpapaliwanag sa kanila.

X-Wing · Hilera

Teaching board · diagram ng lokal na kandidato

Obserbahan ang mga kandidato

Tumingin lamang sa kandidatong 2, sa r2c2, r2c8, r6c2, r6c8; maaaring maghintay ang mga pangalan ng linya.

I-verify ang kundisyon

Ang bawat napiling base, row 2, row 6, ay nangangailangan ng 2, at lahat ng kanilang 2 ay nasa column 2, column 8. Ang mga asul na panimulang linya ay tinatawag na mga base.

Iguhit ang konklusyon

Amber crossing lines ay tinatawag na mga cover. Ang 2 base ay nangangailangan ng 2 na mga kopya ng 2. Walang takip ang maaaring maglaman ng dalawa, kaya ang bawat takip ay inookupahan ng base 2. Ang target na r1c2 ay nasa isang takip sa labas ng mga base at nawawala ang 2.
