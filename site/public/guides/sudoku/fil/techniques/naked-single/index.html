Hakbang-hakbang na halimbawa
  • Kahon

Kilalanin ang pattern

Isang digit lang ang nananatiling posible sa isang cell pagkatapos mailapat ang mga panuntunan sa Sudoku.

Paano ito mahahanap

Pumili ng walang laman na cell at alisin ang mga digit na nakalagay na sa row, column, at box nito, o suriin ang mga marka ng lapis nito.

Ano ang pinapayagan nito

Punan ang cell ng nag-iisang natitirang kandidato.

Iwasan ang paghahalo

Ang cell ay hindi kailangang ang huling walang laman sa isang rehiyon. Ang isang Nag-iisang puwesto (Hidden Single) sa halip ay nagtatanong kung saan mapupunta ang isang digit sa loob ng isang rehiyon.

Hakbang-hakbang na halimbawa · Kahon

Asul: batayan. Berde: konklusyon. Mga numerong may guhit: inalis na kandidato. Ang R1C1 ay hilera 1, hanay 1.

Hakbang 1 · Lagyan ng check ang row, column at box

R2C2: ang mga napunong digit sa row, column at box nito ay nag-alis ng 1, 2, 3, 5, 6, 7, 8, 9, na naiwan lamang ang kandidatong 4.

Hakbang 2 · Konklusyon

Ang cell na ito ay dapat na 4.

Ano ang pinapayagan nito

Ang cell na ito ay dapat na 4.
