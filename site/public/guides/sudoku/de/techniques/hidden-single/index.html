Versteckter Single · Beispiel Schritt für Schritt

Für eine Zahl bleibt in einer Zeile, Spalte oder einem Block nur eine mögliche Zelle. Diese Zelle darf noch andere Kandidaten haben. Trage die Zahl in die einzige verbleibende Zelle dieser Einheit ein.

Muster erkennen

Für eine Zahl bleibt in einer Zeile, Spalte oder einem Block nur eine mögliche Zelle. Diese Zelle darf noch andere Kandidaten haben.

So findest du es

Wähle eine Zahl und prüfe einen Block, eine Zeile oder Spalte. Bereits gesetzte gleiche Zahlen schließen andere Zellen aus.

Das folgt daraus

Trage die Zahl in die einzige verbleibende Zelle dieser Einheit ein.

Verwechslung vermeiden

Beim Naked Single bleibt in einer Zelle nur ein Kandidat. Beim Hidden Single bleibt für eine Zahl in einer Einheit nur ein Platz. Prüfe vorher die ganze Einheit.
