Muster erkennen

Nach Anwendung der Sudoku-Regeln bleibt in einer Zelle nur eine mögliche Zahl.

So findest du es

Wähle eine leere Zelle. Schließe Zahlen aus ihrer Zeile, Spalte und ihrem Block aus oder prüfe ihre Kandidaten.

Das folgt daraus

Trage den einzigen verbleibenden Kandidaten in die Zelle ein.

Verwechslung vermeiden

Die Zelle muss nicht die letzte freie in einer Einheit sein. Beim Hidden Single bleibt für eine Zahl nur ein Platz in einer Einheit.
