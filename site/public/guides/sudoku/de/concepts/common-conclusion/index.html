Begriff

Ein Ergebnis aller möglichen Zweige gilt unabhängig von ihrer Auswahl.

So findest du es

Notiere Folgen je Zweig und suche das gemeinsame Ergebnis.

Häufiger Fehler

Eine Entfernung aus nur einem Zweig ist kein gemeinsamer Schluss.
