Définition

Les deux extrémités ne peuvent pas être fausses en même temps : si l’une est fausse, l’autre doit être vraie. Un chiffre limité à deux positions dans une unité, ou une case à deux candidats, peut fournir cette relation.

Comment le trouver

Vérifiez qu'un chiffre n'a que deux positions dans une région ou qu'une case n'a que deux chiffres candidats.

Erreur courante

Se voir est insuffisant. Une troisième possibilité permet que les deux extrémités soient fausses.
