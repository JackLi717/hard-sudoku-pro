Chiffres de candidat verrouillés · Notions clés

Pour Pointing, tous les candidats d’un chiffre dans un bloc sont sur une même ligne ou colonne : supprimez ce chiffre sur le reste de cette ligne ou colonne, hors du bloc. Pour Claiming, tous les candidats d’un chiffre sur une ligne ou colonne sont dans un même bloc : supprimez ce chiffre dans les autres cases de ce bloc, hors de cette ligne ou colonne.

Définition

Pour Pointing, tous les candidats d’un chiffre dans un bloc sont sur une même ligne ou colonne : supprimez ce chiffre sur le reste de cette ligne ou colonne, hors du bloc. Pour Claiming, tous les candidats d’un chiffre sur une ligne ou colonne sont dans un même bloc : supprimez ce chiffre dans les autres cases de ce bloc, hors de cette ligne ou colonne.

Comment le trouver

Choisissez le bloc ou la ligne source 3 × 3, comptez chaque position du chiffre, puis vérifiez si elles se trouvent toutes à son intersection avec l'autre région.

Erreur courante

Une position source en dehors de cette intersection empêche l’élimination revendiquée.

Observer les chiffres des candidats

Pour Pointing, tous les candidats d’un chiffre dans un bloc sont sur une même ligne ou colonne : supprimez ce chiffre sur le reste de cette ligne ou colonne, hors du bloc. Pour Claiming, tous les candidats d’un chiffre sur une ligne ou colonne sont dans un même bloc : supprimez ce chiffre dans les autres cases de ce bloc, hors de cette ligne ou colonne.

Vérifier l'état

Choisissez le bloc ou la ligne source 3 × 3, comptez chaque position du chiffre, puis vérifiez si elles se trouvent toutes à son intersection avec l'autre région.

Tirer la conclusion

Tous les chiffres candidats sources se trouvent dans l'intersection de la ligne de bloc 3 × 3, de sorte que la cible dans l'autre partie de la région affectée peut être supprimée.
