Aperçu des poissons · Notions clés

Définition

Les techniques de poissons examinent les positions d'un chiffre. Dans le X-Wing le plus simple, deux lignes ne peuvent placer ce chiffre que dans les deux mêmes colonnes, de sorte que les autres lignes ne peuvent pas le placer dans ces colonnes. Les quatre chiffres candidats aux intersections ligne-colonne sont les quatre coins du rectangle.

Comment le trouver

Concentrez-vous sur un chiffre : choisissez deux lignes avec exactement deux positions chacune, toutes deux dans les mêmes deux colonnes ; puis échangez des lignes et des colonnes.

Erreur courante

Vérifiez chaque chiffre candidat dans les lignes choisies, pas seulement quatre coins attrayants. Les lignes de base et de couverture nomment ces lignes et colonnes ; les concepts suivants les expliquent.

X-Wing · Ligne

Conseil pédagogique · diagramme des chiffres du candidat local

Observer les chiffres des candidats

Regardez uniquement le chiffre candidat 2, à r2c2, r2c8, r6c2, r6c8 ; les noms de lignes peuvent attendre.

Vérifier l'état

Chaque base sélectionnée, rangée 2, rangée 6, a besoin d'un 2, et tous leurs chiffres candidats 2 se trouvent dans colonne 2, colonne 8. Les lignes de départ bleues sont appelées lignes de base.

Tirer la conclusion

Les lignes de croisement ambrées sont appelées lignes de couverture. Les lignes de base 2 nécessitent des copies 2 de 2. Aucune ligne de recouvrement ne peut en contenir deux, chaque ligne de recouvrement est donc occupée par une base 2. La cible r1c2 est située sur une ligne de couverture en dehors des lignes de base et perd 2.

X-Wing · Colonne

Conseil pédagogique · diagramme des chiffres du candidat local

Observer les chiffres des candidats

Regardez uniquement le chiffre candidat 2, à r2c2, r8c2, r2c6, r8c6 ; les noms de lignes peuvent attendre.

Vérifier l'état

Chaque base sélectionnée, colonne 2, colonne 6, a besoin d'un 2, et tous leurs chiffres candidats 2 se trouvent dans rangée 2, rangée 8. Les lignes de départ bleues sont appelées lignes de base.

Tirer la conclusion

Les lignes de croisement ambrées sont appelées lignes de couverture. Les lignes de base 2 nécessitent des copies 2 de 2. Aucune ligne de recouvrement ne peut en contenir deux, chaque ligne de recouvrement est donc occupée par une base 2. La cible r2c1 est située sur une ligne de couverture en dehors des lignes de base et perd 2.
