Définition

Les deux extrémités ne peuvent pas être vraies en même temps : si l’une est vraie, l’autre doit être fausse.

Comment le trouver

Vérifiez les chiffres candidats identiques qui se voient, ou les chiffres distincts dans une case.

Erreur courante

Un lien d’inférence faible ne nécessite pas qu’une des deux extrémités soit vraie. Les chiffres candidats non liés n'ont aucun lien.
