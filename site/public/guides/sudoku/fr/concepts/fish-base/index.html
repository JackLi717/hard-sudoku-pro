Lignes de base du poisson · Notions clés

Les lignes de base sont les lignes ou les colonnes choisies pour inspecter chaque chiffre candidat d'un chiffre. Les lignes bleues sont le point de départ : chacune doit éventuellement contenir un 2 ; dans la version colonnes, commencez par les colonnes bleues.

Définition

Les lignes de base sont les lignes ou les colonnes choisies pour inspecter chaque chiffre candidat d'un chiffre. Les lignes bleues sont le point de départ : chacune doit éventuellement contenir un 2 ; dans la version colonnes, commencez par les colonnes bleues.

Comment le trouver

Concentrez-vous sur 2 et trouvez tous les 2 dans chacune des deux ou trois lignes bleues.

Erreur courante

Le bleu marque les lignes de départ, pas un poisson terminé. Vérifiez ensuite quelles lignes croisées contiennent leurs chiffres candidats.

X-Wing · Ligne

Conseil pédagogique · diagramme des chiffres du candidat local

Observer les chiffres des candidats

Regardez uniquement le chiffre candidat 2, à r2c2, r2c8, r6c2, r6c8 ; les noms de lignes peuvent attendre.

Vérifier l'état

Commencez par le rangée 2, rangée 6 bleu et trouvez chaque 2 ; chaque ligne doit éventuellement contenir un 2. Ces lignes de départ sélectionnées sont les lignes de base.

Tirer la conclusion

Les rangée 2, rangée 6 bleues sont les lignes de départ ; chaque 2 sur chacun est affiché.
