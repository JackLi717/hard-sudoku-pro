Nœuds de candidats groupés · Notions clés

les chiffres candidats d'un chiffre dans une intersection partagée peuvent agir comme un nœud logique. Un vrai groupe signifie qu'au moins un membre est vrai.

Définition

les chiffres candidats d'un chiffre dans une intersection partagée peuvent agir comme un nœud logique. Un vrai groupe signifie qu'au moins un membre est vrai.

Comment le trouver

Corrigez un chiffre et trouvez des positions partageant à la fois une ligne et un bloc 3×3.

Erreur courante

Les chiffres candidats de même chiffre dispersés sur des blocs 3 × 3 ne constituent pas un groupe d'intersection.

Vérifier l'état

Tirer la conclusion

Les chiffres candidats marqués partagent une intersection de bloc ligne 3 × 3, ils peuvent donc former un nœud groupé.
