Définition

Une case à deux candidats contient exactement deux chiffres possibles. L’un de ces deux chiffres sera sa valeur finale.

Comment le trouver

Comptez tous les chiffres candidats dans une case vide.

Erreur courante

Comptez chaque note dans la case. Un chiffre candidat, trois ou plus n'est pas une bivaleur.
