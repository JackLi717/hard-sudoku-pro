Platon Sudoku · Apprendre le sudoku

Ensembles nus · Notions clés

Dans une même unité, l’ensemble des candidats de N cases contient exactement N chiffres distincts. Ces chiffres sont réservés à ces cases.

Ce cours est adapté des leçons de l’application Platon Sudoku. Lisez ici l’exemple complet, puis poursuivez l’apprentissage et la pratique dans l’application.

Définition

Dans une même unité, l’ensemble des candidats de N cases contient exactement N chiffres distincts. Ces chiffres sont réservés à ces cases.

Comment le trouver

Choisissez des cases dans une même ligne, colonne ou bloc. Comptez les chiffres distincts présents parmi tous leurs candidats, en comptant chaque chiffre une seule fois.

Erreur courante

Comptez chaque chiffre candidat dans les cases sélectionnées. Des chiffres plus distincts que les cases brisent cet ensemble nu.
