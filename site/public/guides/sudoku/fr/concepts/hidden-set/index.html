Platon Sudoku · Apprendre le sudoku

Ensembles cachés · Notions clés

Dans une même unité, N chiffres ne peuvent apparaître que dans N cases, même si ces cases contiennent d’autres candidats.

Ce cours est adapté des leçons de l’application Platon Sudoku. Lisez ici l’exemple complet, puis poursuivez l’apprentissage et la pratique dans l’application.

Définition

Dans une même unité, N chiffres ne peuvent apparaître que dans N cases, même si ces cases contiennent d’autres candidats.

Comment le trouver

Choisissez les chiffres et comptez chaque place qu'ils peuvent occuper dans toute la région.

Erreur courante

Vérifiez toute la région. Un chiffre sélectionné en dehors des cases en surbrillance brise cet ensemble caché.
