Reconnaître le modèle

Trois cases dans une ligne – bloc 3 × 3 ou colonne – intersection de blocs 3 × 3 ne contiennent que trois chiffres entre elles.

Comment le trouver

Vérifiez les trois cases où une ligne ou une colonne traverse un bloc 3×3. Recherchez un ensemble combiné d’exactement trois chiffres candidats.

Ce qu'il permet

Supprimez ces trois chiffres de toutes les autres cases de la ligne partagée et du bloc 3×3.

Évitez les confusions

Les trois cases n'ont pas besoin d'avoir des chiffres candidats identiques. Chaque chiffre candidat doit appartenir au même ensemble de trois chiffres.

Exemple étape par étape · Ligne

Cet exemple part d’une position intermédiaire enregistrée. Les candidats intègrent des éliminations logiques antérieures et ne sont pas des notes automatiques nouvellement générées.

Bleu : indices. Vert : conclusion. Chiffres barrés : candidats éliminés. R1C1 signifie ligne 1, colonne 1.

Étape 1 · Observez le triple

Ces trois cases ne peuvent utiliser que 1, 7, 8. Chaque chiffre doit occuper une case.

Étape 2 · Voir les régions partagées

Ces trois cases se trouvent à la fois dans rangée 5 et bloc 5, les trois chiffres sont donc réservés dans les deux régions.

Étape 3 · Supprimer les chiffres des candidats

Supprimez les chiffres candidats 7 marqués des autres cases de rangée 5 et bloc 5.

Ce qu'il permet
