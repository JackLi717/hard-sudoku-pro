Reconnaître le modèle

Deux liens d'inférence forts pour un chiffre se connectent via un lien d'inférence faible ; la forme peut ressembler à un Skyscraper, à un cerf-volant ou à un Rectangle vide (Empty Rectangle).

Comment le trouver

Tracez deux liens d'inférence forts et leur connexion faible. Identifiez les deux points de terminaison externes avant de rechercher une cible partagée.

Ce qu'il permet

Supprimez le chiffre de tout chiffre candidat qui voit les deux points de terminaison externes.

Évitez les confusions

Deux paires en surbrillance ne suffisent pas sans une connexion faible valide. Un chiffre candidat ne voyant qu’une seule extrémité extérieure ne peut pas être supprimé.

Exemple étape par étape · Skyscraper

Cet exemple part d’une position intermédiaire enregistrée. Les candidats intègrent des éliminations logiques antérieures et ne sont pas des notes automatiques nouvellement générées.

Bleu : indices. Vert : conclusion. Chiffres barrés : candidats éliminés. R1C1 signifie ligne 1, colonne 1.

Étape 1 · Voir la chaîne partagée à quatre chiffres candidats

Turbot Fish est le nom générique d'une chaîne X à quatre chiffres candidats. Skyscraper, Two-String Kite et un chiffre à deux candidats Rectangle vide (Empty Rectangle) sont nommés mises en page de cette même chaîne. Suivez les quatre cercles pour 3.

Étape 2 · Deux places dans rangée 3

Dans rangée 3, 3 ne peut aller que dans R3C1 ou R3C5. L’un d’eux doit être 3.

Étape 3 · Deux places dans rangée 8

Dans rangée 8, 3 ne peut aller que dans R8C2 ou R8C5. L’un d’eux doit être 3.

Étape 4 · Connectez les deux liens d'inférence forts

R3C5 et R8C5 se voient dans colonne 5. Ils forment le lien d’inférence faible : ils ne peuvent pas être tous les deux 3. Cette mise en page est Skyscraper ; nous voyons ici sa chaîne Turbot Fish partagée.

Étape 5 · Essayez une hypothèse

Et si R7C1 était 3 ? Numéros marqués ? font partie de cette hypothèse, et non des réponses confirmées. R3C1 partage colonne 1 avec R7C1, il ne peut donc pas également s'agir de 3. R8C2 partage bloc 7 avec R7C1, il ne peut donc pas également s'agir de 3.

Étape 6 · Deux chiffres identiques dans une région

R3C1 ne peut pas être 3, il ne reste donc plus que rangée 3 à R3C5. Dans cette hypothèse, il doit s'agir de 3. R8C2 ne peut pas être 3, donc rangée 8 force R8C5 à être 3. Mais R3C5 et R8C5 partagent colonne 5 : cela mettrait 3 là deux fois !

Étape 7 · L'hypothèse ne peut pas être vraie

Pour chaque cible, en supposant que 3 répète ce chiffre dans colonne 5. Supprimez le chiffre candidat 3 de R7C1 ; toutes les hypothèses temporaires sont retirées.

Ce qu'il permet

Pour chaque cible, en supposant que 3 répète ce chiffre dans colonne 5. Supprimez le chiffre candidat 3 de R7C1 ; toutes les hypothèses temporaires sont retirées.
