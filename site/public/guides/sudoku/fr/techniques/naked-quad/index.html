Quadruplet nu (Naked Quad) · Exemple étape par étape

Quatre cases dans une ligne, une colonne ou un bloc 3×3 ne contiennent que quatre chiffres entre elles. Supprimez ces quatre chiffres de toutes les autres cases de cette région.

Reconnaître le modèle

Quatre cases dans une ligne, une colonne ou un bloc 3×3 ne contiennent que quatre chiffres entre elles.

Comment le trouver

Comparez quatre cases avec de courtes listes de chiffres candidats dans une région. Leur ensemble combiné doit contenir exactement quatre chiffres.

Ce qu'il permet

Supprimez ces quatre chiffres de toutes les autres cases de cette région.

Évitez les confusions

Un quad n’est pas constitué de quatre listes de chiffres candidats identiques. Aucune case sélectionnée ne peut contenir un cinquième chiffre et les quatre cases doivent partager une région.

Bleu : indices. Vert : conclusion. Chiffres barrés : candidats éliminés. R1C1 signifie ligne 1, colonne 1.

Étape 1 · Observez le quad

Ensemble, ces quatre cases n'ont que 2, 4, 7, 9 comme chiffres candidats.

Étape 2 · Comprendre la réservation

Les chiffres ne peuvent pas se répéter dans rangée 9, ces quatre chiffres doivent donc occuper chacun une case.

Étape 3 · Supprimer les chiffres des candidats

Supprimez les chiffres candidats 2, 4, 7 marqués des autres cases de rangée 9.
