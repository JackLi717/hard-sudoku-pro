XYZ-Wing · Exemple étape par étape

Un pivot à trois chiffres candidats {X,Y,Z} voit deux ailes à deux chiffres candidats {X,Z} et {Y,Z}. Supprimez Z uniquement d’une case qui voit le pivot et les deux ailes.

Ce cours est adapté des leçons de l’application Platon Sudoku. Lisez ici l’exemple complet, puis poursuivez l’apprentissage et la pratique dans l’application.

Reconnaître le modèle

Un pivot à trois chiffres candidats {X,Y,Z} voit deux ailes à deux chiffres candidats {X,Z} et {Y,Z}.

Comment le trouver

Trouvez une case à trois chiffres candidats et deux ailes qui conservent chacune Z plus un autre chiffre pivot différent.

Ce qu'il permet

Supprimez Z uniquement d’une case qui voit le pivot et les deux ailes.

Évitez les confusions

C'est plus strict que XY-Wing : une cible ne voyant que les ailes peut toujours être valide. Vérifiez les trois lignes de vue.

Exemple étape par étape · Lien de ligne

Cet exemple part d’une position intermédiaire enregistrée. Les candidats intègrent des éliminations logiques antérieures et ne sont pas des notes automatiques nouvellement générées.

Bleu : indices. Vert : conclusion. Chiffres barrés : candidats éliminés. R1C1 signifie ligne 1, colonne 1.

Étape 1 · Trouver le pivot et les ailes

R5C9 est le pivot à trois chiffres candidats 2, 7, 9. Il voit les deux ailes : R5C4 avec 2, 9 et R6C9 avec 2, 7. Ensemble, ils forment un XYZ-Wing.

Étape 2 · Trouvez la cible partagée par les trois

Le pivot et les deux ailes contiennent du 2. Chaque cible (R5C8=2) voit les trois emplacements possibles de 2.

Étape 3 · Cas 1 : R5C9 est 7

Si R5C9=7, R6C9 ne peut pas être 7 et doit être 2. Chaque cible (R5C8=2) voit le 2 actuel dans R6C9, supprimez donc le chiffre candidat 2 de ces cibles.

Étape 4 · Cas 2 : R5C9 est 9

Si R5C9=9, R5C4 ne peut pas être 9 et doit être 2. Chaque cible (R5C8=2) voit le 2 actuel dans R5C4, supprimez donc le chiffre candidat 2 de ces cibles.

Étape 5 · Cas 3 : le pivot est 2

Si R5C9=2, le pivot lui-même fournit déjà 2. Il s’agit de la troisième et dernière valeur pivot. Chaque cible (R5C8=2) voit le 2 actuel dans le pivot, supprimez donc le chiffre candidat 2 de ces cibles.

Étape 6 · Combinez les trois cas

Pour chaque valeur pivot possible, l’une des valeurs R5C4, R5C9, R6C9 est 2. Chaque cible voit les trois cases, supprimez donc R5C8=2.

Ce qu'il permet

Pour chaque valeur pivot possible, l’une des valeurs R5C4, R5C9, R6C9 est 2. Chaque cible voit les trois cases, supprimez donc R5C8=2.
