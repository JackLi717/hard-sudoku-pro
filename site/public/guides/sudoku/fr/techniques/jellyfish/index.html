Reconnaître le modèle

Pour un chiffre, tous les chiffres candidats des quatre lignes de base se trouvent dans quatre colonnes de couverture. Les lignes et les colonnes peuvent être échangées.

Comment le trouver

Scannez un seul chiffre sur quatre lignes ou colonnes ; comptez chaque chiffre candidat dans les lignes de base sélectionnées et confirmez que seules quatre lignes de couverture sont utilisées.

Ce qu'il permet

Supprimez ce chiffre des lignes de couverture en dehors des quatre lignes de base.

Évitez les confusions

Quatre lignes tracées à elles seules ne constituent pas un poisson. Chaque chiffre candidat dans chaque base doit être situé sur une ligne de couverture choisie.

Bleu : indices. Vert : conclusion. Chiffres barrés : candidats éliminés. R1C1 signifie ligne 1, colonne 1.

Étape 1 · Reconnaître le Jellyfish

Chacune des quatre lignes de base (rangée 2, rangée 3, rangée 6, rangée 7) a toujours besoin de 2, et tous ses chiffres candidats encerclés se trouvent dans les mêmes quatre lignes de couverture (colonne 3, colonne 4, colonne 7, colonne 8). La légende « Lignes de base » marque les quatre lignes de base et « Lignes de couverture » marque les quatre lignes de couverture. Ensemble, ils forment le Jellyfish.

Étape 2 · Chaque ligne de couverture doit être occupée une fois

Les quatre lignes de base doivent placer quatre 2 au total. Une ligne de couverture ne peut pas contenir le chiffre deux fois, et les quatre emplacements sont limités à ces quatre lignes de couverture. Les emplacements occupent donc chaque ligne de couverture exactement une fois.

Étape 3 · Supprimer les chiffres candidats en dehors des lignes de base

Chaque ligne de revêtement reçoit déjà son 2 de l'une des quatre lignes de base. Par conséquent, les chiffres candidats dans les lignes de couverture mais en dehors des lignes de base ne peuvent pas être 2 ; supprimez R4C4=2, R9C7=2, R9C8=2.

Ce qu'il permet

Chaque ligne de revêtement reçoit déjà son 2 de l'une des quatre lignes de base. Par conséquent, les chiffres candidats dans les lignes de couverture mais en dehors des lignes de base ne peuvent pas être 2 ; supprimez R4C4=2, R9C7=2, R9C8=2.
