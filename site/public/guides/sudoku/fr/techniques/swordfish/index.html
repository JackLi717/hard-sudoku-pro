Reconnaître le modèle

Pour un chiffre, toutes ses positions sur trois lignes tiennent dans les trois mêmes colonnes. Les lignes et les colonnes peuvent être échangées.

Comment le trouver

Parcourez un chiffre sur des lignes comportant deux ou trois chiffres candidats. Trouvez trois lignes dont les colonnes de chiffres candidats combinées comptent exactement trois.

Ce qu'il permet

Supprimez ce chiffre des trois colonnes de couverture en dehors des lignes sélectionnées.

Évitez les confusions

Il n'est pas nécessaire que les chiffres candidats forment neuf coins. Vérifiez chaque position dans chaque ligne sélectionnée : aucun chiffre candidat ne peut se trouver en dehors des trois colonnes de couverture.

Cet exemple part d’une position intermédiaire enregistrée. Les candidats intègrent des éliminations logiques antérieures et ne sont pas des notes automatiques nouvellement générées.

Bleu : indices. Vert : conclusion. Chiffres barrés : candidats éliminés. R1C1 signifie ligne 1, colonne 1.

Étape 1 · Reconnaître le Swordfish

Les trois lignes de base (rangée 3, rangée 5, rangée 8) ont toutes encore besoin de 6, et chaque chiffre candidat 6 restant se trouve dans les trois mêmes lignes de couverture (colonne 2, colonne 3, colonne 8). Cela forme un Swordfish.

Étape 2 · Découvrez pourquoi les lignes de couverture sont occupées

Chaque base doit placer un 6, pour un total de trois placements. Une ligne de couverture ne peut pas contenir deux chiffres identiques. Puisque chaque placement est limité à ces trois lignes de couverture, les trois placements doivent occuper chacun une ligne de couverture.

Étape 3 · Supprimer les cibles

Par conséquent, 6 dans les trois lignes de couverture doit être placé à l’intérieur des lignes de base. Supprimez les chiffres candidats marqués en dehors des lignes de base : R9C3=6.

Ce qu'il permet

Par conséquent, 6 dans les trois lignes de couverture doit être placé à l’intérieur des lignes de base. Supprimez les chiffres candidats marqués en dehors des lignes de base : R9C3=6.
