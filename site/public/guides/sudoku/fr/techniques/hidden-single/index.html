Reconnaître le modèle

Un chiffre n'a qu'une seule case possible dans une ligne, une colonne ou un bloc 3×3. La case peut toujours afficher d'autres chiffres candidats.

Comment le trouver

Choisissez un chiffre et numérisez un bloc, une ligne ou une colonne 3 × 3. Éliminez les cases qui voient une copie déjà placée de ce chiffre.

Ce qu'il permet

Mettez le chiffre dans la seule case restante de cette région.

Évitez les confusions

Un Singleton nu (Naked Single) a un chiffre candidat dans une case. Un Singleton caché (Hidden Single) a une place pour un chiffre dans une région. Vérifiez chaque case de cette région avant de la placer.
