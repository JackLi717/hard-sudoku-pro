Finned X-Wing · Exemple étape par étape

Un X-Wing a un chiffre candidat supplémentaire dans une ligne ou une colonne de base. L'nageoire se trouve dans le même bloc 3×3 qu'un coin de base. Supprimez le chiffre uniquement là où la cible partage une colonne de ligne de couverture avec le X-Wing et voit l'nageoire dans son bloc 3×3.

Reconnaître le modèle

Un X-Wing a un chiffre candidat supplémentaire dans une ligne ou une colonne de base. L'nageoire se trouve dans le même bloc 3×3 qu'un coin de base.

Comment le trouver

Trouvez deux lignes de base et deux colonnes de couverture, puis recherchez un chiffre candidat supplémentaire à côté d'un coin dans son bloc 3×3.

Ce qu'il permet

Supprimez le chiffre uniquement là où la cible partage une colonne de ligne de couverture avec le X-Wing et voit l'nageoire dans son bloc 3×3.

Évitez les confusions

N'effacez pas toute la colonne de la ligne de recouvrement. La cible doit voir la nageoire ; vérifiez tous les chiffres candidats de base et le bloc 3×3 partagé.

Exemple étape par étape · Ligne

Cet exemple part d’une position intermédiaire enregistrée. Les candidats intègrent des éliminations logiques antérieures et ne sont pas des notes automatiques nouvellement générées.

Bleu : indices. Vert : conclusion. Chiffres barrés : candidats éliminés. R1C1 signifie ligne 1, colonne 1.

Étape 1 · Construisez le corps complet du poisson

Pour 9, les deux lignes de base (rangée 5, rangée 7) et les deux lignes de couverture (colonne 3, colonne 5) définissent les quatre chiffres candidats du corps R5C3=9, R5C5=9, R7C3=9, R7C5=9. Les chiffres candidats supplémentaires R7C4=9 sont des nageoires dans bloc 8. Les cibles R8C5=9, R9C5=9 se trouvent dans une ligne de couverture en dehors des lignes de base.

Étape 2 · Séparez les nageoires du corps

Les chiffres candidats indiqués R7C4=9 sont les nageoires de bloc 8 ; les quatre autres chiffres candidats R5C3=9, R5C5=9, R7C3=9, R7C5=9 sont le corps X-Wing. Vérifiez maintenant les deux possibilités : une nageoire est vraie, ou chaque nageoire est fausse.

Étape 3 · Supposons que la fin 1 est vraie

Si l'nageoire R7C4=9 est vrai, chaque cible marquée R8C5=9, R9C5=9 la voit dans bloc 8, donc ces cibles ne peuvent pas être 9.

Étape 4 · Cas : chaque nageoire est faux

Si chaque nageoire R7C4=9 est faux, les quatre chiffres candidats du corps R5C3=9, R5C5=9, R7C3=9, R7C5=9 forment une aile X ordinaire à travers les deux lignes de base (rangée 5, rangée 7) et les deux lignes de couverture (colonne 3, colonne 5). Les cibles R8C5=9, R9C5=9 se trouvent dans une ligne de couverture en dehors des lignes de base, donc le X-Wing les exclut.

Étape 5 · Appliquer les deux conditions cibles

Une cible valide doit satisfaire aux deux conditions : elle se trouve dans une ligne de couverture X-Wing en dehors des deux lignes de base et elle voit chaque nageoire. Les cibles R8C5=9, R9C5=9 satisfont aux deux, supprimez donc le chiffre candidat 9.

Ce qu'il permet

Une cible valide doit satisfaire aux deux conditions : elle se trouve dans une ligne de couverture X-Wing en dehors des deux lignes de base et elle voit chaque nageoire. Les cibles R8C5=9, R9C5=9 satisfont aux deux, supprimez donc le chiffre candidat 9.
