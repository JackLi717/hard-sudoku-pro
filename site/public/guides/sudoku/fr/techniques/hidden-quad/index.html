Quadruplet caché (Hidden Quad) · Exemple étape par étape

Dans une ligne, une colonne ou un bloc 3×3, quatre chiffres n'ont des positions possibles que dans les quatre mêmes cases. Supprimez tous les autres chiffres candidats de ces quatre cases.

Reconnaître le modèle

Dans une ligne, une colonne ou un bloc 3×3, quatre chiffres n'ont des positions possibles que dans les quatre mêmes cases.

Comment le trouver

Choisissez quatre chiffres dans une région et vérifiez si toutes leurs positions restantes tiennent dans quatre cases.

Ce qu'il permet

Supprimez tous les autres chiffres candidats de ces quatre cases.

Évitez les confusions

Les quatre cases peuvent d'abord afficher des chiffres candidats supplémentaires. Vérifiez les positions des quatre chiffres dans toute la région, pas seulement les cases marquées.
