Reconnaître le modèle

Un seul chiffre reste possible dans une case après application des règles du Sudoku.

Comment le trouver

Choisissez une case vide et excluez les chiffres déjà placés dans sa ligne, sa colonne et son bloc 3×3, ou inspectez ses marques de crayon.

Ce qu'il permet

Remplissez la case avec son seul chiffre candidat restant.

Évitez les confusions

Il n'est pas nécessaire que la case soit la dernière vide dans une région. Un Singleton caché (Hidden Single) demande à la place où peut aller un chiffre dans une région.

Exemple étape par étape · Case

Bleu : indices. Vert : conclusion. Chiffres barrés : candidats éliminés. R1C1 signifie ligne 1, colonne 1.

Étape 1 · Vérifiez la ligne, la colonne et le bloc 3×3

R2C2 : les chiffres remplis dans sa ligne, sa colonne et son bloc 3 × 3 excluent 1, 2, 3, 5, 6, 7, 8, 9, ne laissant que le chiffre candidat 4.

Étape 2 · Conclusion

Cette case doit être 4.
