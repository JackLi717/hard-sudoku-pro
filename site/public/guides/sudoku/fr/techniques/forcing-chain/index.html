Chaîne de forçage (Forcing Chain) · Exemple étape par étape

Reconnaître le modèle

Un ensemble exhaustif d’alternatives de chiffres candidats est suivi à travers des chaînes d’implication linéaires distinctes.

Comment le trouver

Choisissez une répartition vrai/faux ou toutes les positions d'un chiffre dans une région ; suivez chaque branche jusqu'à sa conséquence vérifiée.

Ce qu'il permet

Ne conservez qu'un placement ou une élimination partagé par chaque branche viable.

Évitez les confusions

Une seule branche parvenant à un résultat est insuffisante ; les alternatives de départ doivent couvrir toutes les possibilités.

Exemple étape par étape · Deux succursales

Cet exemple part d’une position intermédiaire enregistrée. Les candidats intègrent des éliminations logiques antérieures et ne sont pas des notes automatiques nouvellement générées.

Bleu : indices. Vert : conclusion. Chiffres barrés : candidats éliminés. R1C1 signifie ligne 1, colonne 1.

Étape 1 · Où chercher

Le résultat commun à prouver est R1C2=7 ; le commutateur de dérivation est R1C2=5. Tout chiffre candidat est vrai ou faux, ces deux branches couvrent donc toutes les possibilités. Si les deux atteignent le résultat commun, ce résultat est forcé.

Étape 2 · Raisonnement

Branche 1 : supposons que R1C2=5 soit vrai.

Étape 3 · Raisonnement

R1C2=5 est vrai. Supprimez R1C2=7.

Étape 5 · Raisonnement

Branche 2 : supposons que R1C2=5 soit faux.

Étape 6 · Raisonnement

R1C2=5 est faux. Ensemble, ces deux côtés contiennent toutes les options restantes du rangée 1. Par conséquent, R1C5=5 doit être vrai.

Étape 7 · Raisonnement

R1C5=5 est vrai. Supprimez R2C5=5 de colonne 5.

Étape 8 · Raisonnement

R2C5=5 est faux. Ensemble, ces deux côtés contiennent toutes les options restantes du rangée 2. Par conséquent, R2C8=5 doit être vrai.

Étape 9 · Raisonnement

R2C8=5 est vrai. Supprimez R2C8=9.

Étape 10 · Raisonnement

R2C8=9 est faux. Ensemble, ces deux côtés contiennent toutes les options restantes du rangée 2. Par conséquent, R2C4=9 doit être vrai.

Étape 11 · Raisonnement

R2C4=9 est vrai. Supprimez R1C4=9 de colonne 4.

Étape 12 · Raisonnement

R1C4=9 est faux. Il ne reste plus que R1C4 à R1C4=7, cela doit donc être vrai.

Étape 13 · Raisonnement

R1C4=7 est vrai. Supprimez R1C2=7 de rangée 1.

Étape 14 · Raisonnement

Chaque branchement possible atteint le même fait : R1C2=7 est faux. Après avoir retiré toutes les hypothèses, ce fait reste certain.

Étape 15 · Conclusion

Le résultat vérifié est R1C2=7 est faux. Toutes les hypothèses temporaires ont été retirées.

Ce qu'il permet

Bleu : indices. Vert : conclusion. Chiffres barrés : candidats éliminés. R1C1 signifie ligne 1, colonne 1.

Étape 1 · Où chercher

Les racines R2C4=2, R2C4=3, R2C4=6, R2C4=7 correspondent à tous les chiffres candidats possibles dans R2C4. Suivez chacun comme une chaîne d’implication linéaire distincte ; si chaque racine atteint R2C6=3, ce résultat est forcé. Plusieurs racines ne suffisent pas à elles seules à en faire un Réseau de forçage (Forcing Net).
