Triplet nu (Naked Triple) · Exemple étape par étape

Trois cases dans une ligne, une colonne ou un bloc 3×3 ne contiennent que trois chiffres entre elles. Supprimez ces trois chiffres des autres cases de cette région.

Reconnaître le modèle

Trois cases dans une ligne, une colonne ou un bloc 3×3 ne contiennent que trois chiffres entre elles.

Comment le trouver

Avec les chiffres candidats visibles, comparez des groupes de trois cases dans une région et comptez leurs chiffres candidats distincts.

Ce qu'il permet

Supprimez ces trois chiffres des autres cases de cette région.

Évitez les confusions

Les listes de candidats des trois cases peuvent différer. Leur union doit contenir exactement trois chiffres distincts, sans quatrième chiffre dans aucune des cases sélectionnées.

Cet exemple part d’une position intermédiaire enregistrée. Les candidats intègrent des éliminations logiques antérieures et ne sont pas des notes automatiques nouvellement générées.

Bleu : indices. Vert : conclusion. Chiffres barrés : candidats éliminés. R1C1 signifie ligne 1, colonne 1.

Étape 1 · Observez le triple

Ensemble, ces trois cases n'ont que 2, 3, 9 comme chiffres candidats.

Étape 2 · Comprendre la réservation

Les chiffres ne peuvent pas se répéter dans rangée 5, ces trois chiffres doivent donc occuper chacun une case.

Étape 3 · Supprimer les chiffres des candidats

Supprimez les chiffres candidats 2, 3 marqués des autres cases de rangée 5.
