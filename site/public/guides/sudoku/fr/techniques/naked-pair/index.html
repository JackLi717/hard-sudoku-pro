Paire nue (Naked Pair) · Exemple étape par étape

Deux cases dans la même ligne, colonne ou bloc 3 × 3 contiennent chacune uniquement les deux mêmes chiffres candidats. Supprimez les deux chiffres des autres cases de chaque région partagée par la paire.

Reconnaître le modèle

Deux cases dans la même ligne, colonne ou bloc 3 × 3 contiennent chacune uniquement les deux mêmes chiffres candidats.

Comment le trouver

Avec les chiffres candidats visibles, recherchez une case à deux chiffres candidats et vérifiez le reste de sa ligne, de sa colonne et de son bloc 3×3 pour un partenaire identique.

Ce qu'il permet

Supprimez les deux chiffres des autres cases de chaque région partagée par la paire.

Évitez les confusions

Deux cases contenant simplement les deux mêmes chiffres ne suffisent pas si l'une ou l'autre a un troisième chiffre candidat. Un Paire cachée (Hidden Pair) est identifié par l'endroit où peuvent aller deux chiffres, et non par deux cases contenant uniquement ces chiffres.

Ces deux cases contiennent uniquement 1 et 3.

Étape 2 · Comprendre la réservation

Les chiffres ne peuvent pas se répéter dans rangée 2. Une case doit être 1, l'autre 3.

Étape 3 · Supprimer les chiffres des candidats

Supprimez les chiffres candidats 1, 3 marqués des autres cases de rangée 2.
