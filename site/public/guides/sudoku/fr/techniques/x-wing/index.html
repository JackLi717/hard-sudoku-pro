X-Wing · Exemple étape par étape

Reconnaître le modèle

Pour un chiffre, deux lignes ont chacune des positions possibles uniquement dans les deux mêmes colonnes. Les rôles des lignes et des colonnes peuvent être inversés.

Comment le trouver

Choisissez un chiffre et comparez les lignes avec exactement deux cases possibles. Recherchez une autre ligne utilisant les deux mêmes colonnes.

Ce qu'il permet

Supprimez ce chiffre des autres cases de ces deux colonnes, en dehors des deux lignes sélectionnées.

Évitez les confusions

Un rectangle tracé entre quatre chiffres candidats n’est pas suffisant. Vérifiez que le chiffre n'a pas d'autre case possible dans l'une ou l'autre des lignes sélectionnées. Pour un X-Wing basé sur des colonnes, vérifiez plutôt les colonnes sélectionnées.

Exemple étape par étape · Ligne

Cet exemple part d’une position intermédiaire enregistrée. Les candidats intègrent des éliminations logiques antérieures et ne sont pas des notes automatiques nouvellement générées.

Bleu : indices. Vert : conclusion. Chiffres barrés : candidats éliminés. R1C1 signifie ligne 1, colonne 1.

Étape 1 · Où chercher

Chaque ligne de base (rangée 4, rangée 8) comporte exactement deux positions pour 1. Les quatre chiffres candidats encerclés s'alignent sur les deux mêmes lignes de couverture (colonne 2, colonne 9), formant une aile X.

Étape 2 · Cas 1 : occupe les deux lignes de couverture

Choisissez R4C2=1 comme vrai. Dans la même ligne de base (rangée 4), il exclut R4C9=1 ; dans la même ligne de recouvrement (colonne 2), il exclut R8C2=1. L'autre ligne de base (rangée 8) est ensuite laissée avec R8C9=1, de sorte que ce coin soit forcé à être vrai. Les deux lignes de couverture sont occupées ; les cibles (R1C2=1, R7C2=1) sont donc éliminées.

Étape 3 · Cas 2 : occupe les deux lignes de couverture

Choisissez R4C9=1 comme vrai. Dans la même ligne de base (rangée 4), il exclut R4C2=1 ; dans la même ligne de recouvrement (colonne 9), il exclut R8C9=1. L'autre ligne de base (rangée 8) est ensuite laissée avec R8C2=1, de sorte que ce coin soit forcé à être vrai. Les deux lignes de couverture sont occupées ; les cibles (R1C2=1, R7C2=1) sont donc éliminées.

Étape 4 · Conclusion

Dans les deux cas, les deux emplacements 1 des lignes de base (rangée 4, rangée 8) occupent les deux lignes de couverture (colonne 2, colonne 9), une dans chacune. Supprimez donc R1C2=1, R7C2=1 en dehors des lignes de base.

Ce qu'il permet

Dans les deux cas, les deux emplacements 1 des lignes de base (rangée 4, rangée 8) occupent les deux lignes de couverture (colonne 2, colonne 9), une dans chacune. Supprimez donc R1C2=1, R7C2=1 en dehors des lignes de base.
