Reconnaître le modèle

Dans une ligne, une colonne ou un bloc 3×3, trois chiffres sont confinés aux trois mêmes cases.

Comment le trouver

Scannez trois chiffres dans une région et voyez si toutes leurs positions possibles tiennent dans seulement trois cases.

Ce qu'il permet

Supprimez tous les autres chiffres candidats de ces trois cases.

Évitez les confusions

Il n'est pas nécessaire que chaque chiffre apparaisse dans les trois cases. Un Triplet nu (Naked Triple) est trouvé en comptant les chiffres candidats à l'intérieur de trois cases, et non les positions de trois chiffres.

Cet exemple part d’une position intermédiaire enregistrée. Les candidats intègrent des éliminations logiques antérieures et ne sont pas des notes automatiques nouvellement générées.

Bleu : indices. Vert : conclusion. Chiffres barrés : candidats éliminés. R1C1 signifie ligne 1, colonne 1.

Étape 1 · Observez les positions

Dans rangée 6, 2, 4, 6 ne peut apparaître que dans ces trois cases.

Étape 2 · Comprendre la réservation

Ces trois chiffres doivent occuper chacun une case. Aucun autre chiffre ne rentre dans ces cases.

Étape 3 · Supprimer les chiffres des candidats

Supprimez les chiffres candidats 3, 5 marqués de ces trois cases.
