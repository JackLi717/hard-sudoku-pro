Reconnaître le modèle

Quatre cases réparties sur deux lignes, deux colonnes et deux blocs 3×3 forment un rectangle mortel lorsque les quatre sont limités à la même paire.

Comment le trouver

Trouvez trois coins avec uniquement la même paire et inspectez le coin restant à la recherche de chiffres candidats supplémentaires.

Ce qu'il permet

Supprimez les deux chiffres de la paire du quatrième coin.

Évitez les confusions

Les quatre coins doivent occuper exactement deux blocs 3×3 ; si le quatrième n'a que la paire, le puzzle aurait deux solutions.

Étape 2 · Rectangle unique (Unique Rectangle)Type 1

Type 1 : trois coins n’ont que 2, 6. Si le quatrième prenait également un de ces chiffres, le rectangle pourrait être interverti. Le quatrième doit utiliser un autre chiffre.

Étape 3 · Remplissage rectangulaire 1

Remplissage rectangle possible 1 : R2C4=2, R2C6=6, R8C4=6, R8C6=2. L'échange des quatre entrées donne l'autre remplissage. Ce ne sont que des valeurs hypothétiques.

Étape 7 · Type 1 : supprimez les deux chiffres du rectangle

Les trois autres coins sont des cases bivaleurs exactes contenant uniquement 2, 6. Si le quatrième coin R2C4 prenait l'un ou l'autre des chiffres du rectangle, les quatre coins auraient deux remplissages échangeables. Supprimez R2C4=2, R2C4=6 ; R2C4 doit utiliser l’un de ses chiffres candidats supplémentaires.
