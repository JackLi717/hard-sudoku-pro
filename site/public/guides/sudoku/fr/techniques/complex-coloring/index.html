Reconnaître le modèle

des liens d'inférence forts colorent un chiffre en états de vérité logiques opposés au sein de chaque composant ; les relations entre les composants limitent les états de vérité logiques qui peuvent coexister.

Comment le trouver

Colorez chaque composant connecté séparément, puis inspectez les conflits entre composants et les cibles qui voient toutes les alternatives survivantes.

Ce qu'il permet

Supprimez un chiffre candidat exclu de toutes les attributions de couleurs cohérentes.

Évitez les confusions

Ne joignez pas de composants séparés avec un lien d'inférence fort non vérifié et ne supposez pas qu'une couleur est déjà placée.

Exemple étape par étape · Couleur complexe

Cet exemple part d’une position intermédiaire enregistrée. Les candidats intègrent des éliminations logiques antérieures et ne sont pas des notes automatiques nouvellement générées.

Bleu : indices. Vert : conclusion. Chiffres barrés : candidats éliminés. R1C1 signifie ligne 1, colonne 1.

Étape 1 · Confirmer le groupe d'état de vérité de même logique de départ

“Contradiction entre composantes de coloriage (Multi-Component Coloring Contradiction)” — Ce nom décrit une preuve personnalisée entre plusieurs composantes dans cette application ; il ne désigne pas une technique HoDoKu distincte du même nom. Les candidats du chiffre 2 forment 4 composantes de coloriage indépendantes. Le coloriage alterné le long des liens forts place R3C1=2, R8C2=2 du côté A de la composante 2 : ils ont donc la même valeur de vérité et sont exactement les candidats cibles R3C1=2, R8C2=2. A et B sont opposés dans chaque composante ; les conflits relient les états entre composantes.

Étape 2 · Supposons que l'état de vérité logique cible est vrai

Traitez l'ensemble du groupe d'états de vérité logique identique R3C1=2, R8C2=2 comme un seul état de vérité logique et supposez temporairement qu'il est vrai. Suivez les conflits entre les composants.

Étape 3 · Suivez chaque transition de composant

1. R3C1=2 est vrai, donc l’homologue visible R1C2=2 est faux. L’état de vérité logique opposé A/B R1C9=2 dans ce groupe est donc vrai. 2. R1C9=2 est vrai, donc l’homologue visible R5C9=2 est faux. L’état de vérité logique opposé A/B R4C7=2, R5C6=2 dans ce groupe est donc vrai. 3. R4C7=2 est vrai, donc l’homologue visible R4C4=2 est faux. L’état de vérité logique opposé A/B R3C4=2 dans ce groupe est donc vrai. 4. R3C4=2 est vrai, donc l’homologue visible R3C1=2 est faux. L’état de vérité logique opposé A/B R8C1=2 dans ce groupe est donc vrai.

Étape 4 · L'hypothèse force son contraire

L'hypothèse R3C1=2, R8C2=2 force finalement R8C1=2, l'état de vérité logique opposé A/B dans le même groupe. Les deux états de vérité logiques ne peuvent pas être vrais, donc l’hypothèse est fausse.

Étape 5 · Supprimer l'état de vérité logique impossible

L’état de vérité logique de départ ne peut pas être vrai. Supprimez ses chiffres candidats : R3C1=2, R8C2=2.

Ce qu'il permet

L’état de vérité logique de départ ne peut pas être vrai. Supprimez ses chiffres candidats : R3C1=2, R8C2=2.
