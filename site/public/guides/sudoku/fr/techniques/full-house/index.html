Reconnaître le modèle

Une ligne, une colonne ou un bloc 3×3 contient exactement une case vide.

Comment le trouver

Recherchez une ligne, une colonne ou un bloc 3 × 3 presque complet, puis comparez ses chiffres remplis avec 1 à 9.

Ce qu'il permet

Remplissez la case vide avec le chiffre manquant.

Évitez les confusions

Comptez les cases vides dans la région choisie. Un Singleton nu (Naked Single) peut être le seul chiffre candidat pour une case même lorsque plusieurs cases sont encore vides.

Exemple étape par étape · Ligne

Cet exemple part d’une position intermédiaire enregistrée. Les candidats intègrent des éliminations logiques antérieures et ne sont pas des notes automatiques nouvellement générées.

Bleu : indices. Vert : conclusion. Chiffres barrés : candidats éliminés. R1C1 signifie ligne 1, colonne 1.

Étape 1 · Où chercher

rangée 5 n’a que R5C3 laissé vide. Le chiffre manquant est 4, donc R5C3 doit être 4.

Étape 2 · Conclusion

R5C3=4 est forcé par ce modèle.

Ce qu'il permet

R5C3=4 est forcé par ce modèle.
