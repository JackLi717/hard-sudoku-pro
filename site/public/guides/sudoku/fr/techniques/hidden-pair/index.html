Paire cachée (Hidden Pair) · Exemple étape par étape

Reconnaître le modèle

Dans une ligne, une colonne ou un bloc 3×3, deux chiffres ne peuvent apparaître que dans les deux mêmes cases.

Comment le trouver

Scannez une région un chiffre à la fois. Trouvez deux chiffres dont les cases possibles sont exactement la même paire.

Ce qu'il permet

Conservez ces deux chiffres dans les cases appariées et supprimez-en tous les autres chiffres candidats.

Évitez les confusions

Les cases appariées peuvent avoir des chiffres candidats supplémentaires avant l'élimination. Un Paire nue (Naked Pair) commence par des cases contenant uniquement les deux chiffres.

Cet exemple part d’une position intermédiaire enregistrée. Les candidats intègrent des éliminations logiques antérieures et ne sont pas des notes automatiques nouvellement générées.

Bleu : indices. Vert : conclusion. Chiffres barrés : candidats éliminés. R1C1 signifie ligne 1, colonne 1.

Étape 1 · Concentrez-vous sur les deux cases

Commencez par les deux cases en surbrillance. Les deux contiennent les chiffres candidats 5 et 7.

Étape 2 · Confirmez le Paire cachée (Hidden Pair)

Dans rangée 8, 5 et 7 apparaissent uniquement dans ces deux cases en surbrillance. Ils doivent occuper chacun une case, ces cases ne peuvent donc pas contenir d’autres chiffres.

Étape 3 · Supprimez les autres chiffres candidats

Supprimez les chiffres candidats 2, 4, 8 marqués de ces deux cases.
