XY-Wing · Exemple étape par étape

Un pivot à deux chiffres candidats {X,Y} voit deux ailes {X,Z} et {Y,Z}. Les ailes peuvent se connecter via un bloc 3×3, une rangée ou une colonne. Supprimez le troisième chiffre partagé d'un chiffre candidat qui voit les deux ailes.

Reconnaître le modèle

Un pivot à deux chiffres candidats {X,Y} voit deux ailes {X,Z} et {Y,Z}. Les ailes peuvent se connecter via un bloc 3×3, une rangée ou une colonne.

Comment le trouver

Trouvez un pivot à deux chiffres candidats, puis deux autres paires qui partagent chacune un chiffre pivot différent et le même troisième chiffre.

Ce qu'il permet

Supprimez le troisième chiffre partagé d'un chiffre candidat qui voit les deux ailes.

Évitez les confusions

Le pivot lui-même doit avoir exactement deux chiffres candidats. La cible doit voir les deux ailes ; voir seulement le pivot est insuffisant.

Exemple étape par étape · Lien de ligne

Cet exemple part d’une position intermédiaire enregistrée. Les candidats intègrent des éliminations logiques antérieures et ne sont pas des notes automatiques nouvellement générées.

Bleu : indices. Vert : conclusion. Chiffres barrés : candidats éliminés. R1C1 signifie ligne 1, colonne 1.

Étape 1 · Trouver le pivot et les ailes

R5C8 est le pivot avec les chiffres candidats 4, 7. Il voit les deux ailes : R4C9 avec 6, 7 et R5C2 avec 4, 6.

Étape 2 · Trouver la cible partagée

Les deux ailes contiennent du 6. Chaque cible (R4C2=6) voit les deux ailes, il s'agit donc de leur cible commune pour le chiffre candidat 6.

Étape 3 · Cas 1 : R5C8 est 4

Si R5C8=4, R5C2 ne peut pas être 4 et doit être 6.

Étape 4 · Cas 1 : supprimer la cible 6

Chaque cible (R4C2=6) voit R5C2, qui est 6 dans ce cas. La cible ne peut donc pas être 6.

Étape 5 · Cas 2 : R5C8 est 7

Si R5C8=7, R4C9 ne peut pas être 7 et doit être 6.

Étape 6 · Cas 2 : supprimer la cible 6

Chaque cible (R4C2=6) voit R4C9, qui est 6 dans ce cas. La cible ne peut donc pas être 6.

Étape 7 · Combinez les deux cas

Le pivot ne peut être que 4, 7. Dans les deux cas, une aile est 6, supprimez donc R4C2=6.
