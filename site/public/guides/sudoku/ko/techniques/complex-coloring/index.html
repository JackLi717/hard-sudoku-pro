찾는 방법

혼동을 피하십시오

확인되지 않은 강한 연결로 별도의 구성 요소를 결합하거나 색상이 이미 배치되어 있다고 가정하지 마십시오.

단계별 예 · 복합색상

이 예제는 저장된 중간 상태에서 시작합니다. 후보에는 앞선 논리적 제거가 반영되어 있으며 새로 자동 생성한 메모가 아닙니다.

파란색: 근거. 초록색: 결론. 취소선 숫자: 제거할 후보. R1C1은 1행 1열입니다.

단계 1 · 시작 동일 상태 그룹 확인

“여러 색칠 성분의 모순 (Multi-Component Coloring Contradiction)” — 이 이름은 이 앱에서 사용하는 다중 연결 성분 증명의 설명적 이름이며, 같은 이름의 별도 HoDoKu 기법이 아닙니다. 숫자 2의 후보는 4개의 독립된 색칠 연결 성분을 이룹니다. 강한 연결을 따라 색을 번갈아 부여하면 R3C1=2, R8C2=2는 연결 성분 2의 A 쪽에 속하여 같은 참·거짓 상태를 공유합니다. 이들이 바로 목표 후보 R3C1=2, R8C2=2입니다. 각 연결 성분 안에서 A와 B는 서로 반대인 상태이며, 성분 간 충돌이 이 상태들을 연결합니다.

단계 2 · 대상 상태가 참이라고 가정합니다.

동일한 상태 그룹 R3C1=2, R8C2=2 전체를 하나의 상태로 간주하고 일시적으로 참으로 가정합니다. 구성 요소 간의 충돌을 따르십시오.

단계 3 · 모든 구성요소 전환을 따르세요.

1. R3C1=2는 참이므로 표시되는 피어 R1C2=2는 거짓입니다. 따라서 해당 그룹의 반대 A/B 상태 R1C9=2는 참입니다. 2. R1C9=2는 참이므로 표시되는 피어 R5C9=2는 거짓입니다. 따라서 해당 그룹의 반대 A/B 상태 R4C7=2, R5C6=2는 참입니다. 3. R4C7=2는 참이므로 표시되는 피어 R4C4=2는 거짓입니다. 따라서 해당 그룹의 반대 A/B 상태 R3C4=2는 참입니다. 4. R3C4=2는 참이므로 표시되는 피어 R3C1=2는 거짓입니다. 따라서 해당 그룹의 반대 A/B 상태 R8C1=2는 참입니다.

단계 4 · 가정은 그 반대를 강요합니다

R3C1=2, R8C2=2 가정은 결국 동일한 그룹에서 반대 A/B 상태인 R8C1=2를 강제합니다. 두 상태 모두 참일 수 없으므로 가정은 거짓입니다.

단계 5 · 불가능한 상태 제거

시작 상태가 참일 수 없습니다. 후보 제거: R3C1=2, R8C2=2.
