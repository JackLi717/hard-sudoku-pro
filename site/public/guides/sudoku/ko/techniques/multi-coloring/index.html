다중 색칠 (Multi-Coloring) · 단계별 예

한 자리에 대한 두 개의 별도 색상 구성 요소는 각각 반대되는 A/B 상태를 갖습니다. 각 구성 요소의 후보가 다른 구성 요소를 확인하여 구성 요소 간 충돌이 발생합니다. 각각의 반대 대안에서 후보를 보는 대상에서 숫자를 제거합니다.

패턴 인식

한 자리에 대한 두 개의 별도 색상 구성 요소는 각각 반대되는 A/B 상태를 갖습니다. 각 구성 요소의 후보가 다른 구성 요소를 확인하여 구성 요소 간 충돌이 발생합니다.

찾는 방법

두 개의 별도의 강한 연결 네트워크를 구축하고 A/B 상태를 표시하고 서로를 보는 서로 다른 구성 요소에서 후보를 찾습니다.

그것이 허용하는 것

각각의 반대 대안에서 후보를 보는 대상에서 숫자를 제거합니다.

혼동을 피하십시오

두 구성 요소를 하나의 색상 체인으로 병합하지 마십시오. 각 구성 요소의 강한 연결과 두 대안에 대한 대상의 시야를 확인하십시오.

단계별 예 · 두 가지 구성 요소

이 예제는 저장된 중간 상태에서 시작합니다. 후보에는 앞선 논리적 제거가 반영되어 있으며 새로 자동 생성한 메모가 아닙니다.

파란색: 근거. 초록색: 결론. 취소선 숫자: 제거할 후보. R1C1은 1행 1열입니다.

단계 1 · 멀티 컬러링입니다

이 연습에서는 HoDoKu 다중 색상 유형 1을 다룹니다. 두 가지 색상 구성 요소에는 구성 요소 간 충돌이 포함되어 있습니다. 후보 6는 두 가지 별도의 색상 구성 요소를 구성합니다. 각 구성요소 내에서 원형 A와 정사각형 B는 반대 상태입니다. 대상 R7C2=6를 시야에 유지하세요.

단계 2 · 부품 1 검사

색칠 성분 1: 원형 A = R2C2=6, 사각형 B = R2C4=6. A와 B는 서로 반대되는 상태이며, 모든 강한 연결은 이 성분 안에서 두 상태를 잇습니다.

단계 3 · 부품 2 검사

색칠 성분 2: 원형 A = R3C5=6, 사각형 B = R7C5=6. A와 B는 서로 반대되는 상태이며, 모든 강한 연결은 이 성분 안에서 두 상태를 잇습니다.

단계 4 · 구성 요소 간 충돌 찾기

R2C4=6와 R3C5=6는 서로 다른 구성요소에 속하지만 박스 2에서 서로를 봅니다. 둘 다 사실일 수는 없습니다.

단계 5 · 적어도 하나의 반대 상태가 참입니다.

충돌하는 상태는 둘 다 참일 수 없으므로 적어도 하나의 반대 상태(R2C2=6 또는 R7C5=6)는 참이어야 합니다.

단계 6 · 대상은 두 가지 대안을 모두 봅니다.

R7C2=6에는 R2C2=6 및 R7C5=6가 표시됩니다. 반대 상태가 참이면 대상이 제외됩니다.

단계 7 · 대상 후보 제거

R7C2=6를 제거합니다.
