패턴 인식

한 자리의 경우 두 행 각각은 동일한 두 열에서만 위치가 가능합니다. 행과 열 역할은 바뀔 수 있습니다.

찾는 방법

숫자를 선택하고 해당 숫자에 대해 정확히 두 개의 가능한 칸이 있는 행을 비교하세요. 동일한 두 열을 사용하여 다른 행을 찾습니다.

그것이 허용하는 것

​​선택한 두 행 외부의 두 열에 있는 다른 칸에서 해당 숫자를 제거합니다.

혼동을 피하십시오

4개의 후보를 통해 그려지는 직사각형으로는 충분하지 않습니다. 선택한 행에 숫자의 다른 가능한 칸이 없는지 확인하십시오. 열 기반 X-Wing의 경우 선택한 열을 대신 확인하세요.

단계별 예 · 행

이 예제는 저장된 중간 상태에서 시작합니다. 후보에는 앞선 논리적 제거가 반영되어 있으며 새로 자동 생성한 메모가 아닙니다.

파란색: 근거. 초록색: 결론. 취소선 숫자: 제거할 후보. R1C1은 1행 1열입니다.

단계 1 · 볼 곳

각 기본 영역(행 4, 행 8)에는 1에 대해 정확히 두 개의 위치가 있습니다. 원으로 둘러싸인 4개의 후보는 동일한 2개의 커버 영역(컬럼 2, 컬럼 9)에 정렬되어 X-Wing를 형성합니다.

단계 2 · 케이스 1: 두 커버 영역 모두 점유

R4C2=1를 참으로 선택합니다. 동일한 기본 지역(행 4)에서는 R4C9=1를 제외합니다. 동일한 커버 영역(컬럼 2)에서는 R8C2=1를 제외합니다. 그런 다음 다른 기본 영역(행 8)에는 R8C9=1가 남으므로 해당 모서리가 참이 됩니다. 두 커버 영역이 모두 채워지므로 대상(R1C2=1, R7C2=1)을 배제합니다.

단계 3 · 케이스 2: 두 커버 영역 모두 점유

R4C9=1를 참으로 선택합니다. 동일한 기본 지역(행 4)에서는 R4C2=1를 제외합니다. 동일한 커버 영역(컬럼 9)에서는 R8C9=1를 제외합니다. 그런 다음 다른 기본 영역(행 8)에는 R8C2=1가 남으므로 해당 모서리가 참이 됩니다. 두 커버 영역이 모두 채워지므로 대상(R1C2=1, R7C2=1)을 배제합니다.

단계 4 · 결론

완전한 페어링에서 기본 영역(행 4, 행 8)의 두 1 배치는 두 커버 영역(컬럼 2, 컬럼 9)을 각각 하나씩 차지합니다. 따라서 베이스 외부의 R1C2=1, R7C2=1를 제거하십시오.

그것이 허용하는 것

완전한 페어링에서 기본 영역(행 4, 행 8)의 두 1 배치는 두 커버 영역(컬럼 2, 컬럼 9)을 각각 하나씩 차지합니다. 따라서 베이스 외부의 R1C2=1, R7C2=1를 제거하십시오.
