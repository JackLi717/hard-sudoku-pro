네이키드 쿼드 (Naked Quad) · 단계별 예

한 행, 열 또는 박스에 있는 4개의 칸 사이에는 4자리 숫자만 포함됩니다. 해당 지역의 다른 모든 칸에서 해당 4자리 숫자를 제거합니다.

패턴 인식

한 행, 열 또는 박스에 있는 4개의 칸 사이에는 4자리 숫자만 포함됩니다.

찾는 방법

한 영역에서 짧은 후보 목록이 있는 4개의 칸을 비교합니다. 결합된 집합에는 정확히 4자리 숫자가 포함되어야 합니다.

그것이 허용하는 것

해당 지역의 다른 모든 칸에서 해당 4자리 숫자를 제거합니다.

혼동을 피하십시오

쿼드는 4개의 동일한 후보 목록이 아닙니다. 선택한 칸에는 다섯 번째 숫자가 포함될 수 없으며 4개의 칸이 모두 하나의 영역을 공유해야 합니다.

단계별 예 · 행

이 예제는 저장된 중간 상태에서 시작합니다. 후보에는 앞선 논리적 제거가 반영되어 있으며 새로 자동 생성한 메모가 아닙니다.

파란색: 근거. 초록색: 결론. 취소선 숫자: 제거할 후보. R1C1은 1행 1열입니다.

단계 1 · 쿼드 관찰

이 4개의 칸을 합쳐서 후보로는 2, 4, 7, 9만 있습니다.

단계 2 · 예약 이해

행 9에서는 숫자가 반복될 수 없으므로 이 4개의 숫자는 각각 하나의 칸을 차지해야 합니다.

단계 3 · 후보 제거

행 9의 다른 칸에서 표시된 2, 4, 7 후보를 제거합니다.

그것이 허용하는 것

행 9의 다른 칸에서 표시된 2, 4, 7 후보를 제거합니다.
