히든 쿼드 (Hidden Quad) · 단계별 예

하나의 행, 열 또는 박스 내에서 4개의 숫자는 동일한 4개의 칸에서만 위치를 가질 수 있습니다. 해당 4개 칸에서 다른 후보를 제거합니다.

패턴 인식

하나의 행, 열 또는 박스 내에서 4개의 숫자는 동일한 4개의 칸에서만 위치를 가질 수 있습니다.

찾는 방법

한 영역에서 4자리 숫자를 선택하고 나머지 위치가 모두 4개 칸에 맞는지 확인하세요.

그것이 허용하는 것

해당 4개 칸에서 다른 후보를 제거합니다.

혼동을 피하십시오

4개의 칸은 처음에 추가 후보를 표시할 수 있습니다. 표시된 칸뿐만 아니라 전체 영역에서 4자리 숫자의 위치를 ​​확인하세요.

단계별 예 · 행

이 예제는 저장된 중간 상태에서 시작합니다. 후보에는 앞선 논리적 제거가 반영되어 있으며 새로 자동 생성한 메모가 아닙니다.

파란색: 근거. 초록색: 결론. 취소선 숫자: 제거할 후보. R1C1은 1행 1열입니다.

단계 1 · 위치 관찰
