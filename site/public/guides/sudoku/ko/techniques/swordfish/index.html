패턴 인식

한 자리의 경우 세 행의 모든 ​​위치가 동일한 세 열에 맞습니다. 행과 열을 교환할 수 있습니다.

찾는 방법

2~3개의 후보가 있는 행에서 한 자리를 스캔합니다. 결합된 후보 열이 정확히 3개인 행 3개를 찾습니다.

그것이 허용하는 것

선택한 행 외부의 3개 커버 열에서 해당 숫자를 제거합니다.

혼동을 피하십시오

후보는 9개의 모서리를 형성할 필요가 없습니다. 선택한 각 행의 모든 ​​위치를 확인하세요. 세 개의 커버 열 밖에 후보가 있을 수 없습니다.

단계별 예 · 행

이 예제는 저장된 중간 상태에서 시작합니다. 후보에는 앞선 논리적 제거가 반영되어 있으며 새로 자동 생성한 메모가 아닙니다.

파란색: 근거. 초록색: 결론. 취소선 숫자: 제거할 후보. R1C1은 1행 1열입니다.

단계 1 · Swordfish 인식

3개의 기본 영역(행 3, 행 5, 행 8)에는 여전히 6가 필요하며, 나머지 모든 6 후보는 동일한 3개의 커버 영역(컬럼 2, 컬럼 3, 컬럼 8)에 있습니다. 이는 Swordfish를 형성합니다.

단계 2 · 커버가 점유된 이유 확인

각 기준선은 6을 한 번 포함해야 하므로 총 세 번 배치해야 합니다. 한 커버선에 같은 숫자가 두 번 들어갈 수 없고, 모든 배치가 이 세 커버선에 한정됩니다. 따라서 각 커버선에 정확히 한 번씩 배치됩니다.

단계 3 · 대상 제거

따라서 3개 커버의 6는 베이스 영역 내부에 배치되어야 합니다. 베이스 외부에 표시된 후보 R9C3=6를 제거합니다.
