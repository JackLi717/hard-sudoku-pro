Sudoku pencil marks: how to use candidates

What to look for

A candidate is a digit that may still fit in an empty cell. It is a possibility, not a placed answer.

Check that the cell is empty, then rule out digits already placed in its row, column and box.

A small note is a candidate; a large placed digit is not. The local diagram shows only relevant notes.

What can go here?

Look at the highlighted row, column and box. Both 3 and 7 are still possible here; we cannot decide yet.

Make a note and keep looking

Our puzzles have one complete solution, but a candidate is not an answer. Note 3 and 7, then look elsewhere.

Find a cell you can determine

In this new cell, the digits already in its row, column and box rule out every possibility except 7.

Now look back

Once 7 is filled, the original cell can no longer contain 7. Only 3 remains.

Be sure before you fill

Solve a cell you can justify, then return to the uncertain ones. Each confirmed digit can reveal a new clue.
