Множественное раскрашивание (Multi-Coloring) · Пошаговый пример

Два отдельных компонента окраски для одной цифры имеют противоположные состояния A/B. Кандидат от каждого компонента видит другого, создавая межкомпонентный конфликт. Удалить цифру из цели, которая видит кандидата в каждой противоположной альтернативе.

Пошаговый пример

Распознайте закономерность

Два отдельных компонента окраски для одной цифры имеют противоположные состояния A/B. Кандидат от каждого компонента видит другого, создавая межкомпонентный конфликт.

Как его найти

Создайте две отдельные сети с сильными связями, отметьте их состояния A/B и найдите кандидатов из разных компонентов, которые видят друг друга.

Что это позволяет

Удалить цифру из цели, которая видит кандидата в каждой противоположной альтернативе.

Избегайте путаницы

Не объединяйте два компонента в одну цветовую цепочку. Проверьте сильные связи каждого компонента и представление объектом обеих альтернатив.

Пошаговый пример · Два компонента

Пример начинается с сохранённой промежуточной позиции. Кандидаты учитывают предыдущие логические исключения и не являются только что созданными автоматическими заметками.

Синий: основания. Зелёный: вывод. Зачёркнутые цифры: исключённые кандидаты. R1C1 означает строку 1, столбец 1.

Шаг 1 · Это мульти раскраска

В этом пошаговом руководстве рассматривается HoDoKu Multi Colors Type 1: два цветных компонента содержат конфликт между компонентами. Кандидат 6 образует эти два отдельных компонента окраски. Внутри каждого компонента круг A и квадрат B являются противоположными состояниями. Держите цель R7C2=6 в поле зрения.

Шаг 2 · Осмотр компонента 1

Красящий компонент 1: круглый A = R2C2=6; квадрат B = R2C4=6. А и Б — противоположные состояния, и каждое сильное звено объединяет их внутри этого компонента.

Шаг 3 · Осмотр компонента 2

Красящий компонент 2: круглый A = R3C5=6; квадрат B = R7C5=6. А и Б — противоположные состояния, и каждое сильное звено объединяет их внутри этого компонента.

Шаг 4 · Найдите конфликт между компонентами

R2C4=6 и R3C5=6 принадлежат разным компонентам, но видят друг друга в блок 2. Они не могут быть правдой одновременно.

Шаг 5 · Хотя бы одно противоположное состояние истинно.

Поскольку конфликтующие состояния не могут быть одновременно истинными, хотя бы одно противоположное состояние — R2C2=6 или R7C5=6 — должно быть истинным.

Шаг 6 · Цель видит обе альтернативы.

R7C2=6 видит R2C2=6 и R7C5=6. Какое бы противоположное состояние ни было истинным, цель исключается.

Шаг 7 · Удалить целевого кандидата
