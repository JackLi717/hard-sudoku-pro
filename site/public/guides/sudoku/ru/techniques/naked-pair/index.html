Открытая пара (Naked Pair) · Пошаговый пример

Две ячейки в одной строке, столбце или блоке содержат только двух одинаковых кандидатов. Удалите обе цифры из других ячеек в каждой области, общей для пары.

Распознайте закономерность

Две ячейки в одной строке, столбце или блоке содержат только двух одинаковых кандидатов.

Как его найти

Когда кандидаты видны, найдите ячейку с двумя кандидатами и проверьте остальную часть ее строки, столбца и блока на наличие идентичного партнера.

Что это позволяет

Удалите обе цифры из других ячеек в каждой области, общей для пары.

Избегайте путаницы

Двух ячеек, содержащих одни и те же две цифры, недостаточно, если в любой из них есть третий кандидат. Скрытая пара (Hidden Pair) идентифицируется по тому, куда могут идти две цифры, а не по двум ячейкам, содержащим только эти цифры.

Пошаговый пример · Строка

Пример начинается с сохранённой промежуточной позиции. Кандидаты учитывают предыдущие логические исключения и не являются только что созданными автоматическими заметками.

Синий: основания. Зелёный: вывод. Зачёркнутые цифры: исключённые кандидаты. R1C1 означает строку 1, столбец 1.

Шаг 3 · Удалить кандидатов
