Распознайте закономерность

Три ячейки в одной строке, столбце или блоке содержат между собой только три цифры.

Как его найти

Отображая кандидатов, сравните группы из трех ячеек в одном регионе и подсчитайте их отдельных кандидатов.

Что это позволяет

​​Удалите эти три цифры из других ячеек в этом регионе.

Избегайте путаницы

Списки кандидатов трёх клеток могут различаться. Их объединение должно содержать ровно три разные цифры, без четвёртой цифры в любой выбранной клетке.

Пошаговый пример · Строка

Пример начинается с сохранённой промежуточной позиции. Кандидаты учитывают предыдущие логические исключения и не являются только что созданными автоматическими заметками.

Синий: основания. Зелёный: вывод. Зачёркнутые цифры: исключённые кандидаты. R1C1 означает строку 1, столбец 1.

Шаг 1 · Обратите внимание на тройку

Вместе эти три ячейки имеют в качестве кандидатов только 2, 3, 9.

Шаг 2 · Разберитесь с резервированием

Цифры не могут повторяться в строка 5, поэтому каждая из этих трех цифр должна занимать одну ячейку.

Шаг 3 · Удалить кандидатов

Удалите отмеченных кандидатов 2, 3 из других ячеек в строка 5.
