Turbot Fish · Пошаговый пример

Распознайте закономерность

Две сильные связи для одной цифры соединяются через слабую связь; форма может напоминать Skyscraper, воздушного змея или Empty Rectangle.

Как его найти

Отследите две сильные связи и их слабую связь. Определите две внешние конечные точки, прежде чем искать общую цель.

Что это позволяет

Удалите цифру из любого кандидата, который видит обе внешние конечные точки.

Избегайте путаницы

Двух выделенных пар недостаточно без действительного слабого соединения. Кандидата, видящего только один внешний конец, удалить невозможно.

Пошаговый пример · Skyscraper

Пример начинается с сохранённой промежуточной позиции. Кандидаты учитывают предыдущие логические исключения и не являются только что созданными автоматическими заметками.

Синий: основания. Зелёный: вывод. Зачёркнутые цифры: исключённые кандидаты. R1C1 означает строку 1, столбец 1.

Шаг 1 · См. общую цепочку из четырех кандидатов.

Turbot Fish — это общее название для X-Chain с четырьмя кандидатами. Skyscraper, Two-String Kite и Empty Rectangle с двумя кандидатами — это именованные макеты этой же цепочки. Следуйте четырем кругам для 3.

Шаг 2 · Два места в строка 3

В строка 3 3 может идти только в R3C1 или R3C5. Один из них должен быть 3.

Шаг 3 · Два места в строка 8

В строка 8 3 может идти только в R8C2 или R8C5. Один из них должен быть 3.

Шаг 4 · Соедините две сильные связи.

R3C5 и R8C5 видят друг друга в столбец 5. Они образуют слабое звено: они не могут оба быть 3. Это макет Skyscraper; здесь мы видим его общую цепочку Turbot Fish.

Шаг 5 · Попробуйте предположить

Что, если бы R7C1 был 3? Цифры отмечены? являются частью этого предположения, а не подтвержденными ответами. R3C1 разделяет столбец 1 с R7C1, поэтому он также не может быть 3. R8C2 разделяет блок 7 с R7C1, поэтому он также не может быть 3.

Шаг 6 · Две одинаковые цифры в одном регионе

R3C1 не может быть 3, поэтому в строка 3 остался только R3C5. Согласно этому предположению, это должен быть 3. R8C2 не может быть 3, поэтому строка 8 заставляет R8C5 быть 3. Но R3C5 и R8C5 имеют общий столбец 5: это поместило бы 3 туда дважды!

Шаг 7 · Предположение не может быть верным

Для каждой цели, предполагая, что 3 повторяет эту цифру в столбец 5. Удалить кандидата 3 из R7C1; все временные предположения отменяются.

Что это позволяет

Для каждой цели, предполагая, что 3 повторяет эту цифру в столбец 5. Удалить кандидата 3 из R7C1; все временные предположения отменяются.
