Определение

Кандидат, видящий обе конечные точки, из которых хотя бы одна должна быть истинной, сам по себе не может быть истинным.

Как его найти

Сначала докажите связь конечной точки, затем проверьте цель по каждой конечной точке отдельно.

Распространенная ошибка

Видение только одной конечной точки делает другую возможной и не доказывает отсутствия исключения.
