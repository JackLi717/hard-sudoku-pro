Базовые линии рыбы · Основные понятия

Базовые линии — это строки или столбцы, выбранные для проверки каждого кандидата из одной цифры. Синие строки — это отправная точка: каждая в конечном итоге должна содержать цифру 2; в версии со столбцами начните с синих столбцов.

Определение

Базовые линии — это строки или столбцы, выбранные для проверки каждого кандидата из одной цифры. Синие строки — это отправная точка: каждая в конечном итоге должна содержать цифру 2; в версии со столбцами начните с синих столбцов.

Как его найти

Сосредоточьтесь на 2 и найдите каждые 2 в каждой из двух или трех синих линий.

Распространенная ошибка

Синий обозначает стартовые линии, а не завершенную рыбу. Затем проверьте, какие пересекающиеся линии содержат своих кандидатов.

X-Wing · Строка

Учебный совет · Схема местного кандидата

Наблюдать за кандидатами

Смотри только на кандидата 2, на r2c2, r2c8, r6c2, r6c8; имена строк могут подождать.

Проверьте состояние

Начните с синего строка 2, строка 6 и найдите все 2; каждая строка должна в конечном итоге содержать один 2. Эти выбранные стартовые линии являются базами.

Сделайте вывод

Синие строка 2, строка 6 — стартовые линии; на каждом показан каждый 2.
