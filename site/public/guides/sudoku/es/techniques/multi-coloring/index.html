Coloreado múltiple (Multi-Coloring) · Ejemplo paso a paso

Dos componentes de coloración separados para un dígito tienen cada uno de ellos estados de verdad lógicos opuestos A/B. El dígito candidato A de cada componente ve al otro, creando un conflicto entre componentes. Elimine el dígito de un objetivo que vea un dígito candidato en cada alternativa opuesta.

Reconocer el patrón

Dos componentes de coloración separados para un dígito tienen cada uno de ellos estados de verdad lógicos opuestos A/B. El dígito candidato A de cada componente ve al otro, creando un conflicto entre componentes.

como encontrarlo

Cree dos redes de vínculos fuertes separadas, marque sus estados de verdad lógicos A/B y encuentre dígitos candidatos de diferentes componentes que se vean entre sí.

lo que permite

Elimine el dígito de un objetivo que vea un dígito candidato en cada alternativa opuesta.

Evite la confusión

No fusiones los dos componentes en una cadena de colores. Verifique los fuertes vínculos de inferencia de cada componente y la visión del objetivo de ambas alternativas.

Ejemplo paso a paso · Dos componentes

Este ejemplo parte de una posición intermedia guardada. Los candidatos incluyen eliminaciones lógicas anteriores y no son notas automáticas recién generadas.

Azul: evidencias. Verde: conclusión. Dígitos tachados: candidatos eliminados. R1C1 significa fila 1, columna 1.

Paso 1 · Esto es multicolor

Este tutorial cubre HoDoKu Multicolores Tipo 1: dos componentes de colores contienen un conflicto entre componentes. El dígito candidato 6 forma esos dos componentes de coloración separados. Dentro de cada componente, el A marcado con un círculo y el B marcado con un cuadrado son estados de verdad lógicos opuestos. Mantenga el objetivo R7C2=6 a la vista.

Paso 2 · Inspeccionar el componente 1

Componente colorante 1: marcado con un círculo A = R2C2=6; cuadrado marcado como B = R2C4=6. A y B son estados de verdad lógicos opuestos, y cada vínculo de inferencia fuerte los une dentro de este componente.

Paso 3 · Inspeccionar el componente 2

Componente colorante 2: marcado con un círculo A = R3C5=6; cuadrado marcado como B = R7C5=6. A y B son estados de verdad lógicos opuestos, y cada vínculo de inferencia fuerte los une dentro de este componente.

Paso 4 · Encuentra un conflicto entre componentes

R2C4=6 y R3C5=6 pertenecen a componentes diferentes pero se ven en bloque 2. No pueden ser verdad al mismo tiempo.

Paso 5 · Al menos un estado de verdad lógico opuesto es verdadero

Dado que los estados de verdad lógicos en conflicto no pueden ser verdaderos al mismo tiempo, al menos un estado de verdad lógico opuesto (R2C2=6 o R7C5=6) debe ser verdadero.

Paso 6 · El objetivo ve ambas alternativas.

R7C2=6 ve R2C2=6 y R7C5=6. Cualquiera que sea el estado de verdad lógico opuesto que sea verdadero excluye al objetivo.

Paso 7 · Eliminar el dígito candidato objetivo

Retire R7C2=6.

lo que permite

Retire R7C2=6.
