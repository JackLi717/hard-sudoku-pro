Para un dígito, todos los dígitos candidatos en cuatro filas de base se encuentran en cuatro columnas de cobertura. Se pueden intercambiar filas y columnas. Retire ese dígito de las líneas de cobertura fuera de las cuatro líneas de base.

Reconocer el patrón

Para un dígito, todos los dígitos candidatos en cuatro filas de base se encuentran en cuatro columnas de cobertura. Se pueden intercambiar filas y columnas.

como encontrarlo

Escanee un solo dígito en cuatro filas o columnas; cuente cada dígito candidato en las líneas base seleccionadas y confirme que solo se utilizan cuatro líneas de cobertura.

lo que permite

Retire ese dígito de las líneas de cobertura fuera de las cuatro líneas de base.

Evite la confusión

Cuatro líneas dibujadas por sí solas no son un pez. Cada dígito candidato en cada base debe estar ubicado en una línea de cobertura elegida.

Paso 1 · Reconocer el Jellyfish

Cada una de las cuatro líneas base (fila 2, fila 3, fila 6, fila 7) todavía necesita 2, y todos los dígitos candidatos encerrados en un círculo se encuentran en las mismas cuatro líneas de cobertura (columna 3, columna 4, columna 7, columna 8). La leyenda "Líneas de base" marca las cuatro líneas de base y "líneas de cobertura" marca las cuatro líneas de cobertura. Juntos forman el Jellyfish.

Paso 2 · Cada línea de cobertura debe ocuparse una vez

Las cuatro líneas base deben colocar cuatro 2 en total. Una línea de cobertura no puede contener el dígito dos veces y las cuatro ubicaciones se limitan a estas cuatro líneas de cobertura. Por lo tanto, las colocaciones ocupan cada línea de cobertura exactamente una vez.

Paso 3 · Eliminar dígitos candidatos fuera de las líneas base

Cada línea de cobertura recibe ya su 2 de una de las cuatro líneas base. Por lo tanto, los dígitos candidatos en las líneas de cobertura pero fuera de las líneas base no pueden ser 2; eliminar R4C4=2, R9C7=2, R9C8=2.
