Definición

Una suposición trata temporalmente un dígito candidato no resuelto como verdadero para explorar las consecuencias. No es una respuesta colocada.

como encontrarlo

Elija un dígito candidato real y registre sólo las consecuencias que se derivan de ese estado de verdad lógico temporal.

Error común

No trate una suposición como confirmada. Las conclusiones necesitan contradicción o acuerdo entre ramas.
