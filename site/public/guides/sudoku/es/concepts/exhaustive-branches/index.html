Definición

Cada valor inicial posible necesita una rama. Las casillas con dos, tres o cuatro dígitos candidatos necesitan dos, tres o cuatro ramas.

como encontrarlo

Cuente todos los dígitos candidatos iniciales y cree una rama exclusiva para cada valor posible.

Error común

Omitir un tercer valor deja un vacío, incluso si las dos primeras ramas coinciden.
