Reconheça o padrão

Para um dígito, todas as suas posições em três linhas cabem nas mesmas três colunas. Linhas e colunas podem ser trocadas.

Como encontrá-lo

Digitalize um dígito em linhas com dois ou três dígitos candidatos. Encontre três linhas cujas colunas combinadas de dígitos candidatos totalizem exatamente três.

O que permite

Remova esse dígito das três colunas de cobertura fora das linhas selecionadas.

Evite a confusão

Os dígitos candidatos não precisam formar nove cantos. Verifique todas as posições em cada linha selecionada: nenhum dígito candidato pode ficar fora das três colunas de cobertura.

Exemplo passo a passo · Linha

Este exemplo começa em uma posição intermediária salva. Os candidatos incluem eliminações lógicas anteriores e não são anotações automáticas recém-geradas.

Azul: evidências. Verde: conclusão. Dígitos riscados: candidatos eliminados. R1C1 significa linha 1, coluna 1.

Etapa 1 · Reconheça o Swordfish

As três linhas de base (linha 3, linha 5, linha 8) ainda precisam de 6, e cada dígito candidato 6 restante nelas reside nas mesmas três linhas de cobertura (coluna 2, coluna 3, coluna 8). Isso forma um Swordfish.

Etapa 2 · Veja por que as linhas de cobertura estão ocupadas

Cada base deve colocar um 6, totalizando três colocações. Uma linha de cobertura não pode conter dois dígitos iguais. Dado que cada colocação está confinada a estas três linhas de cobertura, as três colocações devem ocupar uma linha de cobertura cada.

Etapa 3 · Remova os alvos

Portanto, 6 nas três linhas de cobertura deve ser colocado dentro das linhas de base. Remova os dígitos candidatos marcados fora das linhas de base: R9C3=6.
