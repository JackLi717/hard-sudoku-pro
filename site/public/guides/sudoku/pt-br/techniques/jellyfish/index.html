Jellyfish · Exemplo passo a passo

Para um dígito, todos os dígitos candidatos em quatro linhas de base ficam em quatro colunas de cobertura. Linhas e colunas podem ser trocadas. Remova esse dígito das linhas de cobertura fora das quatro linhas de base.

Reconheça o padrão

Para um dígito, todos os dígitos candidatos em quatro linhas de base ficam em quatro colunas de cobertura. Linhas e colunas podem ser trocadas.

Como encontrá-lo

Digitalize um único dígito em quatro linhas ou colunas; conte cada dígito candidato nas linhas de base selecionadas e confirme que apenas quatro linhas de cobertura são usadas.

O que permite

Remova esse dígito das linhas de cobertura fora das quatro linhas de base.

Evite a confusão

Apenas quatro linhas desenhadas não são um peixe. Cada dígito candidato em cada base deve estar localizado em uma linha de cobertura escolhida.

Exemplo passo a passo · Linha

Este exemplo começa em uma posição intermediária salva. Os candidatos incluem eliminações lógicas anteriores e não são anotações automáticas recém-geradas.

Azul: evidências. Verde: conclusão. Dígitos riscados: candidatos eliminados. R1C1 significa linha 1, coluna 1.

Etapa 1 · Reconheça o Jellyfish

Cada uma das quatro linhas de base (linha 2, linha 3, linha 6, linha 7) ainda precisa de 2, e todos os seus dígitos candidatos circulados estão nas mesmas quatro linhas de cobertura (coluna 3, coluna 4, coluna 7, coluna 8). A legenda “Linhas de base” marca as quatro linhas de base e “Linhas de cobertura” marca as quatro linhas de cobertura. Juntos eles formam o Jellyfish.

Etapa 2 · Cada linha de cobertura deve ser ocupada uma vez

As quatro linhas de base devem colocar quatro 2 no total. Uma linha de cobertura não pode conter o dígito duas vezes e todas as quatro colocações estão confinadas a essas quatro linhas de cobertura. Portanto as colocações ocupam cada linha de cobertura exatamente uma vez.

Etapa 3 · Remova os dígitos candidatos fora das linhas de base

Cada linha de cobertura já recebe seu 2 de uma das quatro linhas base. Portanto, os dígitos candidatos naquelas linhas que cobrem, mas fora das linhas de base, não podem ser 2; remova R4C4=2, R9C7=2, R9C8=2.
