XY-Chain · Exemplo passo a passo

Cada célula da cadeia possui exatamente dois dígitos candidatos. As células vizinhas se veem e compartilham o dígito de link; as duas extremidades compartilham o dígito alvo. Remova o dígito do terminal compartilhado de uma célula que vê ambas as extremidades.

Reconheça o padrão

Cada célula da cadeia possui exatamente dois dígitos candidatos. As células vizinhas se veem e compartilham o dígito de link; as duas extremidades compartilham o dígito alvo.

Como encontrá-lo

Rastreie células bivaloradas conectadas, alternando para o outro dígito candidato em cada célula, até que o final carregue o dígito alvo inicial.

O que permite

Remova o dígito do terminal compartilhado de uma célula que vê ambas as extremidades.

Evite a confusão

Uma célula de dois dígitos candidatos com uma marca de lápis extra é inválida; cada link e ambas as linhas de visão finais devem ser verificadas.

Etapa 1 · Estabelecer a cadeia de bivalor

Cada célula da cadeia tem exatamente dois candidatos: R5C8={4, 7}, R5C4={3, 7}, R6C6={2, 3}, R6C5={2, 4}. Dentro de cada célula, eles têm uma relação forte: se um é falso, o outro deve ser verdadeiro. Entre células diferentes, os candidatos conectados do mesmo dígito se excluem mutuamente. As extremidades R5C8=4, R6C5=4 compartilham o candidato 4.

Etapa 2 · Raciocínio

Filial 1: suponha que R5C8=4 seja falso.

Etapa 3 · Raciocínio

R5C8=4 é falso. R5C8 agora tem apenas R5C8=7 restante, então deve ser verdade.

Etapa 4 · Raciocínio

Caso 1: R5C8 é a célula de dois valores R5C8=4, R5C8=7. Com seu outro dígito candidato falso, R5C8=7 é forçado a ser verdadeiro sob a suposição atual. Entre as células, é mutuamente exclusivo com R5C4=7, portanto, elimine esses conflitos.

Etapa 5 · Raciocínio

R5C4=7 é falso. R5C4 agora tem apenas R5C4=3 restante, então deve ser verdade.

Etapa 6 · Raciocínio

R5C4 é a próxima célula de dois valores R5C4=3, R5C4=7. Com seu outro dígito candidato falso, R5C4=3 é forçado a ser verdadeiro sob a suposição atual. Entre as células, é mutuamente exclusivo com R6C6=3, portanto, elimine esses conflitos.

Etapa 7 · Raciocínio

Etapa 8 · Raciocínio

R6C6 é a próxima célula de dois valores R6C6=2, R6C6=3. Com seu outro dígito candidato falso, R6C6=2 é forçado a ser verdadeiro sob a suposição atual. Entre as células, é mutuamente exclusivo com R6C5=2, portanto, elimine esses conflitos.

Etapa 9 · Raciocínio

Na célula bivalor do terminal R6C5 (R6C5=2, R6C5=4), R6C5=2 é falso, portanto R6C5=4 é forçado a ser verdadeiro sob a suposição atual. Este endpoint exclui os destinos R6C8=4, R6C9=4.
