Reconheça o padrão

links de inferência fortes colorem um dígito em estados de verdade lógicos opostos dentro de cada componente; os relacionamentos entre os componentes restringem quais estados de verdade lógicos podem coexistir.

Como encontrá-lo

Pinte cada componente conectado separadamente e, em seguida, inspecione os conflitos entre componentes e os alvos que veem todas as alternativas sobreviventes.

O que permite

Remova um dígito candidato excluído por todas as atribuições de cores consistentes.

Evite a confusão

Não junte componentes separados com um link de inferência forte não verificado nem presuma que uma cor já foi colocada.

Exemplo passo a passo · Cor complexa

Este exemplo começa em uma posição intermediária salva. Os candidatos incluem eliminações lógicas anteriores e não são anotações automáticas recém-geradas.

Azul: evidências. Verde: conclusão. Dígitos riscados: candidatos eliminados. R1C1 significa linha 1, coluna 1.

Etapa 1 · Confirme o grupo inicial de estado de verdade com a mesma lógica

“Contradição entre componentes de coloração (Multi-Component Coloring Contradiction)” — Esse nome descreve uma demonstração própria do aplicativo entre vários componentes; não é uma técnica HoDoKu independente com esse nome. Os candidatos do dígito 2 formam 4 componentes de coloração independentes. Ao alternar cores pelos elos fortes, R3C1=2, R8C2=2 ficam no lado A do componente 2: compartilham o mesmo valor lógico e são exatamente os candidatos-alvo R3C1=2, R8C2=2. A e B são opostos dentro de cada componente; os conflitos ligam os estados entre componentes.

Etapa 2 · Suponha que o estado de verdade lógico alvo seja verdadeiro

Trate todo o grupo de estados de verdade lógicos R3C1=2, R8C2=2 como um estado de verdade lógico e assuma temporariamente que é verdadeiro. Acompanhe os conflitos entre componentes.

Etapa 3 · Siga cada transição de componente

1. R3C1=2 é verdadeiro, então o par visível R1C2=2 é falso. O estado de verdade lógico A/B oposto R1C9=2 nesse grupo é, portanto, verdadeiro. 2. R1C9=2 é verdadeiro, então o par visível R5C9=2 é falso. O estado de verdade lógico A/B oposto R4C7=2, R5C6=2 nesse grupo é, portanto, verdadeiro. 3. R4C7=2 é verdadeiro, então o par visível R4C4=2 é falso. O estado de verdade lógico A/B oposto R3C4=2 nesse grupo é, portanto, verdadeiro. 4. R3C4=2 é verdadeiro, então o par visível R3C1=2 é falso. O estado de verdade lógico A/B oposto R8C1=2 nesse grupo é, portanto, verdadeiro.

Etapa 4 · A suposição força seu oposto

A suposição R3C1=2, R8C2=2 eventualmente força R8C1=2, o estado de verdade lógico A/B oposto no mesmo grupo. Ambos os estados de verdade lógicos não podem ser verdadeiros, portanto a suposição é falsa.

Etapa 5 · Remova o estado de verdade lógico impossível

O estado de verdade lógico inicial não pode ser verdadeiro. Remova seus dígitos candidatos: R3C1=2, R8C2=2.

O que permite

O estado de verdade lógico inicial não pode ser verdadeiro. Remova seus dígitos candidatos: R3C1=2, R8C2=2.
