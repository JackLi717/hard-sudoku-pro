Skyscraper · Exemplo passo a passo

Dois links de inferência fortes para um dígito estão localizados em linhas ou colunas paralelas. Uma extremidade de cada link compartilha uma linha de cruzamento. Remova o dígito de qualquer célula que tenha ambas as extremidades desalinhadas.

Reconheça o padrão

Dois links de inferência fortes para um dígito estão localizados em linhas ou colunas paralelas. Uma extremidade de cada link compartilha uma linha de cruzamento.

Como encontrá-lo

Encontre duas linhas com exatamente dois dígitos candidatos para um dígito. Alinhe um dígito candidato de cada linha de uma coluna e inspecione as outras duas extremidades.

O que permite

Remova o dígito de qualquer célula que tenha ambas as extremidades desalinhadas.

Evite a confusão

As extremidades alinhadas não precisam estar no mesmo bloco 3×3. Cada linha base deve ter exatamente dois dígitos candidatos; um alvo deve ver ambas as extremidades desalinhadas.

Exemplo passo a passo · Linha

Este exemplo começa em uma posição intermediária salva. Os candidatos incluem eliminações lógicas anteriores e não são anotações automáticas recém-geradas.

Azul: evidências. Verde: conclusão. Dígitos riscados: candidatos eliminados. R1C1 significa linha 1, coluna 1.

Etapa 1 · Encontre os dois links de inferência fortes

Para 8, linha 5 possui apenas R5C4 e R5C1, enquanto linha 7 possui apenas R7C5 e R7C1. Cada par é um forte elo de inferência: se uma extremidade for falsa, a outra é verdadeira.

Etapa 2 · Conecte os links em um Skyscraper

R5C1 e R7C1 se veem em coluna 1, portanto, ambos não podem ser 8. São as duas extremidades da base; R5C4 e R7C5 são os dois telhados. Este link de inferência fraco entre as extremidades da base conecta os dois links de inferência fortes em um Skyscraper.

Etapa 3 · Siga a corrente até o outro telhado

Se o telhado R5C4 não for 8, linha 5 forçará R5C1 a ser 8. Isso exclui R7C1 em coluna 1, então linha 7 força o outro telhado R7C5 a ser 8.

Etapa 4 · Pelo menos um telhado é verdadeiro

Se R5C4 for 8, a reclamação será imediata; caso contrário, a cadeia força R7C5 a ser 8. Portanto, pelo menos um telhado é 8. Cada alvo (R8C4) vê ambos os telhados, portanto nenhum pode ser 8.

Etapa 5 · Remova os dígitos candidatos alvo

Pelo menos um dos dois telhados é 8 e cada alvo (R8C4) vê ambos. Remova o dígito candidato 8 desses destinos.
