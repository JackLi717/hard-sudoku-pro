Visão geral dos peixes · Conceitos fundamentais

As técnicas de peixe examinam as posições de um dígito. Definição

As técnicas de peixe examinam as posições de um dígito. No X-Wing mais simples, duas linhas podem colocar esse dígito apenas nas mesmas duas colunas, portanto, outras linhas não podem colocá-lo nessas colunas. Os quatro dígitos candidatos nas interseções linha-coluna são os quatro cantos do retângulo.

Como encontrá-lo

Concentre-se em um dígito: escolha duas linhas com exatamente duas posições cada, ambas nas mesmas duas colunas; em seguida, troque linhas e colunas.

Erro comum

Verifique todos os dígitos candidatos nas linhas escolhidas, não apenas quatro cantos atraentes. As linhas de base e de cobertura nomeiam essas linhas e colunas; os conceitos a seguir os explicam.

X-Wing · Linha

Quadro de ensino · diagrama de dígitos do candidato local

Observe os dígitos candidatos

Observe apenas o dígito candidato 2, em r2c2, r2c8, r6c2, r6c8; os nomes das linhas podem esperar.

Verifique a condição

Cada base selecionada, linha 2, linha 6, precisa de um 2, e todos os seus dígitos candidatos a 2 estão em coluna 2, coluna 8. As linhas iniciais azuis são chamadas de linhas de base.

Tire a conclusão

As linhas de cruzamento âmbar são chamadas de linhas de cobertura. As linhas base 2 precisam de cópias 2 de 2. Nenhuma linha de cobertura pode conter duas, portanto cada linha de cobertura é ocupada por uma base 2. O alvo r1c2 está localizado em uma linha de cobertura fora das linhas de base e perde 2.

X-Wing · Coluna

Quadro de ensino · diagrama de dígitos do candidato local

Observe os dígitos candidatos

Observe apenas o dígito candidato 2, em r2c2, r8c2, r2c6, r8c6; os nomes das linhas podem esperar.

Verifique a condição

Cada base selecionada, coluna 2, coluna 6, precisa de um 2, e todos os seus dígitos candidatos a 2 estão em linha 2, linha 8. As linhas iniciais azuis são chamadas de linhas de base.

Tire a conclusão

As linhas de cruzamento âmbar são chamadas de linhas de cobertura. As linhas base 2 precisam de cópias 2 de 2. Nenhuma linha de cobertura pode conter duas, portanto cada linha de cobertura é ocupada por uma base 2. O alvo r2c1 está localizado em uma linha de cobertura fora das linhas de base e perde 2.
