Definição

Uma cadeia alterna links de inferência fortes e fracos para passar restrições de verdade de nó para nó.

Como encontrá-lo

Comece com um link de inferência forte verificado e verifique cada link e nó sucessivos.

Erro comum

Uma linha traçada não é prova. Um link inválido ou fora de ordem quebra a cadeia.
