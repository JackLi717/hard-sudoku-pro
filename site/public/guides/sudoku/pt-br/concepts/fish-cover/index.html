Linhas de cobertura do peixe · Conceitos fundamentais

linhas de cobertura são linhas ou colunas cruzadas que contêm todos os dígitos candidatos para o dígito escolhido nas linhas de base. Aqui, cada dígito candidato 2 nas linhas de base azuis está em uma coluna de linha de cobertura âmbar. Um peixe básico requer que o número de linhas de base seja igual ao número de linhas de cobertura.

Definição

linhas de cobertura são linhas ou colunas cruzadas que contêm todos os dígitos candidatos para o dígito escolhido nas linhas de base. Aqui, cada dígito candidato 2 nas linhas de base azuis está em uma coluna de linha de cobertura âmbar. Um peixe básico requer que o número de linhas de base seja igual ao número de linhas de cobertura.

Como encontrá-lo

Encontre cada 2 nas linhas azuis e conte as linhas âmbar: duas linhas de base precisam de duas linhas de cobertura, três precisam de três.

Erro comum

Quatro cantos não são suficientes. Um extra de 2 fora das linhas de cobertura quebra a condição básica do peixe.

X-Wing · Linha

Quadro de ensino · diagrama de dígitos do candidato local

Observe os dígitos candidatos

Observe apenas o dígito candidato 2, em r2c2, r2c8, r6c2, r6c8; os nomes das linhas podem esperar.

Verifique a condição

Comece no linha 2, linha 6 azul e encontre cada 2; cada linha deve eventualmente conter um 2. Estas linhas iniciais selecionadas são as linhas de base.

Tire a conclusão

Cada 2 em linha 2, linha 6 está no coluna 2, coluna 8 âmbar; existem linhas de base 2 e tantas linhas de cobertura.
