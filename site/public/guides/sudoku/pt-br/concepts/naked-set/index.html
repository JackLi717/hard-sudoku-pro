Conjuntos nus · Conceitos fundamentais

Definição

Em uma mesma unidade, todos os candidatos de N células reúnem exatamente N dígitos distintos. Esses dígitos ficam reservados para essas células.

Como encontrá-lo

Escolha casas de uma mesma linha, coluna ou bloco e conte os dígitos distintos presentes em todos os seus candidatos, contando cada dígito apenas uma vez.

Erro comum

Conte cada dígito candidato nas células selecionadas. Mais dígitos distintos do que células quebram esse conjunto nu.
