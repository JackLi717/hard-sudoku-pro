隱性數組 · 核心概念

在同一區域內，N 種數字只出現在 N 格中，即使這些格還有其他候選數也成立。

本課程改編自 Platon Sudoku App 的教學內容。你可以在這裡讀完完整實例，再到應用程式中繼續學習和練習。

定義

在同一區域內，N 種數字只出現在 N 格中，即使這些格還有其他候選數也成立。

如何尋找

固定數字，逐格數它們在整行、整列或整宮中的所有可去位置。

容易誤判

要檢查整個區域；若所選數字還出現在高亮格以外，就不是這個隱性數組。

得出結論

高亮數字在標出的區域中只出現於高亮格；數字數與格子數相同，構成隱性數組。
