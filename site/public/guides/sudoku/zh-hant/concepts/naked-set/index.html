顯性數組 · 核心概念

在同一區域內，N 格的全部候選數合計恰好是 N 種數字。這些數字只能填在這 N 格中。

定義

在同一區域內，N 格的全部候選數合計恰好是 N 種數字。這些數字只能填在這 N 格中。

如何尋找

選取同一行、列或宮中的格子，再計算這些格全部候選數的聯集：相同數字只計一次。

容易誤判

只看高亮候選不夠；選中格子的全部候選若超過格子數，就不是這個顯性數組。
