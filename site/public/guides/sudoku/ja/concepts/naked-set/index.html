ネイキッド集合 · 基本概念

同じ領域の N マスに候補が合計 N 種類しかない構造です。

このレッスンは Platon Sudoku アプリの教材をウェブ向けに構成したものです。ここで例題を最後まで読み、アプリで学習と練習を続けられます。

Google Play で見る ↗

定義

同じ領域の N マスに候補が合計 N 種類しかない構造です。

探し方

同じ行・列・ブロックの選んだマスで候補の種類を数えます。

よくある誤り

選んだマスの候補の種類がマス数を超えると、そのネイキッド集合は成立しません。
