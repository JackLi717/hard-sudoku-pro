ヒドゥン集合 · 基本概念

N 個の数字の位置が一領域で N マスだけに限られる構造です。

このレッスンは Platon Sudoku アプリの教材をウェブ向けに構成したものです。ここで例題を最後まで読み、アプリで学習と練習を続けられます。

Google Play で見る ↗

定義

N 個の数字の位置が一領域で N マスだけに限られる構造です。

探し方

数字を固定し、領域全体の置き場所を数えます。

よくある誤り

選んだ数字が強調マスの外にもあれば、そのヒドゥン集合は成立しません。
