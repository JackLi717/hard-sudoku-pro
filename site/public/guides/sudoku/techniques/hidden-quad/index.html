Hidden Quad · Step-by-step example

Within one row, column, or box, four digits have possible positions only in the same four cells. Remove any other candidates from those four cells.

Recognize the pattern

Within one row, column, or box, four digits have possible positions only in the same four cells.

How to find it

Choose four digits in one region and check whether all their remaining positions fit within four cells.

What it allows

Remove any other candidates from those four cells.

Avoid the mix-up

The four cells can show extra candidates at first. Check positions for the four digits across the whole region, not only the marked cells.

Step-by-step example · Row

This example starts from a saved intermediate position. Its candidates include earlier logical eliminations; they are not fresh automatic notes.

Blue: evidence. Green: conclusion. Crossed-out digits: eliminated candidates. R1C1 means row 1, column 1.

Step 1 · Observe the positions

In row 8, 1, 6, 8, 9 can appear only in these four cells.

Step 2 · Understand the reservation

These four digits must each occupy one cell. No other digits fit in these cells.

Step 3 · Remove candidates

Remove the marked 2, 4 candidates from these four cells.

What it allows
