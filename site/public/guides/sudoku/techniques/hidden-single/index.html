Hidden Single · Step-by-step example

A digit has only one possible cell in a row, column, or box. The cell may still show other candidates. Put the digit in the only remaining cell of that region.

Recognize the pattern

A digit has only one possible cell in a row, column, or box. The cell may still show other candidates.

How to find it

Choose one digit and scan a box, row, or column. Rule out cells that see an already placed copy of that digit.

What it allows

Put the digit in the only remaining cell of that region.

Avoid the mix-up

A naked single has one candidate in a cell. A hidden single has one place for a digit in a region. Check every cell in that region before placing it.
