Unique Rectangle · Step-by-step example

Four cells in two rows, two columns, and two boxes form a deadly rectangle when all four are restricted to the same pair. Remove both pair digits from the fourth corner.

Recognize the pattern

Four cells in two rows, two columns, and two boxes form a deadly rectangle when all four are restricted to the same pair.

How to find it

Find three corners with only the same pair and inspect the remaining corner for extra candidates.

What it allows

Remove both pair digits from the fourth corner.

Avoid the mix-up

The four corners must occupy exactly two boxes; if the fourth has only the pair, the puzzle would have two solutions.

Step 2 · Unique Rectangle Type 1

Type 1: three corners have only 2, 6. If the fourth also took one of these digits, the rectangle could be swapped. The fourth must use another digit.

Step 3 · Rectangle filling 1

Possible rectangle filling 1: R2C4=2, R2C6=6, R8C4=6, R8C6=2. Swapping all four entries gives the other filling. These are hypothetical values only.
