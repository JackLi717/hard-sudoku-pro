Finned X-Wing · Step-by-step example

An X-Wing has an extra candidate in one base row or column. The fin lies in the same box as a base corner. Remove the digit only where the target shares a cover column with the X-Wing and sees the fin in its box.

Recognize the pattern

An X-Wing has an extra candidate in one base row or column. The fin lies in the same box as a base corner.

How to find it

Find two base rows and two cover columns, then look for an extra candidate beside one corner in its box.

What it allows

Remove the digit only where the target shares a cover column with the X-Wing and sees the fin in its box.

Avoid the mix-up

Do not clear the entire cover column. The target must see the fin; verify all base candidates and the shared box.

Step-by-step example · Row

This example starts from a saved intermediate position. Its candidates include earlier logical eliminations; they are not fresh automatic notes.

Blue: evidence. Green: conclusion. Crossed-out digits: eliminated candidates. R1C1 means row 1, column 1.

Step 1 · Build the complete fish body

For 9, the two base lines (row 5, row 7) and two cover lines (column 3, column 5) define the four body candidates R5C3=9, R5C5=9, R7C3=9, R7C5=9. The extra candidates R7C4=9 are fins in box 8. The targets R8C5=9, R9C5=9 lie in a cover line outside the base lines.

Step 2 · Separate the fins from the body

The outlined candidates R7C4=9 are the fins in box 8; the other four candidates R5C3=9, R5C5=9, R7C3=9, R7C5=9 are the X-Wing body. Now check both possibilities: a fin is true, or every fin is false.

Step 3 · Assume fin 1 is true

If the fin R7C4=9 is true, every marked target R8C5=9, R9C5=9 sees it in box 8, so those targets cannot be 9.

Step 4 · Case: every fin is false

If every fin R7C4=9 is false, the four body candidates R5C3=9, R5C5=9, R7C3=9, R7C5=9 form an ordinary X-Wing across the two base lines (row 5, row 7) and two cover lines (column 3, column 5). The targets R8C5=9, R9C5=9 lie in a cover outside the bases, so the X-Wing excludes them.

Step 5 · Apply both target conditions

A valid target must satisfy both conditions: it lies in an X-Wing cover outside the two bases, and it sees every fin. The targets R8C5=9, R9C5=9 satisfy both, so remove candidate 9.
