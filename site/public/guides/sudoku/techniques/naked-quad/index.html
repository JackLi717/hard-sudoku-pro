Naked Quad · Step-by-step example

Four cells in one row, column, or box contain only four digits between them. Remove those four digits from every other cell in that region.

Recognize the pattern

Four cells in one row, column, or box contain only four digits between them.

How to find it

Compare four cells with short candidate lists in one region. Their combined set must contain exactly four digits.

What it allows

Remove those four digits from every other cell in that region.

Avoid the mix-up

A quad is not four identical candidate lists. No selected cell may contain a fifth digit, and all four cells must share one region.

This example starts from a saved intermediate position. Its candidates include earlier logical eliminations; they are not fresh automatic notes.

Blue: evidence. Green: conclusion. Crossed-out digits: eliminated candidates. R1C1 means row 1, column 1.

Together, these four cells have only 2, 4, 7, 9 as candidates.

Step 2 · Understand the reservation

Digits cannot repeat in row 9, so these four digits must each occupy one cell.

Step 3 · Remove candidates
