Naked Pair · Step-by-step example

Two cells in the same row, column, or box each contain only the same two candidates. Remove both digits from the other cells in every region shared by the pair.

Recognize the pattern

Two cells in the same row, column, or box each contain only the same two candidates.

How to find it

With candidates visible, find a two-candidate cell and check the rest of its row, column, and box for an identical partner.

What it allows

Remove both digits from the other cells in every region shared by the pair.

Avoid the mix-up

Two cells merely containing the same two digits are not enough if either has a third candidate. A hidden pair is identified by where two digits can go, not by two cells having only those digits.

Step-by-step example · Row

This example starts from a saved intermediate position. Its candidates include earlier logical eliminations; they are not fresh automatic notes.

Blue: evidence. Green: conclusion. Crossed-out digits: eliminated candidates. R1C1 means row 1, column 1.

Step 1 · Observe the pair

These two cells contain only 1 and 3.

Step 2 · Understand the reservation

Digits cannot repeat in row 2. One cell must be 1, the other 3.

Step 3 · Remove candidates

Remove the marked 1, 3 candidates from other cells in row 2.

What it allows

Remove the marked 1, 3 candidates from other cells in row 2.
