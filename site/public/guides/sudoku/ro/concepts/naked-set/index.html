Definiție

În aceeași unitate, toți candidații din N celule formează împreună exact N cifre distincte. Aceste cifre sunt rezervate acelor celule.

Cum să-l găsești

Alegeți celule din aceeași linie, coloană sau același bloc și numărați cifrele distincte din toți candidații lor, numărând fiecare cifră o singură dată.

Greșeală comună

Numărați fiecare cifră candidată din celulele selectate. Cifre mai distincte decât celule rup acest set gol.
