Definiție

Un candidat este o cifră care încă poate fi înscrisă într-o celulă goală. Este o posibilitate, nu o valoare deja confirmată.

Cum să-l găsești

Verificați dacă celula este goală, apoi excludeți cifrele deja plasate în rândul său, coloana și blocul 3×3.

Greșeală comună

O notă mică este o cifră candidată; o cifră mare plasată nu este. Diagrama locală arată doar note relevante.

Observați cifrele candidatului

Un candidat este o cifră care încă poate fi înscrisă într-o celulă goală. Este o posibilitate, nu o valoare deja confirmată.

Verificați starea

Verificați dacă celula este goală, apoi excludeți cifrele deja plasate în rândul său, coloana și blocul 3×3.

Trage concluzia

Celula evidențiată este goală, iar 2-ul său mic este încă o valoare posibilă.
