Nice Loop / AIC · Exemplu pas cu pas

Un lanț de inferență alternativ conectează stările de adevăr logice ale cifrelor candidate cu legături de inferență puternice și slabe verificate. Lanțurile deschise și închise au concluzii distincte. Utilizați rezultatul verificat: eliminați o cifră candidată sau plasați o cifră atunci când starea sa de adevăr logic opus este imposibilă.

Această lecție este adaptată din aplicația Platon Sudoku. Citește exemplul complet aici, apoi continuă să înveți și să exersezi în aplicație.

Recunoașteți modelul

Un lanț de inferență alternativ conectează stările de adevăr logice ale cifrelor candidate cu legături de inferență puternice și slabe verificate. Lanțurile deschise și închise au concluzii distincte.

Cum să-l găsești

Urmăriți fiecare implicație de la un capăt, înregistrând tranzițiile puternice și slabe și dacă lanțul se închide sau contrazice un punct final.

Ce permite

Utilizați rezultatul verificat: eliminați o cifră candidată sau plasați o cifră atunci când starea sa de adevăr logic opus este imposibilă.

Evitați amestecul

O legătură puternică înseamnă: dacă un capăt este fals, celălalt este adevărat. O legătură slabă înseamnă: dacă un capăt este adevărat, celălalt este fals. Nu inversați aceste implicații; verificați relația dintre capete înainte de a trage concluzia.

Această lecție Nice Loop / AIC folosește familia de noduri de cifre candidate obișnuite a lui HoDoKu: eliminări și plasări discontinue, lanțuri deschise de tip 1 și tip 2 și bucle continue. Începeți de la R1C6=1 este adevărat și inspectați R1C6=1. În coloana 6, rândul 2, coloana 9, rândul 7, Bloc 3×3 5, rândul 5, coloana 1, rândul 9, coloana 8, o legătură cu linie continuă înseamnă că cel puțin un capăt este adevărat; o legătură întreruptă înseamnă că cele două puncte finale nu pot fi adevărate în același timp. Urmăriți câte o relație evidențiată.

Pas 2 · Ipoteza: începeți lanțul alternativ

Branch 1: să presupunem că R1C6=1 este adevărat.

Pas 3 · Relație slabă: conflictul cifrelor candidate legate

R1C6=1 este adevărat. Eliminați R1C6=8.

Pas 4 · Relație puternică: celălalt punct final este forțat

R1C6=8 este fals. Împreună, aceste două părți conțin fiecare opțiune rămasă în coloana 6. Prin urmare, R2C6=8 trebuie să fie adevărat.

Pas 5 · Relație slabă: conflictul cifrelor candidate legate

R2C6=8 este adevărat. Eliminați R2C6=6.

Pas 6 · Relație puternică: celălalt punct final este forțat

R2C6=6 este fals. Împreună, aceste două părți conțin fiecare opțiune rămasă în rândul 2. Prin urmare, R2C9=6 trebuie să fie adevărat.

Pas 7 · Relație slabă: conflictul cifrelor candidate legate

R2C9=6 este adevărat. Eliminați R2C9=3.

Pas 8 · Relație puternică: celălalt punct final este forțat

R2C9=3 este fals. Împreună, aceste două părți conțin fiecare opțiune rămasă în coloana 9. Prin urmare, R7C9=3 trebuie să fie adevărat.

Pas 9 · Relație slabă: conflictul cifrelor candidate legate

R7C9=3 este adevărat. Eliminați R7C6=3.

Pas 10 · Relație puternică: celălalt punct final este forțat

R7C6=3 este fals. Împreună, aceste două părți conțin fiecare opțiune rămasă în coloana 6. Prin urmare, R6C6=3 trebuie să fie adevărat.

Pas 11 · Relație slabă: conflictul cifrelor candidate legate

R6C6=3 este adevărat. Eliminați R5C4=3.

Pas 12 · Relație puternică: celălalt punct final este forțat

R5C4=3 este fals. Împreună, aceste două părți conțin fiecare opțiune rămasă în rândul 5. Prin urmare, R5C1=3 trebuie să fie adevărat.

Pas 13 · Relație slabă: conflictul cifrelor candidate legate

R5C1=3 este adevărat. Eliminați R9C1=3.

Pas 14 · Relație puternică: celălalt punct final este forțat

R9C1=3 este fals. Împreună, aceste două părți conțin fiecare opțiune rămasă în rândul 9. Prin urmare, R9C8=3 trebuie să fie adevărat.

Pas 15 · Relație slabă: conflictul cifrelor candidate legate

R9C8=3 este adevărat. Eliminați R2C8=3.

Pas 16 · Aceeași celulă: forțați cealaltă cifră candidată

R2C8=3 este fals. În aceeași celulă R2C8, cealaltă cifră candidată R2C8=8 este forțată adevărată în ipoteza curentă.

Pas 17 · Relație slabă: conflictul cifrelor candidate legate

R2C8=8 este adevărat. Eliminați R2C6=8.

Pas 18 · Relație puternică: celălalt punct final este forțat

R2C6=8 este fals. Împreună, aceste două părți conțin fiecare opțiune rămasă în coloana 6. Prin urmare, R1C6=8 trebuie să fie adevărat.

Pas 19 · Lanțul ajunge la o contradicție

Deducerea contrazice „R1C6=1 este adevărat”, deci R1C6=1 este fals.

Pas 20 · Retrageți umplutura anterioară a dreptunghiului

Retrageți această presupunere și consecințele ei. Reveniți la instantaneul neschimbat al cifrei candidatului înainte de a examina următoarea posibilitate.

Lanțul alternativ a pornit de la „R1C6=1 este adevărat” și a urmat relațiile etichetate puternice și slabe, inclusiv comutatoare cu aceeași celulă acolo unde a fost necesar, până la o contradicție. Prin urmare, R1C6=1 este fals. Toate stările de adevăr logice temporare sunt retrase.
