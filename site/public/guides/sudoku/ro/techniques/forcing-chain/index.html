Recunoașteți modelul

Un set exhaustiv de alternative de cifre candidate este urmat prin lanțuri de implicații liniare separate.

Cum să-l găsești

Alegeți o împărțire adevărat/fals sau toate pozițiile unei cifre într-o regiune; urmați fiecare ramură până la consecința ei verificată.

Ce permite

Păstrați doar o poziție sau o eliminare împărtășită de fiecare ramură viabilă.

Evitați amestecul

O ramură care ajunge la un rezultat este insuficientă; alternativele de pornire trebuie să acopere toate posibilităţile.

Exemplu pas cu pas · Două ramuri

Exemplul începe dintr-o poziție intermediară salvată. Candidații includ eliminări logice anterioare și nu sunt notițe automate abia generate.

Albastru: dovezi. Verde: concluzie. Cifre tăiate: candidați eliminați. R1C1 înseamnă rândul 1, coloana 1.

Pas 1 · Unde să caut

Rezultatul comun de demonstrat este R1C2=7; comutatorul de ramură este R1C2=5. Orice cifră candidată este fie adevărată, fie falsă, astfel încât aceste două ramuri acoperă toate posibilitățile. Dacă ambele ajung la rezultatul comun, acel rezultat este forțat.

Pas 2 · Raţionament

Branch 1: să presupunem că R1C2=5 este adevărat.

Pas 3 · Raţionament

R1C2=5 este adevărat. Eliminați R1C2=7.

Pas 4 · Retrageți umplutura anterioară a dreptunghiului

Retrageți această presupunere și consecințele ei. Reveniți la instantaneul neschimbat al cifrei candidatului înainte de a examina următoarea posibilitate.

Pas 5 · Raţionament

Branch 2: să presupunem că R1C2=5 este fals.

Pas 6 · Raţionament

R1C2=5 este fals. Împreună, aceste două părți conțin fiecare opțiune rămasă în rândul 1. Prin urmare, R1C5=5 trebuie să fie adevărat.

Pas 7 · Raţionament

R1C5=5 este adevărat. Eliminați R2C5=5 din coloana 5.

Pas 8 · Raţionament

R2C5=5 este fals. Împreună, aceste două părți conțin fiecare opțiune rămasă în rândul 2. Prin urmare, R2C8=5 trebuie să fie adevărat.

Pas 9 · Raţionament

R2C8=5 este adevărat. Eliminați R2C8=9.

Pas 10 · Raţionament

R2C8=9 este fals. Împreună, aceste două părți conțin fiecare opțiune rămasă în rândul 2. Prin urmare, R2C4=9 trebuie să fie adevărat.

Pas 11 · Raţionament

R2C4=9 este adevărat. Eliminați R1C4=9 din coloana 4.

Pas 12 · Raţionament

R1C4=9 este fals. R1C4 mai are acum doar R1C4=7, așa că trebuie să fie adevărat.

Pas 13 · Raţionament

R1C4=7 este adevărat. Eliminați R1C2=7 din rândul 1.

Pas 14 · Raţionament

Fiecare ramură posibilă ajunge la același fapt: R1C2=7 este fals. După retragerea tuturor ipotezelor, acest fapt rămâne cert.

Pas 15 · Concluzie

Rezultatul verificat este R1C2=7 este fals. Toate ipotezele temporare au fost retrase.

Ce permite

Pas 1 · Unde să caut

Rădăcinile R2C4=2, R2C4=3, R2C4=6, R2C4=7 sunt fiecare cifră candidată posibilă din R2C4. Urmăriți fiecare ca un lanț de implicații liniar separat; dacă fiecare rădăcină ajunge la R2C6=3, rezultatul este forțat. Numai rădăcinile multiple nu fac acest lucru un Rețea de forțare (Forcing Net).
