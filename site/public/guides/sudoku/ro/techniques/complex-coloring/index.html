Recunoașteți modelul

Inferența puternică leagă culoarea unei cifre în stări de adevăr logice opuse în fiecare componentă; relațiile dintre componente constrâng care stări logice de adevăr pot coexista.

Cum să-l găsești

Colorează fiecare componentă conectată separat, apoi inspectează conflictele între componente și țintele care văd fiecare alternativă supraviețuitoare.

Ce permite

Eliminați o cifră candidată exclusă de toate atribuirile de culori consistente.

Evitați amestecul

Nu uniți componente separate cu o legătură de inferență puternică neverificată și nu presupuneți că o culoare este deja plasată.

Exemplu pas cu pas · Culoare complexă

Exemplul începe dintr-o poziție intermediară salvată. Candidații includ eliminări logice anterioare și nu sunt notițe automate abia generate.

Albastru: dovezi. Verde: concluzie. Cifre tăiate: candidați eliminați. R1C1 înseamnă rândul 1, coloana 1.

Pas 1 · Confirmați grupul de început cu aceeași stare logică de adevăr

“Contradicție între componente de colorare (Multi-Component Coloring Contradiction)” — Acest nume descrie o demonstrație proprie aplicației între mai multe componente, nu o tehnică HoDoKu distinctă cu același nume. Candidații cifrei 2 formează 4 componente de colorare independente. Alternarea culorilor de-a lungul legăturilor puternice pune R3C1=2, R8C2=2 pe partea A a componentei 2: au aceeași valoare de adevăr și sunt exact candidații-țintă R3C1=2, R8C2=2. A și B sunt opuse în fiecare componentă; conflictele leagă stările dintre componente.

Pas 2 · Să presupunem că starea de adevăr logică țintă este adevărată

Tratați întregul grup de stări de adevăr logic R3C1=2, R8C2=2 ca o stare de adevăr logic și presupuneți temporar că este adevărat. Urmăriți conflictele dintre componente.

Pas 3 · Urmăriți fiecare tranziție de componentă

1. R3C1=2 este adevărat, deci peer-ul vizibil R1C2=2 este fals. Prin urmare, starea logică de adevăr R1C9=2 opusă A/B din acel grup este adevărată. 2. R1C9=2 este adevărat, deci peer-ul vizibil R5C9=2 este fals. Prin urmare, starea logică de adevăr R4C7=2, R5C6=2 opusă A/B din acel grup este adevărată. 3. R4C7=2 este adevărat, deci peer-ul vizibil R4C4=2 este fals. Prin urmare, starea logică de adevăr R3C4=2 opusă A/B din acel grup este adevărată. 4. R3C4=2 este adevărat, deci peer-ul vizibil R3C1=2 este fals. Prin urmare, starea logică de adevăr R8C1=2 opusă A/B din acel grup este adevărată.

Pas 4 · Presupunerea forțează opusul ei

Presupunerea R3C1=2, R8C2=2 forțează în cele din urmă R8C1=2, starea de adevăr logică opusă A/B în același grup. Ambele stări de adevăr logic nu pot fi adevărate, deci presupunerea este falsă.

Pas 5 · Eliminați starea de adevăr logic imposibil

Starea de adevăr logică de pornire nu poate fi adevărată. Eliminați cifrele sale candidate: R3C1=2, R8C2=2.

Ce permite
