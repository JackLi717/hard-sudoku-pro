Recunoașteți modelul

Trei celule într-o intersecție rând–3×3 bloc sau coloană–3×3 bloc conțin doar trei cifre între ele.

Cum să-l găsești

Verificați cele trei celule în care un rând sau o coloană traversează un bloc 3×3. Căutați un set combinat de exact trei cifre candidate.

Ce permite

Eliminați acele trei cifre din fiecare altă celulă din linia partajată și blocul 3×3.

Evitați amestecul

Cele trei celule nu trebuie să aibă cifre candidate identice. Fiecare cifră candidată din ele trebuie să aparțină aceluiași set de trei cifre.
