Set tersembunyi · Konsep teras

Dalam satu kawasan, N digit hanya boleh muncul dalam N petak, walaupun petak itu juga mengandungi calon lain.

Definisi

Dalam satu kawasan, N digit hanya boleh muncul dalam N petak, walaupun petak itu juga mengandungi calon lain.

Bagaimana untuk mencarinya

Pilih digit dan kira setiap tempat yang boleh mereka duduki di seluruh rantau.

Kesilapan biasa

Semak seluruh wilayah. Digit yang dipilih di luar petak yang diserlahkan memecahkan set tersembunyi ini.
