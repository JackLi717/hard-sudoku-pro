Paljaat joukot · Keskeiset käsitteet

Saman alueen N ruudun kaikki ehdokkaat muodostavat yhdessä täsmälleen N eri numeroa. Nämä numerot on varattu kyseisille ruuduille.

Tämä oppitunti perustuu Platon Sudoku -sovelluksen opetusaineistoon. Lue koko esimerkki täällä ja jatka oppimista ja harjoittelua sovelluksessa.

Määritelmä

Saman alueen N ruudun kaikki ehdokkaat muodostavat yhdessä täsmälleen N eri numeroa. Nämä numerot on varattu kyseisille ruuduille.

Kuinka löytää se

Valitse ruutuja samasta rivistä, sarakkeesta tai lohkosta. Laske kaikkien niiden ehdokkaiden joukosta eri numerot; laske kukin numero vain kerran.

Yleinen virhe

Laske jokainen ehdokasnumero valituissa ruuduissa. Selkeämmät numerot kuin ruudut rikkovat tämän paljaan joukon.
